# Fusion planner catalogue

`Data/Catalog.sqlite` is the indexed planner input.
`Data/Manifest.json` records counts, provenance and hashes.
The CSV files expose API types, options, enum values, commands, native types and gaps.

Read the [collection and query guide](../../../Documentation/Reference/Research/FusionPlannerCatalog.md).
Run `VerifyCatalog.py Data` from this directory before consuming the bundle.
All support qualification remains unverified.
This research inventory does not participate in production conversion.
