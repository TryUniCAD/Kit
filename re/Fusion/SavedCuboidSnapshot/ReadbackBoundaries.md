# Saved cuboid readback boundaries

## Independent graph and strict adapter

Two exact source-free inputs, baseline `ed4bfd74…` and post-freeze holdout `f318fd94…`, each passed lower document-codec readback after independent in-memory insertion of a derived snapshot, a minimal structural scene, and both together. All six were refused by public strict projection with `Native fixed rectangle parameter index disagrees with its table`. The constructor's native-state version 1 expects no auxiliary snapshots, graphics, or configurations. The current dispatcher sends any such archive to the vendor-saved projector. These isolated test archives were never published or opened in Fusion.

The solution needs two independent checks. Derive and verify the full constructor graph including the new snapshot owners and payload, then independently admit only a measured constructor-plus-auxiliary profile while preserving the previous version contracts. Auxiliary enclosure or a token alone cannot establish eligibility. The authoring comparison must include all added payloads and references. The existing `CompareNative` summary only compares segments, bodies and materials.

The two source-free graphs both passed the existing constructor summary comparison. Passing the same comparison to two independent verified vendor archives with auxiliary views removed in memory failed on invalid authored material name or constructor record mismatch. Their saved auxiliary values must never be dropped as a workaround. Keep the saved-family strict projection and complete native-state evidence in the route.

## Saved ownership verification

Two distinct serializer collections own the history and the snapshot. The selected history serializer must bind back to the component's ordinary `Bodies` collection. The cache serializer must bind to the separate cache collection and name the exact snapshot archive member. The snapshot's solid and profile roots use caches scoped to the current asset and component, and the sketch root uses the selected sketch's `bodyId`.

All four saved-cuboid fixtures and the existing dimension-edited fixture have these ownership joins. Their tool, region and sketch passive IDs vary from `10,9,8` to `19,18,17`; their saved address values also vary. The reader checks the actual roles and count instead of inferring them from those examples.

The six integration mutations redirect each serializer's reverse collection link, point the cache collection to the history serializer, rename the snapshot, substitute a foreign asset scope, or substitute a different root ID. Before tightening, all six emitted typed states reproduced the intended changes and strict-opened in read-only mode. The same six mutations still round-trip at the lower codec and now receive distinct strict refusal diagnostics for the affected relationship.

An in-memory test with the selected snapshot removed, one extra snapshot with matching geometry, and a wrong root plus the extra snapshot also established strict admission before enforcing cardinality. The exact mutated archive hashes were `2d93a74f3a5ffbe28016753503193f86b56e6b48185de5add9aaf9a87e9be4fc`, `fe5b24e18c595ab37cec233ac2ca59e0ef2a7b886d6ef9a3210330bd017be17f` and `e75215b57ddbbc025b7c526eafb6ba95e208819d67338c93adb18f9bd6293234`. All three now fail strict reading because the saved fixed-corner profile requires exactly one typed prism snapshot.

The related older Reset archive `b40c6af9371c06ba9b267d0bb98e6ed08632e3a70482983f89971405b8629da9` uses a different typed snapshot. It retains four passive roots, including a retired sheet, with 202 records. Its draft/reset projection remains separate. ## Reserved holdout measurement

The exact source-free holdout `f318fd94e17b42603c93135d9d6fde7691e5050f950edeee29d4be0d7a5d52b0` passed four distinct Fusion 2706.1.17 stages on the resumed run. The previously interrupted receipt remains separate. Total measured stage time was 15.497 seconds before process startup and retirement overhead. Fusion opened and rebuilt the candidate at 3.71952 cm³. An independent native height edit to 29.5 mm reached 26.7624 cm³ and the restore to 4.1 mm returned 3.71952 cm³. Independent native width and depth edits reached 5.08851 and 1.842048 cm³, respectively, and each reverted to the original volume. The 1,285 kg/m³ material and effective RGBA `[55,149,208,255]` survived the measured states. The control used an appearance override, so appearance assignment equivalence remains open.

Both exact native archives were reopened, passed strict SDK readback, and preserved complete typed state after persisted JSON. The resulting evidence index SHA-256 is `6999303332894f1e4100ba5bc6370d18416c9406163e47253bfd650c8db7f4ff`. The held-out geometry and material lifecycle now have native evidence. Complete saved-source writing and presentation are later gates.

## Native presentation probe

`ObservePresentation.py` currently accesses `units` in `hasattr` and then through a second getter, and a native exception can discard the whole observation. A follow-up measurement must record unavailable getters individually, preserve successful values and leave a required missing or connected field explicit. The physical density comparison remains distinct from body and face appearance assignment, camera, visibility and rendered outputs.
