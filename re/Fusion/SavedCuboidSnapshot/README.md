# Cuboid snapshot ownership seam

`SnapshotOwners.py` stages the known ownership fields in a fresh constrained-cuboid `AuthorState`. Call `stage_snapshot_owners(author, SnapshotRootPlan(tool, region, sketch), addresses=...)` after the existing body/feature links and rectangle dimensions are complete and before `EmitDesign`. The result is the full member name for `DocumentSnap`. The author graph keeps the relative `BRepSerializer.partName`. The probe derives a new UUID from the owning asset and component. Repeated adoption on the same author graph is refused.

The ordered passive IDs bind the generated tool solid, profile region and sketch sheet. The two new `ETCachedTopology` records take `PartScope(author)` and have no progenitor. Their IDs are allocated by the existing author state. The cache collection remains empty, the `.smbh` body map retains its own namespace, and the optional `ModelDataRef.caches` matrix is outside this seam. Addresses are required explicitly as three unsigned 64-bit values. The code checks their wire type and cardinality. Fusion regenerated three address values from zeros in two existing saved-archive controls. A newly generated owner graph still needs native qualification. [Address contrast](SnapshotAddressContrast.md)

`BuildDesign.py` currently builds a local `AuthorState` and immediately passes it to `EmitDesign`. The separate research adoption path could factor that state construction into a private builder, retaining the existing public wrapper and ordinary emission byte path. The eventual research caller could stage the new fields, use the same `EmitDesign`, and bind the independently derived part through `EmitSnapPart(DocumentSnap(...))`. No vendor archive or program is a constructor input.

The in-memory smoke checks used two freshly authored cuboids. The ordinary `BuildDesign` emitted 205 entity records for each. The snapshot seam used a minimal `AuthorState` role fixture. The touched owner fields passed `DraftGroups`, the two topology cache records and passive ID record round-tripped exactly through `EncodeEntities` and `DecodeEntities`, and the separately generated 11,919-byte snapshot in each case round-tripped through the typed snapshot codec. Missing addresses, a Boolean address, duplicate root IDs, a broken ownership join and duplicate graph adoption were refused. Different asset/component identities yielded distinct names. These measurements cover the individual pieces. The seam still needs a complete archive test. No native run or archive publication occurred.
