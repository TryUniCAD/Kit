## Confirmed grammar

- `ASM BinaryFile4` selects signed little-endian four-byte integer fields. Existing generic journal readers already model this width. Specialized history, snapshot, and ASM table readers must use the same width.
- Native editing allocates entity tags on geometric records. The tags are source identity values, not constant empty fields. Canonical record ownership and body-key ownership remain distinct.
- A nonzero rectangular taper uses the existing typed planar journal vocabulary. With height `h` and angle `a`, the top profile offsets each side by `h tan(a)`. Positive taper expands the cap; negative taper contracts it. Both cap dimensions must remain positive.
- Integrating `(w + 2 z tan(a))(d + 2 z tan(a))` from zero to `h` gives volume. Integrating its first and second moments gives the centroid and complete inertia tensor. Wall area uses the independent slanted side lengths. All native mass-cache fields are checked against these values.
