The original six-phase drawing-edge trial failed in both pristine control observers before edge enumeration. Both actual native drawings opened and rebuilt without errors or warnings; the view and resolved child owned `authored configuration`, while the visible root component returned an empty occurrence configuration. The generated lanes never launched. The unchanged negative result is retained in [DrawingEdgeRootObserverNative01.json](../measurements/2026/DrawingEdgeRootObserverNative01.json).

## Source boundary

[DrawingRootComponentConfiguration2026.json](DrawingRootComponentConfiguration2026.json) pins complete original module hashes, exact vtable cells, complete UI getter ranges and independently delimited three- and six-byte leaves. The registered 2026 metadata binds the actual IComponent2 getter to the XDispatch2 vtable, rather than the obsolete XDispatch interface or the nearest disassembler label. The implementation obtains the component configuration owner through virtual +0x188. Its null branch returns the initially empty string. The moUnitComponent table supplies null at that owner slot and true at its root slot. An empty occurrence configuration is therefore not evidence that the view lost its configuration.

This is a source rule and a negative observation, not yet a completed native edge lifecycle. The exact runtime component class was not captured in the failed batch. The retry checks observable ownership directly.
