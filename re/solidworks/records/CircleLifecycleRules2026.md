## Coordinates and stamps

The ordinary point loop also skips the selected seam marker. An eligible finite center result is committed and counted when maximum component displacement is at least `1e-8`; smaller movement is committed without that count only when its actual runtime option is nonzero. A point setter additionally has real journal/spatial-index/notification bookkeeping.

Circle repair is separate. Let `er` be absolute radius disagreement and `en` absolute out-of-plane marker error. The returned change count increments if either exceeds `1e-8`. Repair is skipped only when both are strictly below `1e-11`; otherwise native code writes a positive-X provisional marker and runs its independently documented seventeen-degree collision search. A repair can occur without a counted stamp increment.

The first stamp addition sums actual point/arc counted changes plus the plane pass, whose selected 2D plane count is zero. The second addition comes from an allocated block-support helper, not a presumed null pointer. Its collector remains empty for the free graph, and for independently admitted local center/radius references with block `-1` and kind zero/two; it returns zero at its empty-count branch.
