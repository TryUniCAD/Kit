# SDK ordered mate native observation protocol

Task B04-SW2026-MATES, owner `/root/assembly_occurrence`, delivery PR #121.
The root agent owns the serial Windows oracle. This tranche adds a source-only
observer and packet freezer around the independently generated SDK ordered
assembly. It changes no writer, public admission, prior fixture or native
control. Its exit condition is a controlled native edit, synchronized save and
fresh reopen of the exact frozen pair with all ordered identities preserved.
That native exit condition is pending in this record.

## Measurements

[InspectSdkOrderedMates.py](../../tooling/sw2026/InspectSdkOrderedMates.py) reuses
the existing `InspectCombinedPlanarMates.phase` and `signature`, including the
proven fresh-process, immutable-input and child-before-parent save path. It
reuses `InspectSdkSingleMate.observe` for both actual active configuration names,
the live child boss D1, and absence of unauthored child sketch dimensions.
The four native phases are the A22 control, generated edit/save, generated fresh
reopen and final A22 control.

The generated checkpoints require the complete 27-row parent and 25-row child
trees, two resolved body instances, fixed first occurrence, exact occurrence
names/configurations, independently predicted transforms, volume, area and
centre of mass. They retain all three ordered mate kinds and six ordered datum
endpoints. Every endpoint resolves its intended component and uses `IsSame`
against that component's specific `IRefPlane`, following the
[measured object-identity rule](../../../Documentation/Gotchas/Conversion/Solidworks/Oracle/MateDatumReferenceUsesSpecificPlane.md).
Both placed-frame and native entity plane relations must agree with the
independent constraints, including the deliberately unconstrained parallel gap.

The editable parameter is `D1@DistanceX@SdkOrderedMixed.Assembly`, changing
47.35 to 63.21 mm. The observer requires setter status zero, retained coincidence
and parallelism, movement along the rotated Right normal, and the independent
edited mass and transforms. The 18.625 mm child depth remains driving and
unchanged. Both child and parent must save with `[true, 0, 0]`. Fresh reopen
checks the child stamp before rebuild, both saved hashes, full trees, references,
configuration names and edited state. Both pristine brackets must remain
healthy and identical, and all four process creation identities must differ.

## Host preflight

[SdkOrderedMateExpectations.py](../../tooling/sw2026/SdkOrderedMateExpectations.py)
independently checks the raw authored neutral rectangle, dimensions, roles,
configurations, occurrence frames and mate inputs before any COM import. Its
placement adapter is bounded to proper Z rotations for this fixture; arbitrary
rotations are not silently admitted. The native edit predictor must reproduce
the previously frozen independent edited geometry and every constraint.

[PrepareSdkOrderedMateTrial.py](../../tooling/sw2026/PrepareSdkOrderedMateTrial.py)
creates an unused external packet with all sixteen exact observer dependencies.
Run its `--help` for the fixture, disclosed control case/parent/child and output
arguments. The frozen observer accepts `verify` or `run`, the packet path and
mandatory `--packet-sha256`. Only `run` enters the Windows oracle; the root agent
executes it serially after the normal idle and license custody checks.

The [host preflight receipt](../measurements/2026/SdkOrderedMateObserverPreflight01.json)
records a passing Python 3.11 process, zero native processes and an empty COM
import set. All sixteen source files parse under that interpreter. The packet
hash is `c2f397de848cc8f1df65dfed15362758570b6b0476895efa3fdeea9be374e525`;
the exact source hashes and independent prediction are frozen before native
execution. This is observer readiness evidence. It establishes no new native
acceptance, held-out coverage or public writer support.
