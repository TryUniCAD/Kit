## Independent phases

[RunSealedNestedEvaluation.py](../../tooling/sw2026/RunSealedNestedEvaluation.py) accepts `verify`, `run` and `summarize`. A run names only slot `1` or `2`, a trial identifier and one phase:

1. `before`: fresh native read-only inspection of the exact disclosed N02 source hierarchy at its original path
2. `build`: code lock, public environment probe, guest-private source validation, request/prediction lock and two guarded generations
3. `generated`: fresh native open, independent hierarchy/transform/geometry/dimension checks, rebuild, source-spec leaf depth edit, repeated root checks and deepest-first owned saves
4. `reopen`: fresh read-only open of the exact synchronized edited dependencies, independent geometry and parameter checks, rebuild, retained update stamps and preserved generated definition trees
5. `after`: independent fresh disclosed N02 control even if an earlier phase failed
6. `qualify`: guest-private verification of the complete chronological bracket, four distinct pinned native identities, unchanged original source siblings, immutable generated inputs, code-before-source/request-before-execution receipts and saved/reopened artifact identity

Each invocation creates one unused public phase directory and one private phase directory. Failed work does not prevent the independent `after` command. A retry of `reopen`, `after` or `qualify` uses a new attempt directory; build and generated mutation are never overwritten or retried in place. Changing writer construction after hidden exposure requires a new independently sealed cohort, rather than a case-specific repair of these results. An observer-only correction needs a new frozen packet and a separate receipt preserving the original failure and any prior output.

The public progress path is `Progress/SlotNN/T01/phase/attempt/Record.json`. Root exclusively executes the guest transport and owns all native processes. The guest command shape is:

```text
python -B Tools/RunSealedNestedEvaluation.py run Evaluation.json 1 T01 before --packet-sha256 PACKET_SHA
```

Run each phase separately in the listed order, then repeat for slot two. Always run the final control after a failed measurement; never inspect a private failure on the host to fit a constructor. Use the existing serialized transport supervisor with the exact public progress directory. An unfinished or failed phase cannot qualify.

Host-safe `summarize` reads only the two public progress trees and frozen public packet. It requires both guest qualifications, eight distinct pinned native identities and no native overlap. It emits an immutable public result containing only verdicts, hashes and process/timing provenance. It does not unseal private designs or detailed observations.
