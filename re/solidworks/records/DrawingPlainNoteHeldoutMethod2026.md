## Proposed thirteen-process native schedule

| Order | Role | Required observation |
| --- | --- | --- |
| 1 | ControlBefore | Exact pristine drawing open/rebuild, no annotation, actual sheet/view/tree |
| 2 | NativeNoteSourceControl | Exact disclosed native note control, Unicode text, both public name/point APIs, free/non-dangling state |
| 3-7 | Slot01 | SourceInitial, SourceEdited, CandidateInitial, CandidateIndependentEdit, CandidateReopen |
| 8-12 | Slot02 | Same five roles on the second independently locked source |
| 13 | ControlAfter | Exact pristine bracket and baseline invariants |

Each role starts its own exact-build process. SourceInitial and SourceEdited open immutable root-verified original and previously locked edited sources read-only, providing independent actual native reference states. CandidateInitial measures the generated original before and after rebuild. CandidateIndependentEdit reopens the original candidate, sets the locked edited text, rebuilds and proves the original position/name/attachment/tree state unchanged; it then sets the locked edited position, rebuilds and proves text/name/attachments/tree preserved. It saves only to an unused derivative with result `[true,0,0]`. CandidateReopen opens that hash-bound derivative in a fresh process and compares to SourceEdited and the preceding edited identity.

The batch requires thirteen distinct process creation FILETIMEs, zero open/rebuild/save diagnostics, healthy controls, unchanged immutable input hashes and clean owned closure. Failed/skipped phases remain explicit. A failing trailing control invalidates the batch. This plan launches no process.

## Independent comparisons

For each native phase capture exact Unicode text; actual `IAnnotation.GetName` and `INote.GetName`; actual `IAnnotation.GetPosition` and `INote.GetTextPoint2` separately; annotation count one; attached entities zero; non-dangling state; active sheet name and eight GetProperties2 values; no model view after the sheet sentinel; rebuild status; and native problem count. Position tolerance is fixed at `2e-9 m` absolute per coordinate, with zero relative tolerance. Preserve raw strings privately and publish only source/candidate digests and residuals for private slots.

Reuse `InspectDrawingCache.drawing_tree`, exercised by the existing `InspectBlankRewrite.phase` route, for actual ordered feature names, concrete types and parent/order. The old ordinary drawing snapshot measures sheet/view state and problem count; it does not substitute for this tree. Compare source and generated note-shaped drawings directly. Retain every baseline tree-name difference; no row filtering or rename whitelist is introduced. Within each source/candidate lifecycle require its tree to remain stable across the independent edits and reopen.

The typed host qualifier must replay complete Definition bytes, aliases, maps and cursor positions independently from normal public projection. It must resolve the actual sheet folder -> display -> component note -> note data -> text hierarchy; actual owner/backlink aliases; name holder versus other identity domains; separate cached attachment and text point; effective frame; direction and distance; and final saved copies. Raw field retention is not modeled admission. The getter/producer rules are in [the position record](DrawingPlainNotePositionOwners2026.md), with [name ownership](DrawingPlainNoteNameOwners2026.md) separate.

Full source admission also requires all source fonts, text formatting, styles, units, properties, chronology and other objects to be accounted by supported semantic inputs. Exact baseline field inventories and constructor-side classification must precede any cache equivalence: a stored glyph cache cannot be copied or silently dropped. Independent rendering or ordinary display-geometry evidence is still a distinct unbound observation requirement; text enumeration alone is not a visibility proof.
