## Normal read route to implement after source locks

The current normal strict read returns `solidworks.typed_resolved_semantics.status=unsupported`, diagnostic `extrusion end mode is outside ordinary boss semantics`. It retains the cut as `NativeFeatureDefinition`. This is honest unqualified retention and is not the completed parametric reader.

The narrow route is:

1. Extend the internal end owner with an explicit no-distance branch. `ReadEndMode` can identify type 1 only under the supported single/double-direction conditions. `ReadExtrude` must not call `RequireNative(f18)` or `ReadDepthOwner` on a null distance. Retain actual profile and support aliases.
2. Preserve no cut parameter. `ExtrudeOwner.DepthValue` currently requires a `DepthOwner`; use a tagged bound or an optional depth with checked callers. Reject spurious active distance owners and keep blind/mid-plane/two-length behavior unchanged.
3. Make the neutral boundary honest. `NativeOperation.length_mm` already permits absence, but `BuildExtrude` currently returns no definition when it is absent, and `ExtrudeFeature.length` is mandatory. The correct route needs an explicit absent length allowed for through-all, with blind lengths still required. Do not fill it from the stock, API placeholder depths, or an invented zero driving parameter. Existing ordinary JSON remains unchanged when its length is present.
4. Reuse the proven saved atom/chooser helpers independently of `CheckCutModes`' current blind-only assumptions. Keep the cold finite-pocket intersection code closed until separately justified.
5. Add the native rectangle's actual inactive rows and four unary relations through a keyed point/line projection. Keep array slot identity and preserved history separate from visible contour geometry; do not renumber references by dropping rows.
6. Only mark the complete history as admitted when both profiles, both operations, all native parameters, support, body dependency and actual configuration qualify together. Preserve existing unsupported diagnostics and normal part/assembly behavior outside this slice.

No source hooks are enabled here. Reverse, two-direction through-all, boss termination, nonprincipal supports, thin/draft/offset/reference variants and held-out generalization remain outside this one-design proof. New writer work still waits for the original native held-out source locks and a separate complete construction/prediction freeze.
