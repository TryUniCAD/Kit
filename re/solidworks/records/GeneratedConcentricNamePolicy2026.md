## Preference lease and recovery

The true branch performs no preference setters. Every false process independently captures actual original `true`, writes durable `Captured.json` and `Armed.json` before mutation, sets enum 18 to `false`, and verifies the actual readback before any document open. A `finally` restores the captured original and records its readback. The reused setter is documented `VT_VOID`; a Python `None` is expected and cannot substitute for the getter predicate.

Each false phase has its own recovery command and journal. Recovery requires that exact captured/armed original-true obligation and verified oracle identity, independently idle CAD processes and an unused output directory. It never opens a document, resumes the observation or saves anything. It does not require the native source files still to exist. Do not close foreign processes to satisfy recovery. A surviving process or missing journal is an explicit refusal.
