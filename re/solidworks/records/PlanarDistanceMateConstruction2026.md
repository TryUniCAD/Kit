# Ordinary aligned planar distance mate construction in SOLIDWORKS 2026

This proof covers one positive, driving distance between two resolved principal planes in a flat, unfrozen assembly. The admitted input has explicit alignment, no flip, no arc override, equal upper and lower API distance arguments, and an ordinary free occurrence opposite a fixed occurrence. It uses SOLIDWORKS 2026 SP05.2 build `34.5.2.0604`, archive version `19000`, the original licensed images and disclosed A18. All instruction addresses use the preferred image base.
