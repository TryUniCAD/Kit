## Field ownership

| Field | Rule in the measured profile |
| --- | --- |
| Active `f108` | The signed unit vector selected in the actual child's local coordinates. The new input supplies the two axes in ordered endpoint order. Each must be collinear with the actual generated cylinder carrier and both selections must agree on the same child-local direction. |
| Active and support `fd0` / `fe8` | The selected occurrence's proper rigid frame transforms the actual carrier anchor as a point and the requested local direction as a vector. Both endpoints retain the requested signed alignment and the actual ordered occurrence chains. |
| Active `f50,fb0,fb8` | The existing two-rim mode stores `f50=2`. One actual rim anchors the carrier. Plane and loop ownership supply the other physical rim. The first extent is zero. The other is the signed length of the actual rigidly placed rim displacement projected onto the active world axis. Both positive and negative represent a nonzero span. |
| Detached support | Its cylinder carries the same transformed point and direction as that endpoint. Its tuple remains the original `(-1,1,1,-1)` and it has no `f108` node. It retains the actual generated face, body atom and occurrence snapshot. The active cap rows still come from the generated child. |

The optional keyword argument is `endpoint_axes`. Without it, the same two local carrier axes and the existing positive-bound predicate produce the inherited bytes. The explicit branch refuses invalid axis counts, non-finite or non-unit coordinates, unrelated carrier vectors, opposing child-local directions, repeated occurrences, mismatched placement and inconsistent world alignment.
