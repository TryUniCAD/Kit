The ordinary generated blank opens, rebuilds and reaches `SaveAs3`, which returns `[false,1,0]`. This probe observes callbacks on the same generated blank and the disclosed seven-stream reduction. It uses the earlier save-mode observer and the exact inputs from that comparison. The reduced native lane and generated lane run at the same disposable input and output paths. A pristine blank brackets them. [Earlier save-mode comparison](../measurements/2026/GeneratedBlankDrawingSaveModes03.json) · [Shared save path](DrawingSaveBoundary2026.md)

The handler records event ordinals and relative monotonic times and returns zero. It requests no third-party storage. Both packets contain identical input files and eight identical support tools. ## Native measurement

Seven distinct pinned SOLIDWORKS processes completed the corrected-binding trial. All lanes opened with zero errors and warnings, rebuilt with their expected scale and matched the ten-row feature tree. The pristine brackets and reduced native lane each emitted `[7,9,28]`, saved with `[true,0,0]`, and reopened cleanly. The generated lane emitted `[7]` before returning `[false,1,0]` and left an empty target. [Measured receives and source hashes](../measurements/2026/DrawingBlankSaveEventsNative01.json)

Event 7 proves the generated save completed drawing preparation and reached `SolidStorage_c::iDoSave`. The first missing comparison events belong to the third-party storage callback stage. The remaining interval includes the rest of `iDoSave` before `OnSaveDocument`, the document and target-storage setup, and initial `SaveToStorage` work through document properties. The callback guard can also affect whether the later events fire. Entry to Definition serialization and commit remains unobserved for the generated lane. [Earlier return-edge analysis](DrawingContainerSaveFraming2026.md#shared-save-return-edges)

The executed observer compared a live save-status tuple with a list and marked the final result uninterpretable. The repository observer normalizes that comparison. Offline re-evaluation reproduced the original classification using tuples, then verified the corrected evaluation on both live-shaped tuples and JSON lists. Only the failure-reproduction flag, interpretability flag and stage classification changed. The receipt binds the raw native result and original observer SHA separately from the corrected source and evaluation SHAs. Both original packets and their native records remain immutable.
