## Why these sources

The exact retained FCStd inputs `C059-P01` (`73cd885c…`) and `C130-P01` (`d1f9225b…`) have four-line corner rectangles and one blind Pad. They also contain live expressions. C059 links the actual spreadsheet cell alias `Dimensions.w` to the named sketch width; C130 links `Pad.Length` to `Sketch.Constraints.width / 2`. Their pre-fix portable reads keep the source text but leave `Expression.parameter_ids` empty. Cached 30/40 mm widths and 10/20 mm depths are not substitutes for those dependencies. C059 also owns an authored spreadsheet text cell; proving native equations will not by itself preserve that entire sheet.

The existing SDK constructs an empty `moRelMgr_c` with the real part owner. The older [equation record](Equations.md) is explicitly a 2025 observation and does not license 2026 populated construction. The 2026 serialization map identifies relation, side, global-variable and dimension-wrapper classes; it does not classify their field values or establish native acceptance. The root agent independently owns that static 2026 continuation.

## Preference and recovery boundary

Only the owned author session temporarily disables the dimension prompt. It durably records the actual original toggle value and exact oracle identity before mutation, applies false, then restores the captured value in `finally` and reads it back. The native document setters are restricted to declared source authoring and the planned live edit. Fresh reopens and controls save no documents and write no preferences. `recover` requires this protocol's exact unfinished author journal, an idle oracle, an unused receipt and the original value from that journal. It starts only a new owned session, restores toggle 10 and verifies it without opening any CAD document. No process or license service is terminated.
