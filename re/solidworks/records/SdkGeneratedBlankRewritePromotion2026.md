# Canonical generated blank rewrite integration

The normal SDK and CLI regenerate an unchanged canonical SDK blank sheet at a new destination. Strict source decoding supplies the typed `BlankDrawInput` witness. Admission recreates all seven streams and verifies the original whole-file SHA-256 and native sheet ID. The writer then constructs all seven streams with a new self locator and save time. The source layout, presentation, history and model title are preserved. [Source and native custody](SdkGeneratedBlankRewritePromotion2026.json)

The original blank profile remains one unlinked ANSI A landscape sheet. Ordinary vendor-authored drawings, native-saved derivatives, model views, annotations and layout changes fail this rewrite admission. The metadata decoder accepts only known typed owners and only omits fields explicitly marked as nullable with a default of `None`. This preserves neutral documents serialized before the optional note field was introduced.

Two canonical SDK sources were locked before the rewrite and ran through four byte-identical guarded builds in pairs. The successful held-out retry reused those outputs across twelve fresh SOLIDWORKS 2026 SP05.2 processes. Both pristine control lifecycles passed. The observer compared thirty sheet states and 120 ordered feature rows across open, scale edit, native save and fresh reopen. [Held-out native receipt](../measurements/2026/BlankRewriteHeldoutNative01.json)

The final integrated source passed eight fresh processes on two disclosed sources through direct SDK, SDK via JSON, inferred CLI and explicit CLI. The four routes produced the same output SHA-256 for each source at the fixed destination and save event. Each output strictly reopened, the source stayed immutable, and guarded construction made zero runtime input reads. `Header2` and `Contents/Definition` changed. A separate negative confirms that note metadata prevents publication. The preceding pre-attestation observer and CLI expectation attempts are retained in the custody record.
