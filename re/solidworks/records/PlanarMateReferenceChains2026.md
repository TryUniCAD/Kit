## Native dispatch and wire rules

Their original image hashes, complete exception extents, chained fragments and vtable cells are in the evidence table. The 19000 owner tag is independent of that field. `setFiledOwner` at `0x4b836740` sets a filed-owner handle id at `+0x10`. Each disclosed component has a live assembly owner and still carries both chain fields. The chain stamp read starts at version `0x837`; the earlier load writes runtime `0xffffffff` instead.

The reference-chain owner-presence guard is an any-bit test. The bound `sldmfcu!0x3c7ac130` returns the condition word AND the supplied nonzero mask. In the masked store branch, the signed owner-presence value is 1 when chain runtime `+0x18` holds an owner and 0 otherwise. The matching load resolves it from the archive context. With current ordinary condition zero the reader recovers its owner from the helper and the optional word is absent. The older unmasked reader before `0x3b3` reads a model pointer first. The old pre-`0x144` non-mode-2 read can take a separate `moReference_c` object. The mode starts at `0x76` and the configuration pair at `0x8d2`. The feature-list loader before `0xf21` takes a framework `su_CObList` path. Those older branches retain their existing provisional status or explicit unmodeled rejection.

The 19000 schema selects the same operations as before from the verified version. Unverified versions explicitly pass through provisional schema owners, preserving previously admitted representations. Special conditions use the observed field gate. The scope of this proof is the wire structure of the ordinary object archive. Database serializers and the runtime effects of special conditions require separate qualification. The portable 19000 drawing rule output remains byte-identical.
