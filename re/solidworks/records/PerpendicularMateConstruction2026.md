## Narrow input boundary

Admission requires exactly two direct occurrences of one actual generated part definition, one explicit fixed anchor and exactly one nondimensional perpendicular mate. Each endpoint selects an actual principal datum from its occurrence. Proper rigid placement and independently orthogonal world normals are required. Different datum names do not establish orthogonality: equal-named planes can qualify under a measured relative rotation, while different names with nonorthogonal placements fail.

Scalar distances, explicit alignment variants, extra perpendicular or mixed groups, expanded occurrence groups, different child definitions and nonprincipal/face/axis references remain closed. Existing coincident, parallel, distance, ordered, repeated and nested routes retain their previous bytes. The public compiler/registry is unchanged.

The constructor preserves explicit semantic endpoint order. D02 proves that the native UI's selection-call order can differ from the stored order; the implementation does not introduce an ID sort fitted to that observation. A native trial must preserve or report the actual ordered owner result.
