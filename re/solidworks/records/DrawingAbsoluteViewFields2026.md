# SOLIDWORKS 2026 ordinary absolute drawing view fields

`DrawingFrontRecordProcess.py` builds a complete `moAbsoluteView` for one named, explicitly 1:1 `*Front` view of a generated forward blind rectangular boss. It adds the view to the actual unformatted ANSI A sheet. The shared part, projection, link and support constructors supply the authored fields and object identities. The process serializes the entire drawing `Contents/Definition` and a separate `Header2` through their normal version-19000 archive roots. ## Process evidence

```sh
uv run --isolated --frozen --extra dev --python 3.11 python -B \
  re/tooling/sw2026/DrawingFrontRecordProcess.py < /private/authored-front-view.json
```

The request shape is the same as the [front projection and support process](DrawingFrontViewConstruction2026.md). The guard allows source imports before construction and rejects file reads and subprocess launches during the build. Output is a JSON receipt. The SDK's typed Definition walk joins the generated native placement and model reference to a one-view layout constructed from the same authored sheet metadata. The complete drawing metadata and public `open_document` path require the later package trial.

Two requests varied the names, sheet position and generated prism dimensions. Each 28,566-byte Definition and 919-byte Header2 round-tripped exactly, including a 4,153-byte `moAbsoluteView` record with 151 admitted fields. The next Definition map index was 172 and the next persistent ID was 16. A third request with longer authored view and configuration names grew the view record to 4,281 bytes and Definition to 28,760 bytes while retaining the object count. All three produced identical receipts on immediate independent replay and zero runtime input reads. Independent arithmetic verified the transform and outline. Requests for another orientation or scale, an unclassified view property and an empty support name failed before producing a report.

The independently locked disclosed D01 and D02 drawings were read only for comparison. Their whole Definitions, Header2 and 4,502-byte view records decoded with exact extent. Each disclosed Definition and Header2 re-encoded byte-identically. Each view had 152 fields, with one extra typed sketch-cache field present. Both agreed with the factory and projection observations in the receipt. The control bodies and report details for the held-out drawings stayed sealed.
