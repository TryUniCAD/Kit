## Constraints and datums

Every source row is retained in order: four endpoint coincidences, four horizontal/vertical line rules, one root-point coincidence and two line-length drivers. The portable root-point row currently has one local reference; its actual native slot metadata also contains `(-1,1)`. The official [FreeCAD 0.21.2 GeoEnum source](https://raw.githubusercontent.com/FreeCAD/FreeCAD/0.21.2/src/Mod/Sketcher/App/GeoEnum.h) defines that pair as the sketch root point. This supplies an actual owner without guessing from coincident coordinates. It remains a missing typed reference in this pre-fix portable read.

The official [0.21.2 Sketch distance branch](https://raw.githubusercontent.com/FreeCAD/FreeCAD/0.21.2/src/Mod/Sketcher/App/Sketch.cpp) treats Type 6 with one line and undefined second geometry as line length. The current SDK `MakeRectValue` creates `sgPntPntDist` with actual endpoint handles, providing a reusable geometric owner. The four explicit coincidence rows need a separate preservation argument: the qualified anchored SDK rectangle instead shares endpoints and has seven native relation rows. Equal present geometry does not license silently deleting those source constraints. [Pinned public-source identities](../measurements/2026/FcstdRectanglePublicSourcePins01.json)

All three source datum frames numerically match the existing `PrincipalFrame` formulas: XY-plane → Front, XZ-plane → Top and YZ-plane → Right. Actual IDs, names and full transforms remain in the envelope; matching a native role does not rename or discard the source datum. This is geometric role correlation, not a wire identity claim.
