The two disclosed SDK-generated rectangle parts pass ordinary native load, rebuild, independent width/height edits, save and fresh reopen. All original generated bytes are unchanged. Existing authored C paths are admitted only through the pinned previous packet/result plus exact candidate hash and size.

This failure is not attributed to the native file format. The successful retry proves the corrected identity path for these measured relation entities. It does not prove every possible COM default interface or arbitrary relation kind.
