Let U be its unsigned explicit ID argument and C the module-static u32 at 0x4415bc10.

- If U != 0, the assigned auxiliary ID is U and this function leaves C unchanged
- Otherwise it assigns the old C and then stores (C+1) mod 2^32
- The original image initializes C=1; this is an image seed, not a promise that the next modeled face receives one
- Both enabled-new-ID and legacy-pointer branches use that allocator
- In the new-ID path, integer field three starts with that auxiliary ID, followed by converted external-model references; an actual null local-model reference contributes zero

No universal session reset, overflow acceptance, atomicity, face allocation order, or full-file ID sequence is inferred.
