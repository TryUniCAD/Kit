## Minimal independent intent

Each slot contains one active unformatted ANSI A landscape sheet, width `11×0.0254 m`, height `8.5×0.0254 m`, no model views and no model references. The guest privately chooses an ordinary ASCII sheet name and a reduced positive integral scale ratio. Slot01 initially reduces the view scale and later enlarges it; Slot02 initially enlarges it and later reduces it. The two ratios in each slot are selected independently within the declared ordinary range. Every choice, including the edit target, is sealed before a native source is authored.

`BlankDrawingPrivate` generates those values only under a Windows guest guard, with OS entropy, exclusive file creation and an independent custody nonce. No concrete slot value, seed, native file or detailed observation is materialized on the host. Host-visible output contains opaque slot IDs, hashes, process identities and phase status only. Failure text and raw API arguments stay in guest-local private records.

The portable shape contract is `DrawingData(ActiveSheetId, Sheets, ModelRefs=())` with one `DrawingSheet(EntityId, EntityName, SheetWidth, SheetHeight, ScaleRatio, Views=())`. The ID is an authored neutral identity, not a captured native object number. These fields suffice for the sheet layout. Complete native construction also requires explicit `DrawDocOptions`, UI settings, header/history provenance and self-file identity. Default units, drafting standard, folder/support names, summary/custom text, native presentation and provenance cannot be silently dropped or inferred from a matching sheet cache. A future compiler must preserve them or reject their unsupported source owners.

## Frozen source method

`BlankDrawingSourceSlots.py prepare` creates an unused external packet with eight checksum-bound research tools, the exact disclosed pristine drawing control and a serial recipe. The installed `.DRWDOT` is only a corpus-authoring prerequisite; it is hash checked in the guest and never supplied to a Kit writer. The exact 2026 oracle remains SHA-256 `3f6844591c7456a476bdc141817a21c3c10f770e12347a698eef5ea8ad60d1fe`, version `34.5.2.0604`.

Run guest `verify`, then the no-CAD `metadata` phase. It checks the actual registered `ISheet` members and argument counts on type library 34.0, and the installed template identity. [`ISheet`](https://help.solidworks.com/2026/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ISheet_members.html) supplies the native name/scale operations. The actual registered metadata and fresh readback remain authoritative. In particular, `SetName` success is established by reading the actual name back rather than assuming a Boolean return convention.

After committing the independently authored tools, execute each slot independently:

| Step     | Native process | Required observation                                                                                                                                                                                                                          |
| -------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `seal`   | None           | Guest-local intent and edit target fixed; publish only their hash                                                                                                                                                                             |
| `before` | Fresh          | Exact pristine drawing opens as document kind 3, rebuilds cleanly and has a live sheet/tree                                                                                                                                                   |
| `author` | Fresh          | Create from the pinned native drawing template; set the real sheet name and scale, require no sheet format/model view, check all eight sheet properties and the complete ten-row tree, rebuild and save the original source with `[true,0,0]` |
| `edit`   | Fresh          | Open the immutable source with `0/0`; check original intent/tree, edit the actual sheet scale, rebuild, verify the independent target and save a distinct derivative with `[true,0,0]`                                                        |
| `reopen` | Fresh          | Open the derivative with `0/0`, rebuild and verify the same full tree and edited sheet properties                                                                                                                                             |
| `after`  | Fresh          | Independently repeat the pristine control, retaining a failed candidate rather than suppressing its outcome                                                                                                                                   |
| `lock`   | None           | Rehash original, derivative and intent; require all five phases, distinct process births, serial order and both controls; publish hashes only                                                                                                 |

Always run the independent `after` control after a native phase failure. Do not run dependent author/edit/reopen phases after their prerequisite fails. A malformed/missing earlier record must not prevent the trailing control. Preserve a failed phase and use a separately frozen retry rather than overwrite it.

The wrapper reuses `AuthorDrawingSources.make_drawing`, native sheet snapshots and `InspectDrawingCache.phase`. `InspectDrawingCache.phase` adds one optional `edited_ratio` argument, preserving its existing `(3,2)` default and all old callers. `InspectSdkBlankDrawing` remains the separate existing generated-output observer. Source authorship never imports a production constructor.

The whole pair needs ten independent native processes and four healthy pristine controls. This is legitimate blank-sheet intent: three-dimensional body/mass counts are not used as a part acceptance substitute. The live sheet, complete tree, paper, ratio, warning state and actual scale edit/save/reopen are the applicable drawing observations. This does not qualify linked views or broader drawing content.
