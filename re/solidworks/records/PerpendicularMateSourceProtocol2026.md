## Source phases and live-edit limit

Each case has independent `before`, `author`, `reopen-source`, `reopen-edited`, `after` and `lock` commands. Five distinct native process creation identities and healthy bracketing controls are required. Root must execute the trailing control independently even if a source phase times out or fails. Each phase writes progress before native activation; the prescribed source-phase wall-clock limit is 480 seconds, with a separate 240-second control budget. The runner never terminates foreign CAD or license processes.

The author phase first saves the synchronized baseline child and parent. It then requests a separately predicted, already valid reorientation of the floating occurrence about the fixed endpoint's world normal through `SetTransformAndSolve2`, and changes the child's driving extrusion depth. It requires the exact requested rigid pose and independent geometry, then saves a separate edited child/parent pair. The original pair must remain hash-identical. Separate fresh processes reopen/rebuild each pair and check full tree, IDs, endpoint order, configuration, pose, editable child dimensions, geometry and immutable hashes.

A perpendicular mate has no driving scalar in this bounded profile. The valid reorientation measures real native pose editing while maintaining orthogonality; it does **not** prove correction of an invalid angular start or a deterministic solution for the remaining free degrees of freedom. A subsequent separately frozen off-orthogonal probe must measure that behavior. There is no promise that every perpendicular selection admits the same alignment, auxiliary data, reference subtype or solver state.
