## Frozen order

1. Commit and independently verify the final writer source closure, ordinary registry route, neutral mapper, explicit document options, fixed writer epoch, runtime audit and native observer closure. Create an exclusive `MethodBinding.json` with the schema below and this comparator's exact hash. No private intent or source payload has been read at that point.
2. Only root may release each neutral intent inside the guest. `predict` first validates the method binding, every attached hash and the original public source lock, then requires Windows before reading the exact locked intent. Its private prediction contains the complete stock tree, initial eight sheet properties and the independently sealed edit target.
3. Through the normal public writer, build each slot twice in fresh guarded processes: once by extension and once as explicit `solidworks.slddrw`. Use the same actual target path, explicit options and epoch. Retain separate immutable output copies, equal byte hashes, empty dropped semantics, zero model/template file reads, no CAD calls, and actual atomic-write/no-overwrite proof. Verify the complete frozen source closure independently, not only its manifest's hash.
4. Freeze one `GenerationFreeze.json` binding **both** slot predictions and all four output copies. Only after that digest is fixed may root attach/open the original native sources, saved originals or detailed source observations. The comparator validates all predictions and generated payloads before it reads any native observation record.
5. Reuse the frozen `InspectDrawingCache.phase` observer. Run the exact serial 12-phase order in the JSON protocol. Each source and generated input must open/rebuild without errors or warnings, accept its independent scale edit, save to a distinct derivative with `[true,0,0]`, and reopen/rebuild in a fresh process. Complete D00 edit/save/reopen brackets run before and after; always attempt the independent trailing bracket after a failure.
6. Freeze the observation descriptor file and its digest. Run `compare`. It requires all 12 unique native process births, exact serial intervals, original and derivative identity, healthy cleanup and immutable sources. It compares all 30 sheet snapshots and 120 complete ordered tree rows. Discrete sheet properties and names/types/parents are exact; only width/height permit absolute numerical error of `1e-12 m`, with no relative allowance.

The stock eight-property prediction is `[0,13,numerator,denominator,0,width,height,1]`. Width is `11*0.0254 m`; height is `8.5*0.0254 m`, preserving the typed binary-double construction rather than substituting the rounded decimal property text. Scale terms remain separately exact, not normalized from observations. The paper [decimal gotcha](../../../Documentation/Gotchas/Conversion/Solidworks/Drawings/Qualification/SheetPropertyDecimalsCanRoundNativeDoubles.md) remains applicable.

## Minimal contracts and invocation

The JSON protocol defines the required file descriptors and field names. Every descriptor is `{path: <absolute ordinary file>, sha256: <exact digest>}`. Output paths are unused files created exclusively. Private predictions and raw native records remain guest-local. Standard output contains only status, digest and error type, never a private sheet name, ratio, nonce or path.

```sh
python -B BlankDrawingComparison01.py predict --binding /absolute/MethodBinding.json --binding-sha256 BINDING_SHA --intent /absolute/private/Slot01/Intent.json --slot Slot01 --output /absolute/private/Prediction01.json
python -B BlankDrawingComparison01.py compare --binding /absolute/MethodBinding.json --binding-sha256 BINDING_SHA --generation /absolute/private/GenerationFreeze.json --generation-sha256 GENERATION_SHA --observations /absolute/private/Observations.json --observations-sha256 OBSERVATIONS_SHA --output /absolute/private/Comparison.json
```

Use actual guest absolute paths for guest execution. The protocol deliberately supplies no unseal command and never opens native source payloads. The source closure verification receipt is root-produced; the comparator pins and validates its declared identity, but does not replace the complete source-file verifier or runtime audit.

## Scope and verification

A passing result establishes the compared blank sheet/tree lifecycle only. It explicitly emits `full_source_semantics_qualified=false` and `public_writer_acceptance_claim=false`. Native template settings, style/font/unit owners, summary/custom text, history/provenance and external references need their own exact inventory and preservation/refusal decision; stock sheet parity cannot remove that obligation. This method does not qualify model views, linked children, annotations, non-stock folders or other drawings.

This handoff contains independently authored research code, source hashes and documented vocabulary only. Static AST/compilation, unresolved-name and whitespace checks are recorded separately. No product/integration tests, new writer build, private intent read, native source read, COM launch or blind comparison was executed by this lane. Root must bind and verify the final public writer before using this method.
