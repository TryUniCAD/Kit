# Native lifecycle of an SDK-only blind-boss part

The generated SDK file for the disclosed `sdk plain alpha` design contains
ten independent streams in an 8,166-byte container. Two guarded builds from
the same neutral 24 by 16 mm rectangle produce identical bytes with no
runtime input reads. The [construction record](SdkBlindPartConstruction2026.md)
binds the full independent process closure.

The first trial used the correct candidate and an observer that predicted
the control's environment caption. The actual native caption is the
authored `Environment`. The native boss also exposes the From-support
plane as a second parent. Both healthy controls bracketed the failed
observer decision. The original open independently showed one solid,
zero load diagnostics, the requested configuration and a live depth.

The second trial derives all 25 expected COM rows from the neutral
presentation, retains the prior input bytes, and checks both parent
chains. The four clean processes bracket a generated edit and its fresh
reopen. The initial solid is already present before `ForceRebuild3`.
The measurement uses a relative tolerance of `2e-7`, an absolute
tolerance of `1e-16` in SI units for area and volume, and `1e-12 m` for
coordinates and lengths.

| Native state | Depth in mm | Volume in m³ | Area in m² | Centroid Z in m |
| --- | ---: | ---: | ---: | ---: |
| Initial and rebuilt | 12.75 | 0.000004896 | 0.001788 | 0.006375 |
| Edited and freshly reopened | 16.625 | 0.000006384 | 0.002098 | 0.0083125 |

The native edit returns success, the save reports no errors or warnings,
and the fresh process retains all 25 tree rows and the edited parameter.
Both controls pass. The license process inventory is unchanged. The
[sanitized receipt](../measurements/2026/SdkBlindPartNative01.json)
records both trials, phase hashes, build identity, all stream digests and
110 numeric comparisons. No native input was used to build the part.

The strict public SDK read of each file reports a typed `D1` and one
body with B-rep and tessellation disabled. Its feature timeline has 19
rows on the generated file and 27 on the native save. The public history
projection still needs to reconcile nested native tree items and non-tree
records. The disclosed lifecycle does not qualify the original held-outs,
the public writer or the production corpus.
