# Measured principal offset-plane delivery

Task `B04-SW2026-REFPLANES` in PR #121. The root integration owns the normal SDK
routes and Windows evidence. The scope is a principal offset datum with its
own editable D1, a centred radius-driven circle, and a forward blind boss
with an independent editable D1. The signed offset definition and positive
driver use explicit millimetre or metre units. Portable placement stays
in millimetres. Authored metre inputs retain their exact binary64 value.

The constructor creates the ordered principal system, Origin, offset
feature, radial sketch and boss through the shared archive and container.
The datum data owns its real local reference and distance display.
The sketch transform and radial placement derive from the translated frame.
The reader checks the complete linked inventory, actual selection and
driver identities before returning editable history or analytic geometry.

## Native evidence

The [disclosed cohort](../measurements/2026/ReferencePlaneBlindMethod01.json)
has three native-tested designs across Front, reversed Top and Right
supports. Each had both bracket controls, a clean open, a driving-distance
edit, a rebuild, a save and a fresh reopen. Twelve distinct processes
passed 243 numeric checks and retained all 26 native feature-tree rows.
The two [original held-outs](../measurements/2026/ReferencePlaneOriginalHeldouts01.json)
were locked before their writer. Eight fresh native processes passed 162
checks, including both independent distance edits and reopens.

The pinned Windows SDK replay uses the original two guest-local authored
requests and their original self locators and epochs. It verifies the source
freeze before sending each request to guarded workers and publishes only
opaque slot IDs, digests and verdicts. The separate Windows D03 disclosed
artifact first verifies the historical runtime computation.
Its variant uses ordinary platform half-angle trigonometry. The stable
default uses the shared deterministic series. Both generate Config-0
through the same typed owners. The [runtime coefficient note](../../../Documentation/Gotchas/Conversion/Solidworks/Archive/Configuration/ConfigViewCoefficientsVaryByRuntime.md)
records the eight differing near-zero values.

The [aggregate receipt](../measurements/2026/AggregateOffsetDatumDelivery01.json)
binds the exact SDK revision, six previously native-tested artifacts,
the guarded process checks and the normal registry, direct writer and
adapter stream routes. Each route regenerates the archive from authored
or JSON-restored neutral geometry and explicit presentation. Missing,
changed or mismatched receipts and settings are refused before publication.
The Windows compare stages launch no native CAD process. The new proof is
a reproduction of the original qualified native artifacts. The two
separately frozen SDK default candidates still await a native lifecycle.
This result contributes no original FCStd benchmark entries.

takes the authenticated original method directory, the Windows D03

hashed Windows-local source closure through the established Parallels
transport. The opaque requests and detailed worker results stay in
guest custody.
