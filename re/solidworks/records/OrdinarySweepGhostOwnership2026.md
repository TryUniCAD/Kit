`moSweep_c::initialize` calls the actual Section array setter at `0x4cb46258` and Path contact setter at `0x4cb46263`. The Section setter hands the copy to the embedded array at `+0x2c0`. The parent init passes the actual submitted state to the embedded helper at `0x4cb4656f`. The Section, Path and guide arrays have separate lookup methods. The `f274` and `f2ac` fields start at 1 in `moSweepData_c`'s constructor and are zero in every audited new save. The initializer therefore overrides those defaults. `f7c/f80` come from two adjacent words of one direction parameter and control the optional direction-spec branches. The accepted disclosed Standard case passes both zero. The reported COM Standard mode and lack of guide, thin, twist and alternate alignment owners qualify an observation. The mapping of each independent COM property to the private arguments and production-safe values of all outer `fc*` words remain open.

Path `moGeneralCurveRef_w.f08=101` and `f0c=-1` match the native shared constructor at `0x4c30839b` and `0x4c3083a2` for every edit state.
