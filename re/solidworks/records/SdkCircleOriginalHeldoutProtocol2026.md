## Neutral semantic mapping

The input vocabulary comes from the original source author and the SDK's typed neutral model. Only one ordinary circle, fixed local center, one positive primary depth, canonical Front/Top/Right support, radius/diameter driving intent and the three proved ordinary boss end modes are admitted. `radial` normalizes to the neutral `radius` spelling. Unsupported profile geometry, extra construction geometry, additional unclassified source fields, unknown owners or active terminations fail explicitly. [Vocabulary gotcha](../../../Documentation/Gotchas/Conversion/Solidworks/Oracle/NativeRadialUsesRadiusInput.md)

The projection preserves the authored local center/radius, support basis, depth, reversal, active second depth, radial vs diameter parameter and original edit target/factor. It creates a real `CadDocument` with an explicit `Default` configuration and the source author's `CurveSketch`/`CurveBoss` names. The stock English configuration is an explicit evaluation input and a strict native comparison requirement, not a captured writer default. All system folders, principal names, cabinet and origin predictions come from the writer's actual typed system input; the 25-row tree follows the established ordinary native owner rules.

The geometry predictor independently computes the cylinder's axial interval, volume, surface area, centroid and six world-coordinate extremes from its basis, local center, radius and active depth lengths. Reverse and mid-plane cases use their actual signed intervals. It does not call the generator's analytic helper or use native output to set expected values.

Four fresh neutral qualification designs cover translated diameter, reversed Top radius, mid-plane Right diameter and reversed two directions. Each passes two equal guarded builds, complete ten-stream typed preparation and a fresh public SDK read. All 16 processes pass with zero runtime input-file reads or production research imports. These new designs are discovery qualification inputs, not retroactively pre-writer held-outs.
