## Separate kilogram-mass observation

The lifecycle's independent geometric checks cover volume, area and centre of
mass. They do not independently qualify kilogram mass. The
[separate API receipt](../measurements/2026/SdkOrderedAssemblyMassApi01.json)
retains every measured parent and child mass across the nine native snapshots.
Both A22 brackets report parent mass `0.016000000000000004` kg and child mass
`0.000008000000000000001` kg. Their parent-to-two-children ratio is
`1000.0000000000001`. The generated and fresh-reopened pair report
`0.029508984375000002` kg and `0.000014754492187500002` kg respectively,
with ratio `1000.0`.

Dividing each observed mass by its observed volume yields assembly API density
approximately 1000 kg/m³ and child API density 1 kg/m³ in both lanes. This
shared API behavior is not evidence of a generated-only defect. It also does
not establish full kilogram-mass parity between independently different
designs. The related
[unassigned-part density distinction](../../../Documentation/Gotchas/Conversion/Solidworks/Oracle/Parts/DefaultPartDensityHasTwoOwners.md)
separates the stored document preference from effective body density; this
ordered trial did not query that preference. Material assignment and density
override qualification remain outside this fixture's measured acceptance.
