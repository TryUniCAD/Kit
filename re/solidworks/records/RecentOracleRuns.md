# Recent SOLIDWORKS oracle runs

SOLIDWORKS Design Premium 2026 SP5.2, Parallels Windows 11, 2026-11-14.

The host share `\\Mac\Home` is mapped to `Z:` in the guest. Generated files were written to
`Z:\Documents\UniCAD\Kit-solidworks-native\.rescratch\polyline`.

## Additive box

`OracleBox.SLDPRT` was generated from
`re/solidworks/examples/FreeCAD/AdditiveBox-1.1.4.FCStd` through
`write_document(..., allow_carrier=False)`. `OracleDrive.vbs` edited `D1@Boss-Extrude1` to
13 mm, rebuilt, and measured:

```
EDITED_REBUILT=True
EDITED_DEPTH_PARAMETER=13
EDITED_VOLUME_MM3=7800
EDITED_AREA_MM2=2500
```

Expected for 20 x 30 x 13: volume 7800 mm3, area 2*600 + 2*(20+30)\*13 = 2500 mm2.

## Rewritten V8 part

`OracleV8Part.SLDPRT` was generated by reading
`re/solidworks/examples/Single Turbo Dual Overhead Cam V8 - KDP - 2024/BLOQUE V8.SLDPRT`
and writing it with `allow_carrier=False` (`native-exact`, 736673 bytes). `OracleOpen.vbs`
reported:

```
OPENED=True REBUILT=True BODIES=1 TITLE=OracleV8Part
```

Three more rewritten V8 parts were opened individually with the same script:

```
part001 (socket head screw) OPENED=True REBUILT=True BODIES=1
part010 (connecting rod)    OPENED=True REBUILT=True BODIES=1
part015 (crankshaft)        OPENED=True REBUILT=True BODIES=1
```

## Triangle depth edit

`OracleTriangle.SLDPRT` was generated from a three-line 42 x 31 triangle with 13 mm depth.
`OracleDrive.vbs` edited `D1@Boss-Extrude1` to 13 mm, rebuilt, and measured:

```
EDITED_REBUILT=True
EDITED_DEPTH_PARAMETER=13
EDITED_VOLUME_MM3=8463
EDITED_AREA_MM2=2840.95104346666
```

Expected: volume 0.5*42*31\*13 = 8463 mm3.
