## Explicit neutral admission

`make_candidate(document, settings)` receives a real neutral `CadDocument` and explicit `PartBuildInput`. The document must contain one active independent configuration, canonical Front support at the model origin, one sketch, one angular boss, one driving `D1` parameter in radians, one actual axis selection and one default body. The sketch has an axis-aligned four-line rectangle strictly to the right of one upward construction line. The four perimeter lines retain their actual unary horizontal/vertical relations; the axis has no fixed, coincident or dimensional relation.

The angular operation is one-sided, with `1e-8 < angle <= 2π`. Its normalized neutral axis direction is positive Y for the forward sweep and negative Y for reverse. The selected source line retains its ordered upward endpoints in both cases. Cross-sketch axes, arbitrary supports, cuts, thin mode, second ends, expressions, tolerances, additional feature/configuration domains, materials, property bags and custom body labels are not admitted.

The constructor emits no partition, delta, tessellation or visual-state stream. Its independent validation B-rep is never attached to the generated file. Every output container, directory, object tag, map, ID and stream length comes from the generated objects and existing codecs.
