## First source lock

Run [AuthorDrawingSources.py](../../tooling/sw2026/AuthorDrawingSources.py) in the pinned VM from the oracle owner's macOS controller. Supply a new output directory outside the checkout, the known-good independent native part control, the generated single-solid `.SLDPRT` and the installed drawing template. Hash all three inputs and the job specification. Choose a drawing template with one named sheet, zero model views and enough paper area for the requested locations. Sheet-format geometry and template properties are part of the native source to inventory. Paper size `0` selects ANSI A landscape. [NewDocument](https://help.solidworks.com/2020/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.ISldWorks~NewDocument.html), [Paper size enumeration](https://help.solidworks.com/2025/english/api/swconst/SolidWorks.Interop.swconst~SolidWorks.Interop.swconst.swDwgPaperSizes_e.html?id=2.10.1.313)

```text
python AuthorDrawingSources.py <absolute-job.json>
```

Use `kit.sw2026.drawing-source-job.v1` with `source_revision`, `oracle_sha256`, `checkout_root`, `output`, `paper_size`, `specs`, `specs_sha256`, `control`, `control_sha256`, `template`, `template_sha256`, `reference_part`, and `reference_part_sha256`. The [public specification](../../tooling/sw2026/DrawingSourceSpecs01.json) defines `D00EmptySheet`, `D01FrontView`, and `D02MovedFrontView`. Before writer work, make a private specification with those discovery cases and two distinct `heldout` model-view layouts. The private specification keeps orientation, scale, and position targets sealed. Only publish the sanitized lock with the case names, source digests, phase receipt digests, and pass counts. Keep source files and detailed private receipts outside the checkout until the writer revision is frozen.

The author opens a private byte-identical copy of the generated part read-only. It creates the drawing with `NewDocument` and its optional model view with `CreateDrawViewFromModelView3`, then measures the requested scale and view position through a typed `IView`. Native traversal starts at the sheet sentinel and advances once before counting actual model views. The author saves `.SLDDRW` via `SaveAs3` and reopens it read-only in a fresh process with explicit drawing document type `3`. Both phases require zero native errors, warnings, modal dialogs, and rebuild issues. The model view must resolve the precise reference path and configuration, expose a nonempty outline, and preserve the native model-to-view transform and child geometry across reopen. The reopen phase moves the view by an asymmetric offset, rebuilds, and measures the corresponding outline translation in memory. The native drawing and child hashes must stay stable. [CreateDrawViewFromModelView3](https://help.solidworks.com/2020/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IDrawingDoc~CreateDrawViewFromModelView3.html), [GetFirstView](https://help.solidworks.com/2024/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IDrawingDoc~GetFirstView.html), [View Position](https://help.solidworks.com/2023/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IView~Position.html), [GetSheetProperties2](https://help.solidworks.com/2018/english/api/sldworksapi/solidworks.interop.sldworks~solidworks.interop.sldworks.isheet~getproperties2.html)

The disclosure-only job plans eight fresh processes. Adding two private cases makes twelve. Two native part controls bracket all drawing phases. Each run records application creation identity and the executable hash. `PrivateInspection.json` and per-phase `Record.json` contain API outputs. `SourceLock.json` reports its source qualification, zero Kit writer output, and false native and held-out writer acceptance. CLI import and public specification validation passed on macOS. The pinned VM run is pending.

## Correlation and portability

1. Inventory the container header and named streams from each disclosed drawing, then identify typed `Contents/Definition` roots and their map context. Confirm the root discriminator against both part and assembly controls.
2. Classify paper, sheet scale, projection convention, attached model and configuration, view kind, orientation, position and scale as authored inputs or derived values. Then correlate the empty, front and moved-front controls to establish field order, conditional types, map bases and generated identifiers. Record projection polylines, external-reference state, thumbnails, duplicated positions, and view cache bytes with their actual owner and lifecycle.
3. Require exact decoding and re-encoding of every load-critical stream with no opaque tail. Prove any omissions or computed neutral values on controlled vendor opens. An editable drawing requires parametric sheet and view records and the correct attached model. Cache geometry alone is insufficient.
4. Qualify multi-sheet ownership, additional reference models, projected/section/detail views, native dimensions, tables, annotations, and sheet formats through controlled family additions. Each family needs a source lock and independent edit/rebuild verification. The first cohort covers one sheet and one ordinary part view.
5. Keep each release's executable and serializer-map pins, archive and container versions, keywords, and reference resolution context separate. A release port must reverify drawing root guards and drawing-only streams alongside the shared model core. [Adjacent release qualification](AdjacentReleaseQualification.md)
