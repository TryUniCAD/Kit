# Ordinary revolved boss construction on SOLIDWORKS 2026

This record covers a one-direction blind revolved boss with one closed planar profile and an axis supplied by a straight construction segment in that profile's sketch. The construction path and the references it requires have pinned static evidence. Full-turn mode and dimension exposure, a saved source cohort, final field classification, fresh Kit generation, and application acceptance are pending.

## Source and acceptance sequence

The tracked `v2026/heldout` inventory contains no identified immutable ordinary revolved boss cohort. Run discovery authoring and privately freeze held-out sources before writing this family's generator. The existing [`Author.py`](../../tooling/sw2026/Author.py) supports implicit single-sketch axis inference. The installed API documents explicit profile mark `0` and axis marks `4` and `16`, with `EXTSKETCHSEGMENT` selected under mark `4` in the [2026 revolve authoring example](https://help.solidworks.com/2026/english/api/sldworksapi/Create_Revolve_Features_Example_VBNET.htm). The first source cohort uses three discovery requests: a full turn, a partial turn, and the same partial turn with reverse direction. Author two additional held-out cases with independent radial intervals, axial intervals, centerline positions and lengths, and partial angles. Keep the specification and authored files of those cases sealed. Calls to `FeatureRevolve2` use `SingleDir = true`, `IsSolid = true`, `IsThin = false`, `IsCut = false`, `ReverseDir` from the request, `BothDirectionUpToSameEntity = false`, `Dir1Type = Dir2Type = 0`, `Dir1Angle` in radians, and `Dir2Angle = 0`. The source tool passes zero for inactive offset distances so constructor defaults can be distinguished from those arguments. Offset reversal and thin mode are disabled. Verify axis mark/type before creation and match reopened axis endpoints and owner. This freeze gives partial-turn cases the required held-out coverage. Full-turn acceptance has its own pending lock and dimension proof.

For an annular sector with radial interval `[ri, ro]`, height `h`, and sweep magnitude `theta`, expected volume is `h * theta * (ro² - ri²) / 2`. Area is `h * theta * (ri + ro) + theta * (ro² - ri²)` plus `2 * h * (ro - ri)` for a strictly partial sweep. Its centroid lies at the axial midpoint. In a signed plane basis with the radial vector along the initial ray and the transverse vector along positive rotation, the two centroid coefficients are `(sin(theta), 1 - cos(theta)) * 2 * (ro³ - ri³) / (3 * theta * (ro² - ri²))`, with the transverse coefficient negated for the reverse sweep. Apply the measured sketch-to-model frame and translated axis origin to obtain global coordinates.

The VM owner can run [`AuthorRevolveSources.py`](../../tooling/sw2026/AuthorRevolveSources.py) with the private `job.json` as its only argument. The job keys are `schema` (`kit.sw2026.ordinary-revolve-job.v1`), `source_revision`, `checkout_root`, `specs`, `specs_sha256`, `control`, `control_sha256`, `oracle_sha256`, and `output`. Supply absolute paths to a hashed private specification and known healthy native control and choose an unused output directory. The private specification has schema `kit.sw2026.ordinary-revolve-specs.v1` and a `cases` array. Each case supplies `name`, `split`, `plane` (`front`, `top`, or `right`), `radius_m`, `axial_m`, `axis_x_m`, `axis_axial_m`, `angle_deg`, `reverse`, and `edit_angle_deg`. Each interval holds its lower and upper endpoints. The source tool takes no input from existing donor part records.

The tool authors and reopens every source in its own SOLIDWORKS process, surrounds the ten source launches with two pinned controls, and writes private phase records. Each phase records feature tree, warnings and errors, axis selection, dimension readback, one-body mass properties, and handedness relative to the selected endpoints. On reopen it resolves and temporarily enables the document's `swDisplayFeatureDimensions` setting through the registered 2026 type library. It edits the driving angular display in memory for partial turns, rebuilds, and confirms the corresponding geometry. It restores the setting and verifies the frozen source digest is unchanged. When a full-turn angular display is unavailable, it records that separately from source health. The final `SourceLock.json` contains standalone file hashes and lengths, provenance, phase receipt digests, and separate explicit acceptance fields.
