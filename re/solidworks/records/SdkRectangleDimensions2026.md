## Neutral admission

[MakeRectDimPart](../../../src/convert/adapters/solidworks/Archive/Construction/Part/MakeRectDimPart.py) is a separate internal entry. It accepts a real `CadDocument`, existing `PartBuildInput` and explicit [RectDimInput](../../../src/convert/adapters/solidworks/Archive/Construction/SketchDimensions/RectDimInput.py).

The neutral document must contain the existing one-configuration, origin Front Plane, one-body, one-forward-blind-create-boss profile. Its only added semantic state is:

- Sketch-owned driving `D1` width and `D2` height, without expressions or extra attributes.
- Boss-owned driving `D1` depth, unchanged from the existing plain route.
- Four active unary relations, each bound to its actual line entity: horizontal, vertical, horizontal, vertical.
- Two active distance relations, bound respectively to edge zero start/end and edge one start/end, with the actual width/height parameter IDs.

The ordered four-line loop starts at the lower-left corner and runs counterclockwise along positive X and positive Y. Every relation, parameter and endpoint reference is checked before reusing the existing plain geometry projection. The projector temporarily removes only these already-validated sketch semantics from its immutable view; the actual output graph then constructs all six relations. It rejects extra/missing, suppressed, driven, mismatched or extended relations.

Parameter lengths must agree with the input geometry after conversion to metres. The equality guard allows `rel_tol=1e-12` and `abs_tol=1e-14` for coordinate/unit arithmetic; it does not fit a native observation. The emitted driver values come from actual endpoint differences.

Text positions are explicit finite pairs in metres. Width text lies below edge zero and projects within its span. Height text lies right of edge one and projects within its span. Design intent, selected leader and route-centreline preference are explicit inputs. The constructor rejects unsupported frames and existing dimensions/constraint references. XY translation remains free; no fixed-centre or fixed-corner relation is invented.
