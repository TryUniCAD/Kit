## Root-owned launch

Copy all 37 packet files to an unused shared packet directory without changing bytes. The native controller resolves all artifact paths relative to that directory, so relocation of the packet itself is supported. Use the established absolute guest Python with `-B`; the prior `-I` launch suppresses the guest's user-site `pythoncom` installation.

Run `Tools/InspectAnsiDrawingLifecycle.py` in order with `verify`, `preflight`, then `run`, followed by the absolute copied `Packet.json` path and:

```text
--packet-sha256 6593627727b39d619a60c609b79e0848084f94b6038d7e7b72a17f5d2a03f25c
```

Root owns every VM action and must retain its normal oracle/process/license inventory checks. This protocol starts no native process on the host and authorizes no license or foreign-process change.

## Fixed exit gates

Eighteen distinct native processes are required: a healthy control, each case's open/rebuild/save, fresh reopen, driving edit plus drawing move/save, fresh reopen of the edit, and the trailing healthy control. The unchanged ordinary observer checks the exact part/drawing trees, parameter and entity identities, linked child/configuration ownership, actual origin profile, analytical geometry, live edits and clean native statuses.

After the terminal native result, run the packet's unchanged `HostTools/QualifyAnsiLifecycle.py` with the frozen candidate directory, copied packet path and an unused output directory. Supply the exact writer manifest, packet, terminal native-result and qualifier digests. It requires twenty actual typed child/drawing joins, complete stream replay, the real origin/file/configuration/component aliases and equality of the entire expected presentation graph at construction and all four lifecycle phases.

No field rewrite is ignored. An ANSI drawing `f20` change still fails complete style retention. A geometry-only lifecycle pass does not grant style, original-source or held-out qualification. A failure of either control invalidates the batch. The earlier failed full-retention result and the first host comparison failure remain immutable.

The [CAD criteria](../../../Documentation/Reference/Operations/CadSuccessCriteria.md) and [instruction book](../../Playbook/README.md) apply. Their stopping conditions remain “The first is success under every criterion on this page.” and “The second is the end of the available context.” This protocol is a bounded experiment, not an overall completion claim.
