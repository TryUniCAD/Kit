## Executable discovery boundary

[ReferencePlanePartProcess.py](../../tooling/sw2026/ReferencePlanePartProcess.py) accepts the normal Part request on stdin with an explicit `offset_plane_discovery` containing only `name`, positive `distance_m` and Boolean `reverse`. The document must contain a centered, fixed-center, radius-driven circle and one blind boss on a principal support. The plane name must be distinct. Unsupported angle/multiple-reference input, diameter mode, missing center fixation and off-plane text fail without emitting an artifact. The radial text point is an authored **world-space three-vector** on the actual sketch plane.

The process constructs the entire file under the existing file audit. It reads back and re-emits Config and ResolvedFeatures with the inherited map, checks support ownership and the driving graph, then round-trips every generated non-XML stream. It emits the bytes and stream hashes and records native qualification as pending.
