# Disclosed width-to-depth same-locator trial

Task `B04-SW2026/equations-local-references`, owner `assembly_frontier`, delivery PR #121. This trial compares two model-only Alpha parts at a single encoded and physical Windows locator. The previous reference opened with one solid and one live row, then lost its COM interface after the width setter returned zero. The equation-free Alpha also lost its interface at the first post-edit body lookup. Both earlier packets opened from shared packet paths while their archives identified a C: path. The later successful SDK origin-rectangle observer staged the source at its encoded locator, checked the actual corner and origin owners and used typed `IPartDoc.GetBodies2(0, True)`. Those findings define the matched trial. [Equation history](PartEquationConfig2026.md) · [Qualified rectangle observer](SdkRectangleCornerNative2026.md)
