reports record 2,456 project Python source modules after translating cached
bytecode paths to source names; 2,280 are not in the original table. Package
initialization and adapter discovery account for the broad import set.

`FrozenCohortSource.json` is a retrospective source inventory, not new unseen
evidence. It pins 3,404 files to writer revision
`f5953529e2114b5648cfe1e5341a83b1c2f0d9d6`: all 3,154 `src` Python files, the
original frozen research/process files and three empty test-package ancestors.

SHA-256. Original freeze/source-lock files remain unchanged. Saved native files,
recorded field programs, templates and proprietary binary artifacts are absent.

The original 354 entries also match the pinned writer's source exactly. The
inventory retains the original process JSON identities and eight generated

for freshly generated output, never sources of writer bytes.

The current tests materialize only the explicit source allowlist from Git into
a temporary directory. They verify original freeze hashes and schema membership
against that directory. A separate interpreter generates each historical part,
with the original read/process guard and complete archive comparisons. Its
output must match the originally measured hash; the current writer must emit
identical bytes independently. The test report marks these as regressions, with
no new unseen evidence or inherited production/native acceptance.

This transition deliberately permits current shared-model development. It does
not relax the historical experiment. A current output change fails its regression
and cannot be accepted by relabeling the old source input as unseen.

The source inventory was generated by static Git/object/hash inspection only.
AST checks and formatting ran locally; no writer, parser or test ran locally.
The new process comparison is pending remote CI.
