mapping defaults. `NativeModel.TypedGraph` carries the bounded report.

native module became part of this scoped change. `HeaderActions.ReadHdrAction`
extracts the existing log-action check; `RadialValue.MatchRadialVal` extracts
the existing radius/diameter comparison. Their error/cursor behavior, tolerance,
comparison order and normalized values are preserved. These legacy routines
are not promoted as strict typed grammar.

`ResolvedFeatures` does not contain complete populated mate groups.

before it can replace public selection-string reconstruction.
