## Producer and public closure

The existing `RectDimInput` accepts explicit finite XY pairs and one shared `RouteCenter` boolean. The audit constructed that input with the source XY pairs and routing mode. Passing the full source points to that same API raises `TypeError('rectangle dimension text requires two planar coordinates')`. `MakeRectDisplay` derives witness state via `ReadRectPlace` and writes the point with implicit Z zero. The archive already serializes three doubles. The independent research `SpatialTextMut` whole-point assignment passed native signed-Z edit/save/reopen on two drawing-linked children, but assumes the existing XY placement. For the planar child, use actual XY for the witness derivation and retain all three source coordinates in the typed text point. The source pair's two routing flags agree, so the existing shared boolean represents them. [Internal input](../../../src/convert/adapters/solidworks/Archive/Construction/SketchDimensions/RectDimInput.py) · [Display builder](../../../src/convert/adapters/solidworks/Archive/Construction/SketchDimensions/MakeRectDisplay.py) · [Measured spatial persistence](DrawingSpatialTextLifecycleProtocol2026.md#measured-lifecycle)

The source projector already separates actual display rows from its clean portable document. Its captured rows remain comparison evidence until that model input exists.
