## Shared target contract

New SDK `Archive/Construction/AssemblyTargets` modules retain the original
generated model, manager, selected configuration, both headers, independent
manager header, local bounds, direct reference/target pairs, activity, typed
configuration/resolved graphs and generated output bytes. A part adapter accepts
the actual `PartCandidate`; an assembly adapter accepts the actual complete
single or ordered SDK candidate. No adapter reads a native file, decodes a saved
template or reconstructs a target from XML.

`MakeTargetDir` computes one first-use directory record per direct definition,
users from placements, independent child-file and manager save stamps, and the
native directory index. `MakeTargetRef` is the common ordinary occurrence
constructor for parts and assemblies. Target kind is preserved in the shared
file definition; target configuration comes from its actual selected node.
Part stamps use the actual model/header state. Assembly stamps fold the actual
child reference graph. Assembly-local bounds retain their independent sphere.

The existing part directory and occurrence functions now delegate to that shared
model without changing their interfaces. Per-occurrence configuration selects
the containing assembly's `fc48` insertion options for an assembly target and
`fc50` for a part target, following the pinned native dispatch. The new target
checks distinguish direct rows and expanded activity and preserve actual owner,
file, configuration, local-bound and stamp relationships.

## Recursive publication

`MakeNestedAsm(AssemblyInput, tuple[TargetPlacement, ...])` creates a fresh
assembly around actual generated targets. It shares the flat constructor's
configuration, resolved, MatesList, Definition and metadata serializers. New
XML enumeration walks actual definition identities once, allocating placement
IDs independently and emitting models in dependency order. Binary directories
remain direct even when XML includes the full closure.

The constructor rejects unsupported native target kinds, inconsistent
configuration/header ownership, cycles, duplicate file identities, sibling or
system name collisions and non-rigid placement frames. The research stdin
entry additionally requires a complete reachable neutral definition DAG and
rejects extra occurrence state. A repeated target is constructed once and
retains one shared model across all placements. Circular child bounds remain
outside this profile under the shared `MakeChildBox` guard.
