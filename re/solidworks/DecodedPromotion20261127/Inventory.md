## Strongest bounded new implementation slice

**Reversed single Front-plane line-loop blind boss**, following explicit coordination with #121/#297. No inspected additional whole feature family already has all evidence needed for immediate public writer admission. Reversal is the smallest extension of the existing donor-free part constructor rather than a claim on another owner's revolution/circle/history work.

Current guards make the missing work exact: `Part/Neutral/RequireBossDef.py` rejects `Definition.reversed`; `Blind/BlindEndInput.py` rejects `IsReversed`; `Part/Neutral/BlindPlan.py` lacks a direction field; `Part/FinishBlindMut.py` hardcodes false. `Blind/MakeBlindEnd.py` already derives `f8c` from `IsReversed`, but `Extrusion/MakeBlindMut.py` makes `moFromEndSpec_c.t` zero, which is the loader-proven sketch-plane start type and must remain zero for this route; removing guards alone would still leave the reader and derived geometry unqualified. Historical `features/Results.md` E7 found two coupled physical bytes yielding negative-Z centroid. Current loader-backed `WriterResearch/Display/EndOwner.md` supersedes interpreting that historical offset as modern start type: `moFromEndSpec_c.t` stays zero for the reversed control; `moEndSpec_c.f8c` is the direction. The modern changed cap-field provenance and every dependent dimension/display/cache field remain separately qualified.

1. Seal fresh independent forward/reverse source pairs on the exact installed build, varying polygon vertices/profile offsets/depth separately and reserving holdouts before inference. Include direction expressed as reversed and explicit vector counterexamples, both relevant first/second direction records, centroid/bounds and healthy before/after controls
2. Trace current generation-19000 end/from-end serializer owners and all five dimension lifetimes. Explain each differing authored/derived/constant/volatile field using the existing typed maps; do not fit constants or offsets from one file
3. Carry direction through neutral plan into the constructor; generate negative-Z prism topology, mass/area/centroid/bounds, configuration and resolved graphs from model values. Inspect `Archive/Construction/Part/EmitPartStreams.py` and its generated owner graph for coupled cache fields before changes
4. Keep public exact-output native measurement gate unchanged. Bind new reports to deterministic candidate bytes/build, use source-free construction guards, and verify write/read through registry and CLI. Do not copy source bytes or weaken `CheckPlainScope` for source imports
5. Independent live depth and profile edits, restore, rebuild, save and fresh-process reopen must agree with derived volume/area/centroid/topology and remain editable. Sealed holdouts plus wrong-direction/modified-receipt/output-path counterexamples must pass/refuse correctly through existing integration/compatibility execution paths

Exit needs complete fields, sealed sources/receipts, exact candidate hashes, current SDK/CLI compatibility and native acceptance. No oracle lease is held by this child. The parent must allocate an exclusive session and record the register claim before capture.
