# SOLIDWORKS feature ladder recovery evidence

This package adds 37 previously missing controlled batches: 111 native files and strict neutral decodes.
Each successful native batch retains control before, variation and control after with independently recorded native measurements.
Two further saved files from the original failed batch are retained separately as salvage. The absent healthy after control and original COM failure are not erased.
The native remaining-batch wall window was about 41.52 minutes, including recovery and waiting. Successful worker execution totaled about 15.75 minutes.

The native queue settled without another COM failure after supported recovery and selecting the Python 3.14 launcher.
The controller preserves 34 completed and two failed attempts: one native COM failure and one local supervisor settlement failure whose returned native files were independently verified.
This is not proof of permanent native worker repair.

All 111 requested native cuboid volumes match the derived neutral bounding-box volumes.
Only 15 front-plane files also match the native centroid. All 48 top-plane and 48 right-plane files have incorrect neutral placement.
The sampler mistakes a timestamp field for a fixed format tag and falls back to a front-plane attachment; the strict typed rectangle path also has an unqualified scene-state branch.
Those two gaps are detailed in SolidWorksPlacementRootCause.json. Neither is repaired by this research package.
Neutral explicit volume and surface-area properties remain unavailable. Strict decoding is not complete semantic recovery, editable conversion or vendor acceptance.

Manifest.json records every artifact hash and all 37 logical cases. Native source bytes remain unchanged.
Derived reports replace operator paths and host names while preserving their original hashes. Reports use gzip timestamps of zero.
Programs contain independently authored native API recipes; configured workers must supply app and work.
No personal transport configuration, bearer credential, vendor software, executable, library, SDK, template or license is included.

Choose a new output report with Python 3.14:

```sh
python3 Verify.py --output /tmp/SolidWorksRecoveryVerification.json
```

The verifier checks evidence consistency. It does not qualify the pending placement fix or target conversion.

`Receipts/` retains sanitized issued-command worker records and native outcome/file-digest records. Their original private receipt hashes remain bound in the manifest. `reproduction_command` entries are portable examples; worker receipts retain the issued arguments with operator paths replaced. `DecodeChannels/` retains each decoder channel. Private native job identities and request nonces are excluded.

Published text uses LF line endings; original receipt and measurement hashes remain recorded. Package attributes preserve those bytes on Windows.
