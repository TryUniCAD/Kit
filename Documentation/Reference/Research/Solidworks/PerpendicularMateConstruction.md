It uses actual child principal datums, one fixed anchor, rigid occurrence transforms and the existing shared allocation, wrapper and archive writers. It does not enable public writing.

The [source lock](../../../../re/solidworks/measurements/2026/PerpendicularMateSourcePosition05.json) predates all new writer code; both hidden designs remain sealed.

`CheckPerpendicularWriter.py` takes an explicit frozen SDK root, baseline root, neutral fixture directory and unused output directory. It builds complete files in guarded child processes and checks real linked graphs and independent geometry. Request dictionary order is preserved and request/prediction/source hashes are retained. The source-only proof does not open native files or start SOLIDWORKS.

Only the root-owned Windows oracle may execute its isolated `run --phase` steps. The trailing disclosed control runs independently of the generated result. No native acceptance is inferred from packet preparation.
