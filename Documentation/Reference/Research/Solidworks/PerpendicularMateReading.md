# Inspect the ordinary perpendicular mate reader

PR #121 integrates the bounded perpendicular mate reader into the normal SDK. The independent research procedure below replays the exact frozen reader and its baseline against disclosed SOLIDWORKS 2026 sources and native-edited siblings.

The complete version19000 MatesList codec reuses the actual inherited resolved map and explicit concrete perpendicular schema/virtual bindings. The narrow semantic projection requires one solved mate, two direct occurrences of the same part, exactly one fixed occurrence, actual child configuration/file/stamps/principal-datum creation and kind, consistent detached selections and independently orthogonal resolved planes. Native internal alignment0 remains neutral `unknown`; the separately observed COM alignment2 is recorded as oracle evidence.

With immutable SDK current and baseline roots and the authorized disclosed packet, run the process proof in an unused directory:

```sh
uv run --isolated --frozen --extra dev --python 3.11 python -I -B re/tooling/sw2026/CheckPerpendicularReader.py \
  --root /absolute/path/to/FrozenCurrent \
  --baseline-root /absolute/path/to/FrozenBaseline \
  --packet /absolute/path/to/PerpendicularMateSourcePacket03 \
  --cohort /absolute/path/to/PublicResolvedVerify03/InputManifest.json \
  --linked-proof /absolute/path/to/ResolvedSdkVerify02/LinkedMatesExact06.json \
  --bindings /absolute/path/to/NativeReaderBindings03.json \
  --output /absolute/path/to/UnusedReaderProof
```

The proof never starts CAD. It hashes the complete SDK/tool closure before execution, checks exact D01 source custody and five recorded native process identities, reads both synchronized source pairs, retains whole-stream byte and alias identity, compares the public plane references/poses/real child dimensions with native observation, checks six prior linked streams and exact legacy behavior, and opens independent malformed diagnostic copies. It verifies the source and original input hashes again at completion. Malformed copies receive no writer or native acceptance credit.

The initial proof passes 80 Python launches, 26 public negatives and one repacked reader control. All native source payloads remain private; published receipts contain identities, numeric fields, statuses and limits. The pre-writer native phases and controls have locked both held-out designs. Their contents remain sealed during writer derivation. Subsequent disclosed designs must be compared with the frozen implementation and reported separately; their expected native endpoint order must come from actual native readback.

A subsequent, separately released D02 source and edited pair pass the exact unchanged implementation in two fresh Python workers. This covers nontrivial rotations, the second fixed occurrence, Top/Right datums and native endpoint reordering.
