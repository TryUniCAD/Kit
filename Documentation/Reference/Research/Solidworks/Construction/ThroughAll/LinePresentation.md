# Through-all source line presentation

The internal line-table component retains actual source catalog and category-font settings. It adds no public format admission.

Use `ReadThruLines(document, link, definition)` with the validated ordinary source envelope and actual typed part Definition. It returns `LineTableInput`: ordered `LinePattern` inputs and a compatible `FontBinding` insertion plan. Use `MakeThruLines` with the actual owner input, part settings, configuration intent, view input, empty-manager input and line input. The builder creates fresh owners and returns the existing typed construction graph. It reads no file and patches no saved stream.

Each pattern needs explicit name/caption, finite signed catalog-space scalars with positive absolute period, and boolean thick/thin. Each category needs name, font selector, preset weight zero/one/two, and end-cap zero/two. The component assigns no physical units to catalog scalars and invents no default/localized rows. A font selector can be absent from the local catalog. Counts and archive identities derive from the new graph.

The native map has seventeen buckets, sampled UTF-16 hashing, case-sensitive identity and head insertion. Each category owns a distinct font object. Starred keys do not persist and are refused. Unknown fields, aliases, custom widths and unqualified modes are refused. Empty tables preserve earlier bytes.

Verification: 101 host processes, 63 SDK refusals, two disclosed sources, six authored table inputs, 56 independent fragment re-emissions and two old complete-container pairs. No native process or original held-out input was used. Six Definition and twenty-nine CMgr frontiers remain; full-source admission stays closed.
