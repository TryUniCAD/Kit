# Audit original through-all sources

The [source auditor](../../../../../re/tooling/sw2026/AuditThroughSource.py) checks complete disclosed source documents before a through-all conversion can be qualified. It accepts a pinned SDK checkout, source manifest, method manifest, a declared control cohort and an unused output directory.

The auditor reads each exact `Trial.json.control_file` through the ordinary SDK, freezes independent signed geometry predictions, retains every source owner ID in a byte-free audit document, and checks the separately read B-rep. Its failure cases cover missing/foreign selected stock, missing or independent extra centre points, unused cut dimensions, lost line relations and foreign direction axes. A shape-identical removed-history input remains rejected by the complete comparison.

The normalized audit document carries an explicit incomplete-projection diagnostic. It is not an accepted writer input. This workflow neither strips the source to two operations nor uses a source-native cache or field bag as a writer template.

The [field and coverage record](../../../../../re/solidworks/records/ThroughAllOriginalSourceNormalization2026.md) lists remaining system, presentation, provenance and identity dependencies. The [process receipt](../../../../../re/solidworks/measurements/2026/ThroughAllOriginalSourceAudit01.json) binds 38 fresh SDK/planning processes. No hidden source, CAD runtime or native writer acceptance is included.

The separate saved two-stock selector check covers the original face-backed wrapper and the edited derivative whose wrapper face is absent. The latter requires the actual consumed atom, self-component, linked chooser representation aliases and original profile markers. The proof also checks the two surviving active partition bodies. The edited derivative retains its existing full stock-mode refusal. [Two-stock selector receipt](../../../../../re/solidworks/measurements/2026/TwoStockSavedSelector01.json)
