# Internal portable SOLIDWORKS assembly compiler

This interface is an unregistered private qualification overlay. It does not add a normal public assembly write route or claim native usability.

`PlanAsmWrite(document, native_path, written_at)` admits a complete portable owned assembly and returns typed constructor inputs. `PrepareAssembly(document, native_path, written_at)` returns the actual complete ordered SDK candidate and its single shared generated child.

The profile uses millimetres, one active configuration, an owned unassigned dimensioned rectangular blind-boss child, its three explicit canonical principal planes, two or three direct rigid occurrences, one fixed anchor and a complete initially satisfied aligned ordinary mate group. Actual endpoint paths and child plane IDs supply selections. A positive driving distance retains the same owned D1 parameter and typed value. Unmapped fields fail before native construction.

Provide one explicit absolute Windows parent destination. The child identity derives from that directory and its actual name. Other hosts must declare their native mapping explicitly; no share or drive mapping is inferred. The regular output transaction publishes both sibling files. Stream and overwrite output remain closed.

The separate option and emission helpers remain internal. Their research-only wrapper uses the ordinary registry/path staging and reports false application/vendor usability until the measured profile passes native qualification. Current public part behavior and default registrations remain unchanged.

The native proposal requires clean controlled open/rebuild, exact trees and references, analytical geometry, a driving edit, child-first synchronized save and fresh reopen. A passing byte round trip or host registry test alone does not enable the route.
