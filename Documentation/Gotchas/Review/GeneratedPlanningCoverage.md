# Generated planning output exceeds model source limits

The review fixture's repaired CLI is small, but its required owning-register update regenerates two multi-megabyte BoardData files.
At head `fa405f5b0710d5cc971985901232519a9acaba63`, the [hosted review](https://github.com/TryUniCAD/Kit/pull/401#pullrequestreview-6099686787) recognized the code repair but withheld approval because those sources were omitted.
A green CI result and a hash alone do not establish model review coverage.

Use exact reconstruction only when the default-branch generator and its other dependencies are unchanged and the complete changed inputs were supplied to the model.
Require both old and new generated bytes to match their Git objects and retain the derivation receipts.
Changed generators, unsupported inputs and stale bases require separate full-source review; do not exempt files by path or silently raise coverage to complete.
