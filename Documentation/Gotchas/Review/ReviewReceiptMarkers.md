# Review formatting includes machine receipt markers

The review body appears to be presentation text, but request discovery and approval receipt matching also read its final fields.
Mention discovery expects the penultimate blank-line-delimited field to contain the exact mention receipt.
Approval discovery expects the body to end with its exact snapshot receipt.

Keep these final fields unchanged when adding headings, tables or collapsible verification details.
Place the closing details tag before the canonical receipts.
Changing only their formatting can otherwise cause duplicate reviews or make an actual approval undiscoverable.
The presentation formatter preserves compatibility with already published receipts.
