# Compare live Front support through the specific plane interface

On SOLIDWORKS build 34.4.1.1011, comparing the P03 sketch support to the Front feature handle returned `IsSame=0`. The sketch support exposed `IRefPlane`; the feature handle required `GetSpecificFeature2` to obtain the specific plane object. Comparing both references through `IRefPlane` returned 1 for the sketch support against Front and 1 for an independent Front refetch. The Front-to-Right and support-to-Right controls each returned 0. Public COM `IUnknown` identity still differed for support and Front.

Use the same documented specific interface on both sides, preserve the raw feature and COM results, and retain positive and negative controls. Feature names, numeric IDs and coincident geometry remain side observations. The stock persistent-reference comparison remained unavailable in the recorded binding.
