# SOLIDWORKS partition identity is checked before name binding

A strict public read of a four-line blind boss can already bind the selected kernel body to its neutral owner. The body then carries `solidworks.native_body` and exact atom and partition provenance. A second exact comparison with a freshly decoded kernel packet sees those fields as differences.

Run the exact active packet comparison before binding public aliases and provenance. When inspecting a finalized document, keep those fields and check them against the owning atom and partition. Differences in those fields do not justify rewriting the public geometry or ignoring a differing packet.
