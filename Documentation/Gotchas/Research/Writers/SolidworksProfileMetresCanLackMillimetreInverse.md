# Some saved SOLIDWORKS profile coordinates have no exact millimetre inverse

An independently authored millimetre sketch can have the same directed shape as a SOLIDWORKS save while their internal metre coordinates differ by a binary64 step. The cold sketch check requires a millimetre value that multiplies back to each original native coordinate. That check refused the two Author04 saves and the warmed Discovery02 control because at least one coordinate lacks that inverse.

Use the separately authored, body-verified millimetre profile for the exact saved-depth research bridge. Preserve the driving depth as a typed metre value. Keep the saved profile coordinate limitation visible when reporting the scope. [Exact depth proof](../../../../re/solidworks/records/VendorBlindBossExactDepth.md)
