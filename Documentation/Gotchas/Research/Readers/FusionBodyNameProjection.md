# A saved Fusion body can have an empty reader name

A source body's native display label and its public reader name can differ. The exact P03 native source receipt calls the sole body `Body1`. The current installed strict reader returns body `fusion:0:309` with an empty name. It still reports its final Boss and assigned typed material.

Keep both observations with their input and reader pins. Verify the saved naming source before deriving a default or treating the label as an authored rename. Body ownership and an assigned material do not establish name preservation. [P03 public admission evidence](../../../Changes/Research/Readers/Comparison/PinnedPublicAdmission.md)
