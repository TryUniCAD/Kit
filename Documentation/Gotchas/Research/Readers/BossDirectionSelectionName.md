# Boss direction paths can carry a sketch name

The pinned SOLIDWORKS reader returns a native `RectangleSketch` name in the public `N_Axis` selection path. The path is not a neutral sketch ID. The original P03 Boss and generated candidate have the same sketch name and different native IDs. The ordinary graph comparison retains the unresolved name-based reference.

Corroborate the direction record with the operation's source span, native owner and target. Follow the actual feature reference to the unique supported sketch. Check its support normal before recording the direction observation. Preserve the original unresolved comparison independently.
