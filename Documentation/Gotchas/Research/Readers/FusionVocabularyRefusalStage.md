# Fusion vocabulary changes move the strict refusal stage

An archived strict-reader control expected an unknown-class refusal.
Registering the feature vocabulary lets that input reach the projection boundary,
where its unsupported history is rejected with a different exact diagnostic.
Other unknown classes now identify their GUID, segment, and object.
See the [queue census comparison](https://github.com/TryUniCAD/Kit/actions/runs/44835681678/job/136631695007)
and [P04 process failure](https://github.com/TryUniCAD/Kit/actions/runs/44835681678/job/136631695048).

Review exact remote messages and preserve all outcome and identity checks when updating a census.
For historical report digests, assert the current refusal first and normalize only the documented diagnostic before comparing the original digest.
