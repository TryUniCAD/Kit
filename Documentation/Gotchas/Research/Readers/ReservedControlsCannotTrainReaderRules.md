# Reserved controls cannot train reader rules

Different filenames, feature values and stream hashes can still belong to one reserved family. Multiple V8 parts agreed on pattern-count offsets, but all belonged to the same holdout project. Reusing one as an explicit control left that boundary intact.

Use the pinned split and the paired capture recipe to select discovery material before fitting offsets. Keep an independent authoring lineage for evaluation. Inspect the [file-run evidence](../../../Changes/Research/Inference/DiscoveryControlEligibility.md) before treating a repeated offset as a reader rule.
