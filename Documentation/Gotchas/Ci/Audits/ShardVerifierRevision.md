# Historical audits need current shard reporting code

Manual audits run a current workflow against the immutable source selected by `audit_sha`.
A source revision that predates sharding does not contain the new shard verifier.
Checking out that source in the reporting job prevents the verifier from starting.
Successful native test shards do not repair the missing reporting code.

Load the reporting script from `github.sha`, the workflow revision.
Keep test source checkouts pinned to `AuditSha`.
The report still verifies the exact artifacts generated by the audited source.

See [PR #230 review evidence](https://github.com/TryUniCAD/Kit/pull/230#discussion_r4655577433)
and the [change record](../../../Changes/Ci/Testing/WindowsResearchCliShards.md).
