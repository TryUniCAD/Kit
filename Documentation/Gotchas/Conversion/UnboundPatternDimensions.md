# Unbound pattern dimensions

A displayed pattern angle can survive strict decoding even when its saved scalar has no verified byte span. In the turbine wheel, the old reader exported the display of 32.73 degrees alongside an inferred native value of 0.03273 radians. Its length conversion had also reached angles.

Use the parameter value and unit for displayed quantities. For native measurements, require a dimension-scalar span and read its native unit. See [the reader change](../../Changes/Research/Inference/SolidWorksDimensionProvenance.md).
