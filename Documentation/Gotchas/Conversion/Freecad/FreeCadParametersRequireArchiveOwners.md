# FreeCAD parameters require their archive owners

A neutral parameter can retain its FreeCAD property record while its separate ID, caption or value changes. On both disclosed origin AdditiveBox sources, the earlier planner accepted a changed Length ID when the feature listed that same ID. It also accepted a changed Width caption and conflicting attachment mode and visibility. Each original FCStd and B-rep kept its exact contents.

Decode the actual primitive's parameter records again from the retained archive. Compare the full typed neutral parameters and their feature-owned IDs before reusing the lineage or building the target. The scoped origin planner performs this check in memory.
