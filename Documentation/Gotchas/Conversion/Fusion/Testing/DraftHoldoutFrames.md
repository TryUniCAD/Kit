# Draft holdouts have different placement boundaries

The two-sided draft campaign has two held-out models with different sketch frames.
`holdout_b` and its five edited or restored states use XY placement.
`holdout_a` uses XZ placement and remains a refusal control for the bounded XY reader.

Select successful CLI and writer-refusal fixtures from their actual recorded transforms.
A holdout name alone does not establish that the source belongs to the accepted placement family.
Retain both the accepted XY states and the rejected XZ states.

The first public integration attempt incorrectly selected `holdout_a` as an accepted XY case.
The fixture was corrected without changing the production placement policy.
