# Equivalent zero signs can change neutral document hashes

Native XY datum axes can contain negative zero while the selected sketch matrix denotes identity.
Building a new neutral frame directly from those axes propagated negative zero into support and BRep reference vectors.
The geometry was equal, but earlier decoded document hashes changed.

Validate the source datum, matrix and ownership first.
Return the existing canonical identity frame for the qualified XY branch.
Retain source values in the typed research evidence and preserve the calculated nonidentity XZ frame.
Do not normalize arbitrary geometry or remove source records to obtain matching hashes.

The frame extension's earlier-document comparison exposed this regression before publication.
