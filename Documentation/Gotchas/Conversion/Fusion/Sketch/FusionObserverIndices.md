# Observer indices include runtime subscriptions

A persisted entity's subject index is not the number of preceding persisted entities that observe the same subject. The native rectangle control saves width/depth subscriptions to AssetSettings at indices4/5. The complete saved graph accounts for indices0/1 through two Browser entries, but it contains no subscriber at2/3.

The native EntityObservers list starts empty and includes both entity and non-entity observers. An unindexed subscription appends at its current length. During load, EntitySubjects resolves each target and calls addSubscribedObserver; an occupied index can be reassigned, and the new index is written back. The dimension constructor requests ordinary unindexed subscription, not a reserved slot4.

Preserve indices when retaining a graph. For fresh graph authoring, allocate a consistent per-target namespace across Design and Browser subjects, and qualify the chosen ordering through native acceptance. Do not create fictitious entities or copy a fixed base count from one capture. The exact identities of the control's two unrepresented positions remain unknown.
