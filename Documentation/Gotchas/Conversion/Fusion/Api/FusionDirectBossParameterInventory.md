# A bare direct Boss follows the Fusion constructor reader

A complete archive readback from the positive XY Boss probe can suggest that the public strict reader accepts the same file. The two paths apply different checks. The research probe reads the parametric archive and verifies the owned sketch and Boss bindings. The direct-owned probe emits four valid feature-owned parameters and no user parameters. Its archive has no snapshot, configuration or graphics attachment. The public strict reader took the constructor path and returned `Unsupported Fusion user parameter inventory`. The saved P03 archive has the same four parameter roles and attachments that select the separate saved-design path. A direct diagnostic of the generated graph against that path also refused its dimension settings observer ranks.

Author the observed Browser and dimension observer order and derive the normals from the linked positive XY frame. Build a genuine snapshot from the generated shape and confirm its tool, profile and sketch owners. Use the full native graph for that proof because the constructor index refuses auxiliary members. The resulting P03 replay enters the unchanged version 2 reader and returns its read-only document. Native Fusion acceptance needs separate evidence.
