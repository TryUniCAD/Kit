# Saved Fusion cuboids can store separate appearance owners

The saved metal controls and saved basic-material edits give the body a legacy appearance instance and a modern compatibility partner. The physical material also links a separate modern appearance aspect. The two modern assets in each measured file have equal typed properties and definitions. Their separate owner links retain different roles.

The metal controls additionally point their component default to the body's physical asset. The basic-material edit and restore leave that default unassigned while the body retains its explicit physical material. The visible color and density alone do not describe either arrangement.

The [authored material research procedure](../../../../Changes/Research/Encoder/FusionAuthoredMaterialProperties.md) uses the existing generated material families. It refuses saved appearance aliases, procedural texture mappings and resources that this scope cannot reproduce.
