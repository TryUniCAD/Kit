# Mirror and Cut selection mode

A whole-body Mirror input and a Cut target both use selection mode 8. Selecting the Cut trailer solely from that number makes a valid Mirror fail before the reader reaches the body association. The mutation in the linked hosted job exposed the early refusal. [Hosted reader control](https://github.com/TryUniCAD/Kit/actions/runs/44749866072/job/136335249134)

Use the owning feature to select the marker and descriptor layout. The Mirror reader checks the ordinary proxy and ordered associations. The Cut reader opts into the Cut marker and checks its target and extent dependency copies. Both paths still validate the reciprocal links.
