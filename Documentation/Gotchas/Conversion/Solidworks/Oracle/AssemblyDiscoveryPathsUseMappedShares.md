# Assembly discovery paths can use a mapped share

The assembly source was authored through the Mac share, but the native
document also retained the Windows drive mapping in reference metadata.
Checking only user-home path spellings missed that mapping. One framed path
occurred in `SwDocContentMgr/SwDocContentMgrInfo`, and the component XML tree
also stored a private `swFile` `swPath` attribute.

For research publication, scan for the exact research-root mapping and handle
the identified metadata owners at unchanged width. Keep the source archive
hash, per-operation ledger and prepared hashes. Do not apply those replacements
to production output or repurpose the files as writer data. The
[prepared fixture manifest](../../../../../re/solidworks/v2026/corpus/assembly-discovery/Manifest.json)
links the ledger to the three discovery saves.
