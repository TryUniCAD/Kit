# Width-to-depth equations use their own measurement report

The measured local equation uses the normal standalone part constructor
and a paired native lifecycle. The plain comparison retained its depth
when the width changed. The enabled equation changed the boss depth and
the edit persisted in a new native process.

Pass that paired report through the usual measurement envelope. The
equation route checks the canonical report digest and the full output
digest before publishing. The generic plain-part receipt schema is
specific to the independently measured plain part artifacts.
