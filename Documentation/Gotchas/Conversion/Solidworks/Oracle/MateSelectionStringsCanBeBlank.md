# Mate selection strings can be blank for valid plane references

Both freshly generated coincident mates have empty selection strings on their detached plane references. SOLIDWORKS resolves the ordered plane objects and aligns the displaced occurrence. Its native save can populate the detached strings without changing the referenced occurrence or plane IDs.

Read the ordered resolved wrappers, occurrence backlinks and child datum IDs. Read alignment from the mate's own field. A string-only scan can miss both valid endpoints and explicit alignment. [Typed readback](../../../../../re/solidworks/records/PlanarMateProjection2026.md)
