# Native reference byte arrays can arrive as memoryview

`IModelDocExtension.GetPersistReference3` returns an opaque byte array. Pywin32 can expose the `VT_UI1` SAFEARRAY as `memoryview`. The exact SOLIDWORKS 2026 SP05.2 disclosed fillet records show that return class for 56 successful calls using the same untyped COM invocation. The first F14a runner admitted bytes, bytearray, tuple and list. Its combined type and size guard rejected all F14a captures and kept neither the returned class nor the length, leaving the original native output itself unclassified. Validate the byte-buffer format, dimensionality, contiguity and byte count before copying it. Record transport metadata before the guard so native null, empty and unsupported return shapes remain distinguishable. Keep tokens in memory and pass the original bytes to the native resolver as a `VT_ARRAY | VT_UI1` VARIANT. Verify the returned entity separately.
