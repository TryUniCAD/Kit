# Live receipt reads can block replacement on Windows

The native research recorder replaces its phase JSON with an adjacent temporary file after each observation. A progress probe opened the live destination with `Path.read_bytes()` during the SP05.2 Mid Plane source reopen. The recorder hit `WinError 5` in `Path.replace()` while recording the edited profile. The COM parameter edit and its geometry checks had already completed. Both native controls passed.

Wait for the worker to close the live phase before reading its file. A progress channel that must inspect the destination concurrently needs Windows delete sharing on its handle, which also permits rename. Preserve the failed receipt and verify the original source hash before repeating the measurement. Repeating the same source after removing the live read completed both candidate phases with healthy controls.
