# A geometric circle radius is not a driving constraint

The legacy circle scanner can synthesize a radius relation from the shape even when it finds no parameter. A saved circle with a centre and seam point still has an intrinsic geometric radius; that does not prove a native radial dimension, fixed centre or solver relation.

Use the actual linked sketch's dimension and logical relation arrays. For the qualified single local closed circle with empty solver/region state, call the existing explicitly free typed path only after confirming the actual owner. Its public sketch contains the real circle and centre, zero relations and zero sketch parameter IDs. Keep unsupported scopes gated rather than removing radius rules globally.
