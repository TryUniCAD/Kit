# Native save can omit a generated downstream cache

The fresh native save of an edited part can omit its standalone downstream cache stream even when the generated input contains that stream and rebuilt geometry and dimensions survive the lifecycle.

Record the cache stream inventory for both files. To qualify the native edge-lookup path, observe the drawing consumer and its returned edge under the applicable save settings.
