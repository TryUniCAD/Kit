# A mate datum reference uses the specific plane object

An aligned coincident datum-plane mate exposes its reference through `IMateEntity2.Reference`. The returned object identifies an `IRefPlane` in the endpoint's component context. `ISldWorks.IsSame` returned `0` when the observer compared this object with the `IFeature` from `IComponent2.FeatureByName`. It returned `1` when the observer compared it with that feature's `GetSpecificFeature2` result.

Resolve `ReferenceComponent` first, check `ReferenceType2` for the datum plane selection type, and look up the intended plane on that component. Compare the mate reference with its specific plane object. Both endpoints gave the same result in all nine snapshots of the disclosed A17 control and the generated aligned coincident trial, including fresh reopen after save.
