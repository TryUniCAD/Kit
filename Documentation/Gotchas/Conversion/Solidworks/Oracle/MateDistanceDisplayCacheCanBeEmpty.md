# A distance mate can carry an empty display value

The generated distance mate stores its driving length in
`moLengthParameter_c.f58`. The attached display's value field
`fad0` starts at zero. The disclosed A18 native save carries the
same value on its driving parameter and display.

Follow the actual retaining dimension handle to read the driving
parameter. Observe the display cache independently when measuring a
native rebuild. [Typed readback](../../../../../re/solidworks/records/PlanarMateProjection2026.md)
