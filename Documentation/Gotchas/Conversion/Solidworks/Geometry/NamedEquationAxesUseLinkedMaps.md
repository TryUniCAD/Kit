# Check origin axes on the equation-aware linked map

A named equation with three actual reference axes has a larger resolved tree than the axis-free stock. The equation must resolve on the same configuration and resolved maps as those axes. Starting from a generic parse can lose the relation context, while filtering the additional names alone loses the owners of the actual plane selections.

Check all three axis roots, both headers' creation events and every selection alias on the equation-aware link. Then exclude those exact owners from the ordinary stock inventory. Keep checking the equation's active and dormant depth fields and the stock independently. A foreign selection owner or a hidden axis cannot qualify for the checked full readback.
