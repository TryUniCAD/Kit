# Use the equation-aware map when binding a saved body

A saved width-depth part has the same ordinary solid carriers as its
plain comparator. Its populated local relation changes the configuration
archive traversal. A second, generic parse without that relation context
can miss the named body's active atom even when the sketch, extrusion
and physical B-rep are individually readable.

Reuse the configuration and resolved maps that already verified the live
equation handles. Require the actual active partition's recipe, producer
and boundary to agree with those handles. A plain save can retain matching
slots and tags and still carry a different depth. Match the outward rings
against the solved feature before binding the body. [Saved equation proof](../../../../../re/solidworks/records/SdkSavedWidthDepth2026.md)
