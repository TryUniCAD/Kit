# Native part preparation is not publication evidence

The ordinary model plan and serializer can generate a valid candidate
without a native runtime. The generic permissive transfer policy previously
allowed that candidate to reach a public destination while both native
acceptance flags were false.

Keep unmeasured candidates in the internal in-memory preparation path. At the
public emission boundary, require a trusted offline native report and match
the complete regenerated archive digest before opening a file or writing to
a stream. A report from another output cannot qualify a change to the model,
creation epoch or encoded locator.
