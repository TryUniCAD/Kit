# Cold shell inspection supplies a derived body label

A cache-free shell carries its actual creating feature and selected cap. The strict reader describes its unsaved body as `Body 1` when it has no stored kernel body label. The model-only stock and shell constructor requires its temporary body name to follow the actual shell feature.

Use the exact construction projection for that input. It derives the temporary label from the linked shell feature and compares a strict read of the regenerated file with the original source. Altering the original body label fails the complete source comparison. Saved shells have their separate recorded names and body history.
