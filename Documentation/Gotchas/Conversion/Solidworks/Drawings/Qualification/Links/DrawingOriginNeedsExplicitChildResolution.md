# Drawing origin identity needs explicit child resolution

A retained `moCompProfile_c` can select a child's actual origin while the public child sketch list contains only its separate ordinary sketch. The public partial drawing reader does not resolve the external file and does not supply the child to its projection. Successful raw retention therefore does not establish portable origin ownership.

Use explicitly supplied, independently hash-bound child bytes and the actual declared external reference path. Keep the child's historical self title/path separate from the drawing's physical directory entry. Follow the real component chain and selected configuration, then compare the actual positive feature ID and its creation epoch. Do not select by a visible sketch name or an archive-map index, and do not perform a hidden filesystem lookup.

[The private typed component proof](../../../../../../../re/solidworks/records/DrawingExplicitOriginJoin2026.md) resolves both disclosed views while preserving raw streams and every existing public diagnostic. It leaves strict/public admission and unprojected owner families unchanged.
