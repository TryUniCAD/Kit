# Origin references use the actual child creation log

A child origin is not guaranteed to have the native unset creation time. The older discovery pair selected origin ID17 with epoch2592000 because that actual origin had no creation event. Four new disclosed native children instead select origin ID5 with epoch1794529625 from their real Header/log graph. All eight source/moved drawing states match the actual child creation epoch.

Resolve the actual generated origin and compute its FRData time with the shared `DatumTime` operation on that generated child's Header/log. Use native unset time only when no actual creation event exists. Do not copy either observed timestamp, assume an origin persistent ID or select the ordinary rectangle sketch by name.

The [source receipt](../../../../../../re/solidworks/measurements/2026/DrawingOriginProfileSourceLock01.json) and [native lookup record](../../../../../../re/solidworks/records/DrawingOriginProfileLinkage2026.md) bind these observations and the lookup rule. View move/save/reopen preserves the selected source origin in these inputs; a new generated display still requires independent qualification.
