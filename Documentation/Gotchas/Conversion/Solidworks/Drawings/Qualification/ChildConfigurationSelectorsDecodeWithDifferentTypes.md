# Child configuration selectors decode with different types

A drawing and its referenced part can select the same named configuration through two typed representations. The drawing Definition view selector exposes a plain string. The child Config-0 self selector retains a Unicode `CStringValue`. A plain-text assertion on both fields rejected ten correctly linked snapshots after native success.

Read text through each field's actual decoded type. Compare both decoded names and IDs to the active child CMgr node reached through the actual manager aliases. Keep the archive map and the representation of each selector intact when verifying byte replay.
