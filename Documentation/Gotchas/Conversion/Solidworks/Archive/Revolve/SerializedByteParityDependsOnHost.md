# Revolve byte parity depends on the host

The same neutral revolve intent, final locator and authoring epoch can
produce different file digests on macOS and Windows. Both writer
revisions reproduced one digest on macOS. The integrated Windows
worker reproduced the previously native-tested Windows digest. The
two containers carried the same ten logical streams and differed
within the same-length `Contents/Config-0` at byte 20,591. Typed readback
preserved the driving angle and closed body in both environments.

reference. Record the exact digest for each additional runtime and
measure native acceptance for changed bytes with the original
geometric and editing checks.
