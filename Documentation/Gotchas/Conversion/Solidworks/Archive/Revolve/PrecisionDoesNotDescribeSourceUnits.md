# Precision does not describe the complete source unit table

A source can use millimetres and two decimal places while retaining a length formatter that differs from the minimal native constructor. The disclosed revolve controls have a primary length row with `.f18=.1`, `.f20=4`, `.f28=8` and `.f88=-13`, plus a separate actual `fb8` dual-length owner. The dual child is an inch formatter with its own inputs. Reading the first matching length class from a graph inventory can confuse those two owners.

Follow `model.f9b8.items[0].o`, then its actual `fb8`, rather than choosing a class by global order. The pinned native getter proves that `fb8` is a dual-unit slot; it is independent of the model's optional analysis table `f9c0`. `MakeDualLength` constructs that complete child from native rules, but it does not close primary formatter or density semantics.

Do not attribute `f88` to `getValidationTolerance` by its nearby name. The exact base getter returns a literal and does not read that field. Preserve its source value as an observation and refuse source preparation until its rule is established.
