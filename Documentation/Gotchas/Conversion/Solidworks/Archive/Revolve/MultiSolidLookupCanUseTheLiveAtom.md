# The general selected-body resolver can join a live atom

The selected-body function branches away from its single-solid shortcut when two real solids exist. The ordinary wrapper still has a direct live atom branch through its separately dispatched body resolver. That branch can accept a valid regenerated body from the part's own atom manager even with a null representative face. [Resolver source evidence](../../../../../../re/solidworks/records/SelectedRevolveCutColdSelector2026.md#actual-resolver-branches)

Check the concrete wrapper, positive backing-list count and actual atom/body ownership before using this path. The complete cold revolve file still requires a controlled native run.
