# Legacy empty text requires a complete property owner

A version-18000 native part can store three XML property scopes and a
schema-one advanced binary property manager with no authored text. The
wheel smoke fixture contains reserved XML rows and a key-zero manager
entry. Its actual file and cut-list containers have no property rows.
The same binary field grammar also occurs in the current version-19000
ladder control.

Consume the complete manager and check each recognized XML scope
before allowing the legacy strict conversion. A familiar stream name,
successful geometry read or empty custom XML cannot prove the
binary owner's state.
