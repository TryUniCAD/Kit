# A SOLIDWORKS advanced property manager can have empty owners

The version-19000 `Contents/CusProps` keyed row count describes attached manager containers. Two unrelated native designs retained one keyed container through separate saves with every advanced property scope empty. Treating any keyed row as a populated property state withheld compatible text and added an unsupported diagnostic.

Check the concrete file and cut-list owners, their actual lists and the recorded policy tuple before admitting the ordinary literal text projection. Populated and unknown states still require explicit semantic support.
