# Typed model identity is not flat public metadata

A caller can expect an ordinary native part read to expose its modeled name as `document.metadata['name']`.

At the pinned revision, the normal reader does not add that flat key. The actual name remains in typed Config's model `moNodeName_c`. The self reference has a separate name and path. Reading the absent flat key raises `KeyError`.

Use the actual typed owner for this research boundary. Keep the source-to-neutral identity gap explicit. Do not invent a public name from the destination basename or claim complete source preservation.
