# A chamfer second distance owns another view

For the generated two-distance chamfer, the `f820` D3 display and its value
dimension use the second incident face. The axes of its annotation view
are swapped from D1, and its normal follows their cross product. The
catalog high-water ID belongs to the final registered view. The active
and shown selection fields retain the reserved unassigned view.

Bind the second view through the actual ordered catalog and D3 membership
before comparing the frame and the geometric witness. Use the
`f8c0` word and its live slots to distinguish this independent driver from
an equal-distance chamfer, which uses D1 on both legs.
