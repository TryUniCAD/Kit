# Flexible configuration names use two IDs

The configuration display name can differ from the name used by the storage writer. The ordinary storage name uses the signed configuration ID. The flexible branch uses the signed IDs at runtime offsets `fbec` and `fbe8` in that order, with the prefix `FlexCfg-` and a hyphen separating them.

Use the actual storage-name selector for the model. Keep both signed decimal values when the flexible branch applies. [Exact-build source proof](../../../../../../re/solidworks/records/DownstreamConfigurationStorage2026.json)
