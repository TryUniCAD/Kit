# Visible Front edges use the camera-facing cap

For the measured ordinary positive XY prism in a canonical Front drawing, GetVisibleEntities2 returns the four outer-cap edges at positive extrusion depth. The requested z=0 edge is geometrically valid but occluded, so the unchanged exact matcher correctly found no match in both pristine controls.

Compute the target from the actual neutral bounds and view normal. For this identity/+Z view select the maximum dot-product support cap, then its minimum-X rail. Keep all three endpoint coordinates, exact child ownership and unique-match requirements. Do not select by enumeration ordinal, drop Z, enlarge tolerance or reuse an observed control depth for another child.

[Source, independent corner prediction and preserved failure](../../../../../../../re/solidworks/records/DrawingVisibleCapSelection2026.md). Other orientations, occluders, hidden-line settings and arbitrary geometry remain outside this bounded target rule.
