# Drawing root occurrence configuration may be empty

A drawing view and its resolved part can report an explicit authored configuration while the single visible root component reports an empty `ReferencedConfiguration`. Requiring all three strings to match stopped both pristine native control observers before edge enumeration.

The pinned native getter asks a component configuration owner through virtual +0x188. The actual unit-component table returns null there and true at its root predicate, so the getter preserves its initially empty string. Do not interpret this as an absent view configuration or replace it with a guessed default name.

The bounded observer requires the actual root, absent parent, exact empty occurrence string, identical component/view model, part types and exact active configuration. This is distinct from an assembly occurrence, whose independent configuration owner remains outside this profile. The [source rules](../../../../../../../re/solidworks/records/DrawingRootComponentConfiguration2026.md) and [negative native receipt](../../../../../../../re/solidworks/measurements/2026/DrawingEdgeRootObserverNative01.json) retain the precise boundary. The corrected edge-annotation lifecycle still needs native execution.
