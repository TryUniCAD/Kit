# Oblique pattern count uses the Back annotation view

The count and pitch displays of a local linear pattern have different annotation-view assignments. The principal-direction disclosures associate their count with the actual Front annotation view and their pitch with a separate named view. In the four measured oblique disclosures, the count joins the actual Back annotation view and the pitch carries the explicit unassigned ID 199.

Bind these IDs through the actual configuration catalog. A view with the same name in the camera view collection has an independent identity. The persistent D1 and D3 dimension order is also independent of the model's display allocation, which allocates the pitch display first.
