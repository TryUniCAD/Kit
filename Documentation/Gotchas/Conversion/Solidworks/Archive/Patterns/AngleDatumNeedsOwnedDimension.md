# Angular datum values need their live dimension owner

The KeyWords record can associate a visible D1 number with a constrained plane without the parameter kind. The shared SOLIDWORKS reader's generic reference projection represented the disclosed 45° plane input as 45 mm. The live `AngleDim_c` and `moAngleParameter_c` store the value in radians and resolve through the selected datum's actual display handle.

For the measured 2026 angular plane, bind the finite hinge and Right-plane constraint through both creation logs. Confirm the live angular parameter against the constraint and its rigid frame, then project the identical parameter ID with an angular type and radians.
