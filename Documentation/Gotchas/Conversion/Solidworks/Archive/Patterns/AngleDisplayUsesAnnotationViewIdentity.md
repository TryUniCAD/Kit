# Angular displays reference an annotation view

The angular datum's display view ID belongs to the model's annotation catalog. The same label can also occur in the standard camera list with its own ID and distinct transform. The four disclosed `*Back` angle displays refer to annotation ID 201. Two other native models assign that same number to `*Front` or `*Left`.

Resolve each `moDisplayAngularDim_c.f2b0` value to one actual `moAnnotationView_c.f360` in `moPart_c.fa48`. Use the authored annotation view's identity and frame when constructing the graph. An ordinary camera ID or a value reused from another part cannot preserve the association.
