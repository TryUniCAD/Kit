# Public assembly anchors need the typed occurrence state

An assembly's complete mate graph and correct placements do not guarantee that
the neutral instances retain the fixed anchor. The legacy public instance
projection supplied `fixed=False` for every occurrence, including an actual
fixed component verified in SOLIDWORKS before and after native save.

For fully admitted ordinary typed planar graphs, read the independent
`moReference_c.f408` Boolean from the linked configuration's actual direct
reference list. Match each occurrence through its persistent ID, full name and
serialized external-feature backlink. Do not infer fixed state from solver
status `f400`, mate presence or enumeration order. A decoded lightweight
reference's missing runtime `owner` pointer does not invalidate those serialized
relationships.

Apply these flags only after complete typed admission. Preserve the established
fallback for deferred or unsupported graphs. The original and native-saved SDK
ordered pair both now read `[true, false]`, with all three mates and six child
plane references intact.
