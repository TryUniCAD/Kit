# Runtime assembly tree rows can lack saved feature identities

The two generated rigid nested assemblies show four light rows and two
note rows in the native feature observer even though their Config-0
environment and resolved cabinet lists are empty. The corresponding
rows in the two original assemblies have actual stored feature IDs.
Both originals also index an empty exploded-view manager that has no
row in the observed native feature tree.

Resolve stored rows through the typed owner lists and the native key
index. Qualify implicit rows only under the observed empty-container
profile and leave their persisted IDs and spans absent. Carry explicit
member settings and optional manager presence when transferring stored
presentation state. [Four-root ownership proof](../../../../../../re/solidworks/records/NestedAssemblyTreeOwners2026.md)
