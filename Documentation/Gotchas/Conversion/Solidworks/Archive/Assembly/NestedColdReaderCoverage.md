# Cold generated assemblies have separate reader coverage

The native component index gives every modeled definition the root display name. It binds each definition to its own file row and preserves the repeated occurrence links. Use the file identity or the actual object ID when comparing definitions. A dictionary keyed by the display name collapses the whole hierarchy into one entry.

The cache-free rectangular leaf archives carry sketch lengths in `sgSketch.dims.val_g2`. The two `sgPntPntDist` rows own the actual lengths and select their displays through two distinct sketch-handle slots. The keyword interpretation could mistake the second length for a radius, and the empty-relation reader used to report a missing Parasolid body. The two sketch dimensions and the boss depth also use two separate owner-qualified `D1` labels.

Use ordinary strict `open_document` on the leaf or resolve the leaf file through its parent. The reader checks the live dimension and display owners, four axis relations, Front-plane frame, ordinary forward blind boss and absence of stored bodies before deriving the solid. Setting `include_brep=False` retains the same editable profile and depth. Crossed owners refuse in either mode.
