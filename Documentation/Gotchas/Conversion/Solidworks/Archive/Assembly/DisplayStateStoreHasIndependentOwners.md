# Assembly display state uses independent owner IDs

The component-tree display list identifies occurrences by persistent feature IDs. The XML-local occurrence ID and the VisualStates key belong to different namespaces. The D01 visual-store list also orders the two occurrences opposite to the component-tree list. Match the actual visual reference's persistent ID and name before comparing occurrence state.

The synchronized empty assembly has a VisualStates state and three feature rows with no display-state list in the component tree. Cache omission and native precedence require their own measurements. [Disclosed owner proof](../../../../../../re/solidworks/records/ConcentricDisplayState2026.md)
