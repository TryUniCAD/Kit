# An exact measured bundle still requires its native locator

A SOLIDWORKS assembly contains its actual linked part and assembly
locators. Staging a complete, byte-identical pair in another directory
keeps its encoded file identities. That exercise does not establish
which child SOLIDWORKS would resolve at the alternate physical location.

Use the measured locator for native usability evidence. For explicit
deferred delivery, return the exact physical handoff files, keep both
native flags false, and report their required native destination.
The [grounded assembly receipt](../../../../../../re/solidworks/records/AuthenticatedPlanarBundle2026.md)
lists the independent native and staged SDK comparisons.
