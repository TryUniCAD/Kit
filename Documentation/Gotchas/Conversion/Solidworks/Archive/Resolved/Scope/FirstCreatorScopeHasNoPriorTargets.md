# The first creator can store selected mode with no prior targets

Selected-body mode identifies a policy for earlier solids. Three
disclosed ordinary first bosses save that mode with a null selected-body
wrapper and no consumed atom. Their generated outputs belong to a
separate atom lane. Inserting a wrapper for the boss's own output would
turn the result into an input to itself.

The exact ordinary rebuild uses the newly extruded solid when there is
no earlier target. Model the scoped case with an empty prior-target set.
The automatic-selection switch belongs to a separate runtime field and
cannot be recovered from the null wrapper. The guarded research
constructor still needs a fresh native lifecycle before promotion.
