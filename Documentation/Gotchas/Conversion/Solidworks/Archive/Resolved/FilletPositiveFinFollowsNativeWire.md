# Fillet positive fin follows the native stock edge

The positive fin identifies the ordered native stock faces of a saved
SOLIDWORKS fillet. A generated rectangular prism with the same positions
and permanent side roles can give the corresponding edge the opposite
direction. On the disclosed axial rail the generated role sequence is
the exact reciprocal of the native sequence. The transverse rim already
matches.

Compare the actual native stock directions and their face roles before
using a modeled coedge sign in a fillet reference. A global reversal
would change the correct transverse roles. [Exact boundary evidence](../../../../../../re/solidworks/records/EdgeFilletConstructionBoundary2026.md)
