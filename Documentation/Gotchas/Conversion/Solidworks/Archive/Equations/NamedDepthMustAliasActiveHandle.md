# A named depth equation must alias the active handle

A forward blind boss can retain a second display dimension with the same cached length as the active depth. An equation with the expected caption and scalar can still point to that dormant dimension. The active display is owned by `moEndSpec_c.f18` and the inactive display by `f20`.

Use the relation's local clone and its actual live handle to verify the target. For an independent dormant value, verify that its display, handle, dimension and parameter belong to the same resolved boss end and have distinct identities. Keep the inactive value out of the neutral feature's active second direction.
