# Saved biography uses embedded telemetry

A new generated file can have zero Biography records. On open and save, SOLIDWORKS can retain populated records with actual machine, path and capacity observations. Several saved parts and an assembly contain one record. A separately edited drawing contains two.

Each Biography record embeds start and end telemetry directly. Those records add no class or object slots to the independent archive map. Decode the full ordered arrays for saved-file verification and derive their serialized counts from their actual rows. Construct an empty biography for a fresh file.
