# KeyWords empty tags follow the stream profile

Compact `/>` and space-padded ` />` express the same empty XML
element. The difference changes a reconstructed KeyWords stream's
bytes. The tracked native corpus uses the compact form. The disclosed
ConcaveOwned generated control uses the spaced form.

Carry the verified style into the framing call. Pass actual XML
elements with ordinary attribute and character data. The serializer
escapes a literal ` />` in those values before compact mode removes
spaces from empty element delimiters. Comments and processing
instructions use separate serializer branches and fall outside this
tree contract.
