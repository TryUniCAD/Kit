# KeyWords sketch type depends on the profile

The internal typed emitter accepts a `Sketch` without `Type` when
its dissection flag is true and the generated index contains a degree
dimension. The ordinary generated revolve uses that form for its sketch.

The native L1 boss index has a `Sketch` without `Type` and carries
two linear dimensions. It uses compact empty tags. The framing control
uses the measured style to reassemble that XML. Native shape vocabulary
can differ from the generated profile vocabulary.
[Native L1 framing control](../../../../../../re/solidworks/records/KeywordFrameSlice2026.md)

Use the typed emitter for its documented generated profiles. Preserve
the native row and its observed style when checking XML framing.
[Typed profile evidence](../../../../../../re/solidworks/records/KeywordModelSlice2026.md)
