# A corner prism predictor cannot validate centered source geometry

The first generated nested discovery predictor admits four ordered rectangle vertices starting at `(0,0)`. The native nested-source cohort instead uses a centered Front Plane rectangle. Reusing that predictor by shifting only the generated sketch would change local centroids, child placements and world geometry.

Preserve the source local frame and explicit vertices. The sealed source-spec adapter derives the centered neutral rectangle and reuses the earlier locked native-source predictor for independent geometry and transforms. The existing corner-prism predictor and all writer files retain their hashes. Both disclosed source cases passed semantic matching and separate guarded generation. Native behavior of the sealed generated candidates remains unmeasured. [Source custody and prediction protocol](../../../../../../re/solidworks/records/SealedNestedAssemblyEvaluation2026.md)
