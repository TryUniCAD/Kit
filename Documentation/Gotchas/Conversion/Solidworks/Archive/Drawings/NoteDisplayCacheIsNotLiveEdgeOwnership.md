# Note display data is not the live edge owner

A displayed note's cache array or display-object ID is insufficient to identify its attached child edge. The pinned display attachment getters resolve the actual component detail item and its attachment list. Their parametric wrapper must contain a type-checked component edge with the actual component/file/configuration and child topology.

The store preamble also synchronizes cached values into the live parametric point. Assuming the opposite direction, or assigning every generic cache element a class from a folded export spelling, can silently join the wrong graph. Preserve live/fallback and cache records separately. Require actual saved object tags and aliases plus independently resolved complete child topology before portable projection.

The [source checkpoint](../../../../../../re/solidworks/records/DrawingNoteAttachmentOwners2026.md) records exact fields and remaining boundaries. No successful saved-note lifecycle is yet part of this evidence, so current unsupported note guards remain necessary.
