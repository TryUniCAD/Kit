# Drawing diagnostics need every control and generated pass

The base generated-front observer exits successfully when its comparison is interpretable. That condition requires healthy pristine brackets and the presence of reduced/generated lanes. It does not require the reduced lane or generated result to pass.

A wrapper that treats this exit as generated native acceptance can therefore overstate a failed controlled experiment. Read the generated result and every control result separately, require fresh-process independence and immutable inputs, and retain the base interpretable field.

The strict property-prefix front observer requires pristine before, reduced native, generated edit/save/reopen and pristine after in eight distinct processes.
