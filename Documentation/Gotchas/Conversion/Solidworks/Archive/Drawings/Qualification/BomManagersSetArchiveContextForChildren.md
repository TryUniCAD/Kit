# BOM managers set archive context for children

The BOM-manager wire body is a signed count and tagged references, but the native serializer also changes a runtime archive helper word around that loop. It sets helper `+0x838` to one before read/store and clears it to zero on normal return. It does not serialize that word or restore its previous value.

The count/reference body therefore does not prove every populated child grammar, nested context, or exception-preservation rule. The exact archive-mode predicate is `IsDBStream`, whose alternate object methods belong to `su_CDBArchive`; that branch is outside the ordinary codec.

Preserve the source collection through the independently bound raw rule and leave unsupported concrete child bodies fail closed. Trace the child and helper context before admitting populated BOM semantics. Do not emit a helper word, assume context preservation, replace rows with an empty collection, or claim BOM-family acceptance from the parent body alone.
