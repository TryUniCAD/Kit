# Shared serializer symbols need concrete binding

A serializer-map symbol can name an unrelated class at a shared function entry. The recorded system-scale serializer name refers to a destructor, while the object dump labels the same three-byte return entry as a UI property-page method. Neither label identifies the actual serialized class.

Bind the original image hash, concrete RTTI, actual primary table and serializer slot first. Decode every instruction reachable from that actual entry and retain complete bounds. Here those independent facts prove an empty `moScaleSysScale_c` body; they do not prove a fresh constructor or a universal model-style default.
