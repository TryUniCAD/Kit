# A writer audit excludes the explicit source read

A preserved-document conversion must read its explicitly supplied source before it can construct the neutral document. The writer's zero-input-read audit starts after that read, public JSON transport, module preloads and typed neutral restoration. Reporting zero private reads for the whole operation would be wrong when the explicit input is a guest-private canonical source.

The guest observer counts one private canonical source file per SDK build, separately from zero original-native source files and zero guarded writer model/template reads. It retains all detailed records inside the guest and exports only the defined status/hash/count allowlist. The unchanged generator still consumes only structured neutral owners during emission.
