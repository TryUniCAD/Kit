# A saved circle can retain its original inactive depth

An ordinary forward blind boss has separate first and second length objects.
After editing the first length and saving the disclosed circle, SOLIDWORKS
writes 21.122625 mm to the active first slot. The second slot still holds
17.825 mm. The second end remains inactive. The saved chooser bounding
centers can also retain their earlier values.

Use the end mode and the actual forward display handle to select the driving
length. Compare the linked output atom and the physical cap stations before
claiming geometry. Two different length records alone do not establish a
two-direction boss.
