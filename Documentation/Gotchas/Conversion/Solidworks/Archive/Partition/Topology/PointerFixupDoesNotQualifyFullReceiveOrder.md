# Pointer fixup does not qualify complete receive order

A generic decoder that replaces a transmitted reference ID with the corresponding received node pointer might appear to prove the kernel preserves every topology chain until enumeration. In Parasolid 37.01.250 it proves that narrower reference-substitution boundary, while the receive core continues through other compatibility and normalization helpers before the public API returns. SOLIDWORKS load and optional rebuild follow it.

Keep the assigned-link decoder rule separate from full load/order acceptance. For a runtime discrimination, correlate the same actual body and typed chain pointers immediately after the matching node receive and at the successful receive return or actual array fill, without deliberate rebuild. Require genuine delivered stops and controls. Do not equate transmit indices, permanent IDs, tags or wrapper handles.

The [pinned source record](../../../../../../../re/solidworks/records/ParasolidReceiveChainLinks2026.md) documents what is proved and what remains open. It records no new native observation and does not reclassify prior warning-32 cache failures.
