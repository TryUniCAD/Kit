# Parasolid new node counts include process pointer fields

The selected mark's `n_new_nodes` describes runtime allocations. The
rollback stream lists the subset with transmit indices. The kernel allocates a
pointer-values node for a positive-length application pointer field and
marks that class nontransmittable. A one-element array containing a null
application pointer still has an allocation.

For the ordinary rectangular boss, two such fields belong to each face
identity and another five belong to body attributes. The six disclosed
rectangles all have 17 more runtime nodes than emitted deletion pairs.
Count the constructed pointer-field allocations separately from the
emitted rollback references.
