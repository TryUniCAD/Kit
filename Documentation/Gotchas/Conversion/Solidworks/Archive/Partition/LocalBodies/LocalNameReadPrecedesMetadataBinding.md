# Read the local name before publishing body metadata

`ReadLocalName` validates the public design body against the raw selected local topology before `BindBodyName` attaches the resolved label and ownership data. Running that stage on the final `open_document` result rejected both disclosed generated label arms with `public geometry differs from the selected native local body`. The final B-rep already had the name and native ownership attributes, so it differed from the just-decoded intermediate B-rep used for the equality check.
