# Bare cylinders require periodic local geometry classification

Both generated cylinder kernels pass native binary exchange. When
attached to completed local part archives, the SDK selects the same
kernel bytes and the actual BaseBody feature and storage group. The
original planar classifier refuses their periodic node inventory.

The scoped periodic reader checks the retained body owner and actual
rollback before interpreting the circular rims. It derives neutral
seam vertices from the two vertex-free native periodic edges.
