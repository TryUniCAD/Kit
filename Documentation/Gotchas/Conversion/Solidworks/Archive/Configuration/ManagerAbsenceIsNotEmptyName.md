# A manager's absent name is not empty text

A configuration manager can have an actual null `moNode_c.f18` while the model and every configuration have ordinary nonempty names. The pinned 2026 owner constructor supplies that state, and all four disclosed ordinary source managers retain it.

Treating this as `moNodeName_c(f08="")`, copying the model name, or substituting the configuration name changes ownership and the independent CMgr archive map. Equal names and IDs also do not prove that current selectors reference the actual owned configuration.

Pass explicit `None` through the lower `ManagerInput` factory when that is the authored intent. Keep normal named defaults. Use `ReadMgrName` and the bounded `ReadMgrIntent` to distinguish null from missing/empty/wrongly typed owners and to verify exact selector aliases. The latter refuses nonordinal or otherwise unmodeled source directories rather than repairing them.

The [source/constructor record](../../../../../../re/solidworks/records/ConfigurationManagerOptionalName2026.md) and [guarded receipt](../../../../../../re/solidworks/measurements/2026/ConfigurationManagerOptionalNameProcess01.json) preserve the independent source and generated evidence. This does not qualify complete original source conversion or the newly generated unnamed files in SOLIDWORKS.
