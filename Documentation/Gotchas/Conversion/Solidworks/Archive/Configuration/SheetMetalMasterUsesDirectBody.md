# A configuration master has a direct feature body

The part's signed f1014 selector governs the presence of f1018. A nonzero
selector enters the concrete sheet-metal master body directly. The body
uses its own virtual inheritance and does not start with an outer archive
object or class tag. It receives no independent archive slot.

Give the child a concrete schema and a separate field scope. Retain the
part's existing archive context. Treat any inner reference according to
its actual inherited field. The ordinary measured body has an empty
per-body list.
