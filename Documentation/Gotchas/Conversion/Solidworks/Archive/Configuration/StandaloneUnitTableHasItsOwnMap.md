# The standalone unit table has its own map

The ordinary assembly's `Contents/User Units Table` reproduces the
actual `Config-0` model user unit graph. The standalone member uses
a new archive map starting at one. The embedded graph follows the
parent's inherited map. Copying the encoded embedded object span
can leave incorrect class references, including the dual length
child's reference.

Serialize the actual user unit object in its own map. Compare all
typed fields and the complete stream with the linked model before
qualifying a source mirror. The XML unit system and mass preferences
use their registered API enums, which differ from this binary
archive's enums.
