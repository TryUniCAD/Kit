# A present feature color table uses schema zero

An ordinary part can store either a schema-zero `moFeatColorTab_c` or a
null node at `moPart_c.fa88`. The ladder control declares the concrete
class and allocates its object. The concave control consumes a two-byte
null node and keeps the map counter unchanged.

Select the member role before decoding it. Preserve the schema zero word
on a concrete feature color object and leave the map alone for the null
branch. The concrete object's unsigned count word has its own signed
repeat interpretation.
