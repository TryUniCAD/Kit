# Verify native base-flange thickness direction

A planar profile and positive thickness do not establish which side of the world datum the API thickens. The first SP04.1 capture at revision f3c6c2f2 stopped after the base flange rebuilt because the resulting solid did not match the intended positive-Z body bounds. Its independent stock opens before and after authoring passed. The failed run did not record the rejected bounds, so the displacement and its cause remain unmeasured.

Capture the native extreme-point bounds and typed base-flange properties before any correction. If an exact negative-Z reflection is the only candidate with the intended profile and thickness, reverse the typed thickness direction, rebuild, and measure the positive-Z body before saving. Preserve the initial and revised bounds in the receipt. Reject other mismatches. The setter requires explicit sheet-metal parameters without material-driven parameters.
