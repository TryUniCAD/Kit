# A saved pattern cache cannot prove feature history

A native version-19000 part can carry a readable Parasolid cache and a known
linear pattern feature while the typed reader still cannot resolve its
saved atom and feature history. Both strict read modes refuse this combination.
Use permissive inspection to see the unresolved feature and cached solid.
Use explicit Parasolid extraction to retrieve the exact saved geometry payloads.
