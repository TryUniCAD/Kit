# Frozen source staging needs canonical paths

Kit's Git release archive omits the root `re/` directory through
`export-ignore`. A frozen native-format research process needs its tools
from the pinned Git blob paths. Extract the named source paths from the
pinned tree with `git ls-tree` and `git cat-file --batch`.

On macOS, a temporary directory can be returned under `/var` while the
grammar registry enumerates its resolved `/private/var` path. The
construction auditor checks the named initialization directory. Resolve
the temporary root before constructing the auditor or passing the root
to a child process. The assembly reproduction first missed the exported
research script, then reached `no schema for moHeader_c` because the
registry directory and auditor used different spellings.
