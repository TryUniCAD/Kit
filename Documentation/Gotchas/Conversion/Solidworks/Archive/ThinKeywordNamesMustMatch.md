# Thin-revolve keyword names must match their resolved owner

A cache-free thin revolve publishes a feature name in KeyWords and stores
its actual name in ResolvedFeatures. A mismatch can pass class and
feature-ID matching and fail later during neutral body binding.

Check both names during typed admission. A strict read then reports
unverified typed history with the name mismatch as its cause. A permissive
read can continue through legacy inspection and withhold the unverified
thin feature and analytic solid.
