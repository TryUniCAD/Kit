# Circular fallback requires the blind end family

A saved mid-plane or two-direction boss can have the same resolved
feature count and circular sketch as the blind-boss archive. Its end
specification still selects a different native record path. Shared main
integration exposed the blind fallback trying to open a packaged layout
during a guarded read of these already resolved profiles.

Use the reached extrusion end to qualify the legacy circular fallback.
An independently resolved mid-plane or two-direction end stays on its
existing reader path. Qualify the rectangle fallback with the reached
profile so a sole closed circle avoids the rectangle layout as well.
