# Scalar difference counters need field occurrences

Expectation: a recursive canonical graph comparison can memoize visited value-identity pairs to avoid cycles and count all different fields.

Actual behavior: applying the memo to Python scalars suppresses distinct fields that contain the same source/target pair. Small integers commonly share Python identities. The original diagnostic therefore reported 13/14/14 Definition frontiers and 20 CMgr frontiers instead of the corrected pre-view 16/18/18 and 29. Product source and output were unchanged, and the complete source gate never depended on these counts.

Workaround: memoize only actual composite graph pairs. Compare scalar occurrences at their own field paths. Reparse generated bytes before comparison, keep unequal-array/count frontiers explicit and retain old reports as historical observations. The new independent source inventories perform exact stream re-emission and preserve the full-source refusal.
