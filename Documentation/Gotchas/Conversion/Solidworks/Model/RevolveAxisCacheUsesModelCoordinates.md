# The revolve axis cache uses model coordinates

The selected construction line belongs to the sketch and stores endpoints in
sketch coordinates. The revolve axis wrapper stores its line start at
`fc8` and unit direction at `fe0` in model coordinates. A Front Plane
profile can hide the difference because its basis is the identity.

Transform the neutral axis endpoints through the sketch frame before
comparing the wrapper. An upward Top Plane line has model direction `−Z`.
The archived span remains a length in metres. The original held-out
verifier rejected the second prediction at this comparison while the
independent native files and measurements remained sealed. The generator
stayed pinned while the verifier was corrected.
