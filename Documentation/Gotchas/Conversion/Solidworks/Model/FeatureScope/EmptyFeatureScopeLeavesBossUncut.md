# Empty feature scope leaves the boss uncut

A generated rectangular boss with a circular blind pocket opened and rebuilt when the request selected all bodies. The same model with feature scope and an empty selected-body array opened with warning 32. The cut feature reported error 71 and its solid had the uncut boss volume.

Use all-bodies scope when it expresses the authored intent. Preserve selected-body scope by deriving its actual persistent references before generating the cut.
