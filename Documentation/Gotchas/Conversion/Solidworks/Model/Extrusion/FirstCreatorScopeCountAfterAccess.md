# First-creator scope count can be zero with an absent array

The exact SOLIDWORKS 2026 SP05.2 direct definition returned count `-1` for the measured scoped first bosses. In fresh read-only processes with selection access, the same owners returned count zero and an absent body array. The corresponding selection access on the two-body cut returned count one and a one-entry array. After release, both first-boss designs rebuilt their single solid with zero issues.

Use the observed count during selection access to interpret the absent array. Measure before and after rollback independently and close without saving. [Controlled selection access](../../../../../../re/solidworks/records/FirstCreatorScopeNativeProtocol2026.md#native-result)
