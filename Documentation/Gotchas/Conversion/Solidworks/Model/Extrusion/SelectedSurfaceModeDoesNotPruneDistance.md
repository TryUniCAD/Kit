# Selected-surface display pruning follows dialog application

The extrusion packet's selected-surface setter clones the actual surface reference and stores native end type 4. Existing distance displays retain their objects during that managed update.

The complete native end-dialog operation also reaches `recreateNecessaryDisplayDims`. Its type-1–4 prune branch can destroy and clear the inactive distance display under the selected environment predicate. Other branches retain or allocate a display.
