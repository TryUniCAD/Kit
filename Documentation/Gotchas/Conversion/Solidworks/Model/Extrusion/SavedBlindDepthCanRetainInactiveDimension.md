# A blind save can retain the inactive depth before the edit

A native-saved single-direction blind boss can retain its inactive
`moEndSpec_c.f20` display after a live D1 edit. In both measured
rectangles the display keeps its distinct original depth. The active
`f18` display has the new depth. The retained zero draft displays also
have independent owners.

Read the actual direction and termination flags before choosing the live
driver. Validate the saved end displays separately. Keep only the active
depth in the ordinary single-direction neutral definition.
