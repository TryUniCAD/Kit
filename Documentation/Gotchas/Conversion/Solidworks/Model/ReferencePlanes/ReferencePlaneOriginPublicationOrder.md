## Expectation

A generated ordinary part retains the native source's feature-history order when its offset plane, supported sketch and blind boss are otherwise valid and editable.

## Observed boundary

The qualified source author starts with `new_part`, which already owns its principal planes and Origin, then calls `InsertRefPlane`. The native source therefore places Origin before the authored offset datum. The initial generated hook allocates and publishes the new plane before Origin. Its body, dimension edit and save/reopen can pass while that source-history order differs. The older independently authored system-folder recipe also adds a separate top-level notes-area row, so its 27-row self-persistence proof does not equal the source's 26-row tree.
