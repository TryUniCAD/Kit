# Offset sketches use a separate origin

An authored offset plane moves its supported sketch and resulting boss. The separate document-origin feature stays at model origin.

The shared research origin constructor rejects a nonzero semantic model origin. Routing both the origin feature and profile through the new offset frame therefore fails before a file is generated. Keep the document-origin feature on the selected model-owned principal support and at the model origin. Route the ordinary profile through the actual offset-plane ID, kind zero and computed offset frame.

The [offset construction record](../../../../../../re/solidworks/records/ReferencePlaneOffsetConstruction2026.md) and [guarded process proof](../../../../../../re/solidworks/measurements/2026/GeneratedOffsetPlaneComposition01.json) record this distinction. The generated plane candidate remains subject to independent native load/edit/rebuild/save/reopen acceptance.
