# A zero coordinate does not declare an origin coincidence

An anchored and an unanchored rectangle can start at the same model
origin. Their editable constraints differ. The scoped equation
preparation requires an explicit fixed construction point at zero
and an active coincidence to the contour's actual first corner.

Bind the coincidence to the true shared endpoint before projecting
the lines. Then construct the native origin relation through the
shared anchored constructor.
