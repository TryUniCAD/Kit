# Native save may omit the keyword material attribute

All three disclosed local imports have an unassigned material owner.
The original keyword index includes the unassigned configuration label.
SOLIDWORKS omits that configuration attribute when saving the generated
parts. All 25 role, name and tag rows remain, including the original
generated import ID.

The saved keyword root also takes the actual generated part name and
its modeled save time. Bind configuration material to the typed
material folder, and retain the presence or absence of the XML
attribute independently during source projection.
