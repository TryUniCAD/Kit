# Local notes follow cabinet member ownership

The measured part archive stores an empty notes head and end under
the annotation cabinet's member list. The two nodes retain reciprocal
partner pointers. Their individual feature bodies omit an explicit
parent field. The native name scan can also leave the end tag's class
empty even when the declared object is present.

Resolve both actual member objects through the cabinet and the shared
archive map. Bind each indexed caption and ID to a name position inside
the corresponding object's byte range. This preserves the ordinary local
solid geometry when the same part carries the measured empty notes pair.
