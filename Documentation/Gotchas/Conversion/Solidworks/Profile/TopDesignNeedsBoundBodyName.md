# A design-only Top box uses the body folder's name

A full strict read of the generated Top rectangle binds the body's
authored name to the archive's output atom. The design-only request
retains the actual sketch, fixed origin and three length parameters.
Its body view uses the `Solid Bodies` folder label because the body
atom's name is only bound by the full reconstruction in this profile.

Read the full linked solid before preparing an exact regenerated
Top part. The name is an authored value even when the sketch geometry
and dimensions are identical. [Companion proof](../../../../../re/solidworks/records/SdkTopCornerColdReadback2026.md)
