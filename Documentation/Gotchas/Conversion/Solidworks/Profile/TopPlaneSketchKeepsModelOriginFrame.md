# A Top-plane sketch keeps the Front-plane model origin owner

A Top-plane sketch uses local U along model +X, V along model −Z and normal along model +Y. The model origin profile keeps its independent Front-plane transform. In the disclosed signed rectangle, the two length handles select the origin corner and the endpoints of its two adjacent edges. The negative local V run retains a positive driving value.

Build the two owners in their own frames. Bind the external origin proxy to the model origin profile and derive the dimension display direction from each actual signed edge. Geometry in negative model Y requires the boss reversal flag with a positive blind depth.
