# Display-state appearance retains its own material ID

A part display-state holder and its live model appearance resolve the
same stock resource in the disclosed SOLIDWORKS 2026 child. The live
model and configuration advance from render-material ID 7 to ID 10
after synchronization. The holder stays at ID 3 and all of its typed
visual store bytes remain equal.

Use the actual allocation event for each assignment. Preserve the
holder's independent ID, locator and property ownership while updating
the live model or configuration. The next ID in Definition belongs to
the document allocator.
