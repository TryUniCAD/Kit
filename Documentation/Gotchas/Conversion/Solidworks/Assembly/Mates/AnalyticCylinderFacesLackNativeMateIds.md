# Analytic cylinder faces lack native mate IDs

An exact public cylinder B-rep may appear sufficient to construct a selected native concentric face. The normal generated circle parts instead omit the kernel partition and body atom manager/output. Their public reader reconstructs analytic faces with model-owned IDs. Those names do not establish a native face's wire index, persistent kernel `node_id`, body atom, or `FACE_ID_2001` owner.

The generic analytic encoder can round-trip this geometry under its own transmit schema without creating the missing SOLIDWORKS attributes or activating the feature output. Keep such a standalone stream separate from a native endpoint qualification. The archive's manager counter and the next possible atom number also do not prove that an atom exists.

Retain the actual generated part, profile, arc, extrusion and header owners, then require a separately proved kernel/body publication before writing the selected face and faceted snapshot. Preserve the optional-vector construction gate. Never substitute an observed saved face ID, a public face suffix or a fabricated output atom.
