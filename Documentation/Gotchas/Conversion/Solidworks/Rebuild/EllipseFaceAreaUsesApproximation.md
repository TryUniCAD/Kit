# IFace2 reports approximate ellipse face area

On SOLIDWORKS 2026 SP05.2, the first ellipse boss's top cap reported `0.0005960569721448918` m² through `IFace2.GetArea`. The independently specified and observed carrier radii give `0.0005959699438630264` m². The two values differ by about 146 ppm. The API documents that `GetArea` calculates an approximation. The failed source stopped before the native whole-body observations and saved no part. [SOLIDWORKS GetArea API](https://help.solidworks.com/2026/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IFace2~GetArea.html) · [Disclosed failure and procedure](../../../../../re/solidworks/records/EllipseBlindBossSource2026.md)

Keep the approximate value in the record. Verify the actual full-period native edge and single physical cap loop before deriving cap area from the observed ellipse. Measure the selected native solid independently with higher-accuracy SI mass properties. Apply the original precision requirements to body volume, total area and centre of mass.
