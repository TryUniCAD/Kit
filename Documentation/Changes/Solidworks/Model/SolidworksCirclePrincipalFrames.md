# Principal-plane circle construction

The shared radial constructor now admits the existing origin-anchored Front, Right and Top plane frames. It rejects other frames and off-plane text. `text_point_m` remains an authored world-space point; center coordinates remain local to the sketch. All new native output and acceptance remain research-only.

The model computes the native ordered frame operations explicitly: circle center through inverse profile frame, authored text through profile frame, world center back through profile frame, and final reference cache through the profile frame and inverse fresh identity delta. Direction, length ratio, offset and reference-distance cache use those results. A null optional handle transform supplies the documented fresh identity delta; it does not make the actual profile frame identity. The construction adds no stored value table or saved-file input.

`PlaneFrame.sketch_point` supplies the inverse of the existing orthonormal model frame. Its pure vector operations serve the common model; only the three explicit principal frames enter this radial writer rung. Arbitrary translated/rotated planes remain closed. The native inspector obtains its expected basis from the neutral plane axis and computes expected center of mass as `cx*u + cy*v + depth*normal/2`. Actual native frame observations are checked separately.

Two independent subprocess requests vary local centers, radii, depths, world text positions and radial modes on Right and Top planes. Each retains all eight complete archive comparisons and runtime read/process guards. The existing Front-plane requests remain unchanged. Remote generation and controlled native measurements for the new frames remain pending. The native body/edit inspector still requires healthy controls, one body, exact fixed-center relation, fully constrained status, radial/depth edits, saves and fresh reopens.
