# Shared line and arc topology in generated sketches

The research constructor accepts `profile_kind: capsule`, `feature_kind: sketch`, `center_m`, positive `radius_m` and `straight_length_m`, and finite `rotation_angle_rad`. It computes four boundary vertices and two distinct arc centers, then composes two ordinary lines and two semicircular arcs in the requested principal plane. Degenerate or unrepresentable geometry fails explicitly. Capsule bodies, driving dimensions and general mixed profiles remain closed; the public adapter remains read-only.

The new shared geometry composer serves circles, open arcs and this mixed graph. It computes point creation order from line/arc permanence roles, distinct incident segments for endpoint adjacency, actual center/endpoint counts, per-type creation IDs, global eligible-segment marker IDs, next counters and initial modification stamp. It allocates a separate concrete handle in each retained endpoint slot and refuses unsupported branching or reused circle markers. The arc contour-admission field checks both actual adjacency slots, allowing an arc to follow a line without assuming that its handle occupies the first slot.

Two remote process requests vary center, radius, straight length, in-plane rotation and principal plane. All existing circle/arc process checks remain active after the shared implementation change. The native inspector checks each line and arc, local endpoints, radii, arc directions, frame, initial active sketch, zero-body state, explicit rebuild, save and fresh reopen between controls. It additionally requires the four joins to share actual native point identities; coincident coordinates alone do not pass.
