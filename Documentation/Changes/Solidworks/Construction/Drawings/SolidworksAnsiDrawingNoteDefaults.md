# Internal ANSI defaults for drawing notes

The internal single-note constructor accepts explicit native detailing
standard zero. That path builds the documented ANSI detailing defaults and
the ten actual drawing views in the shared model graph. The first view is
`*Full Sheet` and the remaining nine are named `Unused`. All ten retain their
construction-time identity transforms. These model detail owners are
independent of the Definition's UI standard class.

The [guarded note worker](../../../../../re/tooling/sw2026/drawing_notes/BuildNoteSdk01.py)
accepts `"detailing_standard": 0` in the explicit research intent. The
existing standard-one default produces the earlier disclosed outputs.
The [drawing initializer record](../../../../../re/solidworks/records/PlainDrawingDefaultViews2026.md)
and [ANSI details record](../../../../../re/solidworks/records/DrawingAnsiStyleConstruction2026.md)
identify the exact build and construction rules.

The first closed ANSI archive passed guarded generation and exact Definition
read and re-emission. The disclosed pair and both controls opened and rebuilt
cleanly. The source and candidate reported the same 3.175 mm text height and
complete ordered tree. Their display baselines still differed by about
0.070 mm, and the candidate viewport remained byte-identical to the earlier
grid-only result. See the [native comparison](../../../../../re/solidworks/measurements/2026/AnsiDrawingNotePresentation01.json).

The option is internal. Original drawing admission, rendering and the
locked source cohort remain open.
