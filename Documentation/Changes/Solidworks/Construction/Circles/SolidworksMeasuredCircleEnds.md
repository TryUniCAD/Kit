# Read and prepare measured fixed-centre circle bosses

The strict SOLIDWORKS 2026 part reader recovers standalone cache-free
fixed-centre circle bosses on the qualified Front, Right and Top supports.
It preserves the actual radial driver, signed extrusion direction and live
depth owner. A mid-plane boss uses a single total length. A two-direction
boss retains separate editable D1 and D2 lengths. Default inspection binds
the analytic solid to the design body. Use `include_brep=False` for editable
history without the solid.

A shared preparation and publication leaf accepts explicit neutral circle
intent and a matching authenticated offline native report in the existing
`solidworks_native_measurement` options envelope. It generates the complete
file before comparing its SHA-256 and opening the destination. The ordinary
writer dispatcher requires the two documented scope selections before callers
can use this leaf through the SDK. Exact authentication limits publication to
candidate bytes bound to prior native evidence.

Six disclosed reports reproduced the complete measured files, including all
ten streams per file, from authored and neutral JSON round-trip inputs. Both
strict read modes preserved the corresponding geometry and driver semantics.
The separate proposed-dispatch proof exercised registry, direct writer and
adapter destinations. The [scope and integration record](../../../../../re/solidworks/records/AggregateCircleEndPort2026.md)
lists all measured combinations, replay commands and remaining native-to-native
limits.
