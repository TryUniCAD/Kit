# Prepare a fresh open shell from strict SDK readback

The internal SOLIDWORKS shell constructor can reconstruct the complete archive from a strict full or design-only SDK read of its generated cold shell. It takes the original locator and creation epoch. The construction uses the verified Front-plane rectangle, both live dimensions and the shell's selected upper stock cap.

The constructor rereads its generated bytes and compares the complete supplied source, including the body, provenance and stored archive identity. It returns the in-memory candidate only after that comparison. The scoped actual saved-shell files remain strict inspection inputs and require their separate saved-state construction rules.

Four guarded workers completed 16 exact candidate comparisons across full and design-only reads and their inspection JSON round trips. They also refused 56 altered source or output settings and 16 public write attempts on the strict readbacks. Public shell publication still requires measured native and held-out acceptance.
