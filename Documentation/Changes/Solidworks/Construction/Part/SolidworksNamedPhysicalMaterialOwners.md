# Construct ordinary SOLIDWORKS part material owners

The shared internal binder accepts an explicit catalog key, material name and positive SI density for a fresh part with one active configuration. It builds the part density subtree and attaches the duplicate configuration density and named visual identity to that actual configuration before stream allocation. This scope uses the two-token catalog identity and constructor appearance. Public conversion requires additional source appearance and catalog semantics.
