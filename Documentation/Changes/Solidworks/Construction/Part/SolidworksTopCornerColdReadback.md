# Reconstruct an anchored Top box from strict readback

The internal SOLIDWORKS preparation path can re-create a cache-free signed
Top-plane box from its complete strict SDK read. It binds the real profile
and body creator, restores the fixed origin coincidence and both sketch
dimensions, and retains the independent height and authored body name.
The existing rectangle writer supplies the archive. The regenerated part
must reproduce the entire strict read, including source identity.

Three disclosed model-only subprocesses regenerated byte-identical files
with zero runtime input reads. Each process checked signed geometry,
linked topology and live driver ownership. One input exercised a one-ULP
display rounding difference. Invalid ownership, a changed origin, changed
source state and changed publication inputs failed before output.

The preparation function requires full geometry with a bound body name.
Public publication of these regenerated files still requires an exact
passing native measurement. [Evidence and reproducible command](../../../../../re/solidworks/records/SdkTopCornerColdReadback2026.md)
