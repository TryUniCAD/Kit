# Count rollback nodes by their allocated owner

The shared SOLIDWORKS partition model counts runtime nodes for a rollback
arm from its real allocated records and their model-owned hidden pointer
slots. The attached cylinder uses this count for its selected partition mark.
The resulting cylinder files match both previously measured concentric
part and assembly pairs byte-for-byte.

The offline audit verifies both allocation directions on the two disclosed
ordinary single-edge fillets and their radius edits, plus the disclosed
axial candidate's saved derivative. The rule covers new and deleted
node counts. The fillet's processed copy count and complete result
construction remain open.
