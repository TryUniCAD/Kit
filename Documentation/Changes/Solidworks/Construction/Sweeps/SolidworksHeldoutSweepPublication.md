# Publish the two held-out Standard swept bosses

The SOLIDWORKS writer can reproduce two additional measured Standard swept
boss parts through the registry, adapter and direct writer. Each neutral
part has one driving Right circle, one driving Front quarter arc and a
body-owned density. Set the authored `solidworks_platform_view_math`
metadata flag to true for these two cases.

Set `receipt.native_report` in `solidworks_native_measurement` to the exact
UTF-8 text of the redacted native report. Supply the measured
`final_destination` and the original `written_at`. Publication checks the
complete regenerated bytes against the measured digest. A changed model,
destination, epoch or receipt leaves the binary sink empty.

The guarded Windows replay reproduced both native-tested files from
authored neutral documents and their JSON round trips. It also re-emitted
Config-0, ResolvedFeatures and GhostPartition from their typed objects.
