# Disclosed SDK rectangle dimension inspection

`InspectSdkRectDims.py` measures disclosed SDK-generated rectangle drivers using
ordinary documented SOLIDWORKS COM. It reuses the existing exact-build controller,
control inspection, call recorder, feature-tree projection and sketch geometry
readback. It adds no native hook, executable patch or licensing operation.

The frozen packet binds the actual neutral requests, complete build/preparation
and independent mathematical reports, ten stream identities, generated files,
39-path writer manifest, complete source closure, installed enum metadata and all
observer tools. It rejects an existing authored native destination before the first oracle launch unless an exact pinned previous trial proves its unchanged candidate hash and size. It never overwrites an input, and derivatives use unused owned output directories.

For two disclosed designs, the proposed batch has ten fresh oracle processes:
before control; width edit/save and fresh reopen; independent height edit/save
and fresh reopen for each original; after control. A one-design first batch uses
six processes. Every generated edit starts from the immutable original.

Each state checks all three actual named driving dimensions, the ordered feature
tree and support dependencies, four line and point identities, the six relation
owners and relation-to-display-to-dimension ownership. The installed type library
binds distance 1, horizontal 4, vertical 5, unknown constraint state 1 and under
constrained state 2. After rebuild the deliberately unanchored rectangle must be
under constrained. First-load unknown state is recorded and may proceed to the
mandatory rebuild; invalid, over constrained and unexpectedly anchored states
reject.

The observer derives solid volume, area and mass from the three authored lengths
and density. It verifies the centroid against the actual measured sketch bounds
and depth. XY translation remains free after an edit, so it does not invent an
anchored centre. The exact entity and relation bindings must survive edits and
fresh reopen. Public `GetID` values are not equated with archive map or persistent
allocation indices.

The fixed control's raw mass values are retained before and after and must agree.
The aggregate requires healthy controls, distinct process birth identities,
unchanged tool/source/input hashes, zero native diagnostics and both clean saves
and reopens. Discovery does not establish held-out or public-writer acceptance.

Use `verify PACKET --packet-sha256 SHA256` for metadata admission and
`run PACKET --packet-sha256 SHA256` only through the root-owned oracle. The initial native packet failed in six distinct processes: both controls passed, and all four candidate attempts opened without warnings but stopped at an invalid `ISketchLine.GetID` lookup before edits or complete body measurements. The corrected observer reuses the established segment identity binding while retaining concrete interface validation. Its retry binds the exact failed result and previous input packet. The corrected packet passed in ten distinct native processes. Both originals opened with one body and no warnings, all four independent width/height edits saved cleanly and retained their dimensions, and every derivative reopened cleanly. Twenty native snapshots preserve six relations, their actual point/line IDs, all three driving dimensions and the complete 25-row tree. All 284 candidate numeric comparisons match at six significant figures. Both fixed controls pass with matching measurements and all original inputs remain unchanged. The [sanitized acceptance receipt](../../../../re/solidworks/measurements/2026/SdkRectangleDimensionsNative01.json) binds the exact measured source and packet. Held-out and public-writer qualification remain separate.
