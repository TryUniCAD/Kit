# Typed SDK revolve construction prototype

The research prototype constructs a complete ordinary rectangular revolved-boss part from a neutral document and explicit SDK settings. It allocates real profile, selected construction-axis, angular display/parameter and feature owners, then emits ten logical streams through the existing typed codecs and container. It reads no saved data and emits no Parasolid cache.

This is research construction, with public revolve writing disabled. The only SDK helper extension permits a concrete version-19000 angular revolve owner to reuse the common angular display constructor. The existing polygon writer retains exact bytes. A source-only 30-process proof covers four deterministic generated designs, 18 strict rejection cases and two baseline/candidate polygon pairs. All ten streams round-trip; typed semantic readback and a separately constructed closed analytic solid validate. The controlled native batch also passes for all four disclosed candidates.

Use `make_candidate(document, settings)` from the research construction module. The profile is one Front rectangle and one distinct upward construction axis, with four real contour axis relations and a single positive radian `D1` parameter. Other feature, end, axis, material and property owners reject. The controlled native run verifies the 25-row tree, actual selected axis, four sketch relations and independent solid measures. All four angles edit, save and reopen cleanly between two healthy controls. Original-source equivalence remains open.
