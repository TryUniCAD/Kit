# Generate authored rectangle driver names

The internal dimensioned-rectangle constructor binds the two sketch dimensions and the boss depth through their actual ordered neutral parameter IDs. It carries each authored name into its live parameter owner and the corresponding KeyWords row. Independent native identity allocation and dimension values follow the same geometry and owner rules.

The construction path requires a name that identifies one native parameter without a feature suffix. Each sketch driver also needs a distinct name within that sketch. The registered public assembly writer requires its measured default child names until native named-output qualification.

Two fresh SDK processes independently construct two neutral rectangle designs and repeat each named build byte for byte. Each named variant changes only its ResolvedFeatures and KeyWords streams. A normal fresh SDK read of the generated bytes preserves the actual names, owners and lengths. Construction attempts zero runtime input reads. Native named output, the explicit body label and sealed acceptance remain open.
