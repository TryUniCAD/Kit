# Authenticate standalone SOLIDWORKS part receipts

Ordinary line-loop bosses, full ellipses, Standard sweeps and equal-distance
or two-distance chamfers verify the published receipt digest and the complete
regenerated archive before opening an output path or writing to a stream.
Both measured compression modes for the line-loop boss remain available.

Guarded SDK checks match both disclosed cases per profile. Each profile
refuses a substituted receipt with otherwise valid hash fields and preserves
the caller's output. The sweep proof also matches its full native archive
after the neutral format added an empty feature output link.
