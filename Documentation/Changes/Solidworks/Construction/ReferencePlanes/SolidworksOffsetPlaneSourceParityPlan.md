# Offset-plane source-parity recipe and observer

The earlier disclosed generated offset plane preserves its own 27-row tree, but its native source control has 26 rows. That self-persistence result does not establish source-to-output tree parity. This research addition prepares a disclosed-only generative recipe and a stricter paired observer while both hidden sources remain sealed.

[ReferencePlaneSourceRecipe.py](../../../../../re/tooling/sw2026/ReferencePlaneSourceRecipe.py) maps only the four declared authored source specifications into an ordinary offset-plane, fixed-center driving-radius circle and blind-boss request. It reuses the existing standard folder-role factory, preserves its authored order explicitly and computes world-space text from the canonical principal frame. Its independent prediction records the source geometry, edit and required semantic feature order. It accepts no saved native fields or observation inputs.

[InspectPairedReferencePlane.py](../../../../../re/tooling/sw2026/InspectPairedReferencePlane.py) verifies frozen case, request, prediction and complete code/tool identities. Its controlled Windows run requires exact ordered source/generated trees and plane/reference/parameter identity, generated edit/save/reopen tree equality, unchanged inputs and healthy source brackets. A prepared packet has execution disabled; only root can integrate the private origin-publication patch and bind a committed writer before a new frozen native trial.

The [preparation receipt](../../../../../re/solidworks/measurements/2026/ReferencePlaneSourceParityPreparation01.json) records eight successful guarded generations across four disclosed specifications, eleven round trips per build and zero runtime input-file reads. Four ordinary defaults retain identical output bytes. A replay of actual native observations accepts the healthy source brackets and rejects the unmatched generated tree. The paired typed comparison retains its physical cabinet-order difference; no native paired acceptance is claimed.
