# Publish the two measured held-out oblique linear patterns

The SOLIDWORKS part writer accepts the earlier native measurement for each
independently locked oblique linear pattern. Supply the parsed report under
`receipt.native_report` in the existing native measurement option, with the
corresponding creation epoch and original logical destination. The writer
uses the original view calculation and verifies the whole archive before
publishing it.

Two Windows workers reproduced the 10,544 and 10,533 byte native-tested files
through the registry, adapter and direct writer, including neutral JSON
round trips. Thirty invalid requests preserved their binary sinks. The
workers read zero runtime input files and started zero native processes.
