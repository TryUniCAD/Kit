# Construct principal-plane linear pattern direction

The shared SOLIDWORKS archive constructor can build the direction
reference for a local linear pattern that selects the actual Top or
Right plane. The typed reference uses the selected plane's display
rectangle, native line geometry and matching header identity. The
existing oblique pattern retains its measured public write scope.

Six disclosed 2026 SP05.2 originals and edits reproduce the corresponding
direction fields and both linked streams. Four guarded generated
processes reproduce two independent typed direction members. The
principal profile still requires complete part construction and native
qualification before publication.
