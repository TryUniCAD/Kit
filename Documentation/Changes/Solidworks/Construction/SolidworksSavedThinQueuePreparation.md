The research preparer derives four cache-free native candidates from two independently authored neutral thin-revolve models. A Front two-wall case and a Right midplane case each have an original and a separate angle-and-thickness derivative. Model names match their native self filenames. The SDK source tree must be unchanged, and the output must be a new absolute directory outside the checkout.

```sh
python -I -B re/tooling/sw2026/revolve/PrepareSavedThinQueue.py --output D:/KitResearch/ThinQueue
```

Run the command on Windows because these candidates retain the actual absolute native locator. The preparer records source revision, SDK tree, tool hashes, neutral JSON, candidate hashes, authored dimensions and analytic volume and centroid expectations. The authoring event is fixed at 1795893600 for deterministic repetition. Both constructions of each exact candidate must agree, and construction must attempt zero input reads and external launches.

This tool prepares inputs for native save captures. It does not qualify them or publish a new supported writer profile. A sole oracle owner must measure healthy controls around fresh candidate processes, verify initial open and rebuild, edit and restore the actual angular and wall drivers, save a distinct native file and reopen it in a fresh process. Retain those saved bytes and the complete build-specific receipts before adding saved-thin shared-suite fixtures. The SDK publication and strict saved-history gates remain intact.
