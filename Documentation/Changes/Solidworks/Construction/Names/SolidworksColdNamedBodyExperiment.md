# Cold named-body construction experiment

Adds a research-only constructor and repeatable host/native experiment for an authored body label on an ordinary fresh rectangular part. The constructor computes a shared archive atom, manager ID, feature output array and reciprocal output IDs from the actual generated graph. It emits no Parasolid cache and does not load a saved CAD file.

The six independent guarded source workers passed exact repeated output, an independently generated plain control, two-stream-only differences, complete typed Config/Resolved readback and zero runtime file accesses. Native load/name/edit/save/reopen remains pending at the source freeze. The public writer and no-cache reader are unchanged; neither production acceptance nor named held-out qualification is claimed.

Use `PrepareColdNames.py` against the frozen SDK source manifest and disclosed pristine control, then let the root-owned VM execute the resulting `InspectColdNamedPart.py` trial.
