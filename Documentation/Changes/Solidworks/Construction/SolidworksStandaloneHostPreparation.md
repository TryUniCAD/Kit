# Standalone POSIX part preparation

The internal plain-part bridge now accepts an absolute POSIX output location for
its exact standalone rectangle profile when the caller provides the measured
neutral native self locator. The actual neutral basename is preserved, while the
host/staging destination stays separate from the native self record. Windows/UNC
behavior is unchanged.

The allowed recipe namespace is the independently authored
`C:\KitSdkCandidates`. This is a declared construction policy, not a claimed real
drive mapping or a vendor format constant. No path is probed, opened or used as a
donor. The same typed graph and all ten computed streams are reused. Public
SOLIDWORKS writing remains disabled.

The [native relocation receipt](../../../../re/solidworks/measurements/2026/SdkPartRelocation01.json)
binds two distinct generated designs and eight fresh native processes. The
Unicode-named case proves clean load/edit/save/reopen while its archived C: locator
is absent before and after. This does not admit assembly or drawing dependency
paths. Unnamed streams, unsupported locator parents, basename changes, multiple
models and linked/bundle modes reject. See the [self/dependency distinction](../../../Gotchas/Conversion/Solidworks/Archive/Construction/StandaloneSelfLocatorsAreNotChildReferences.md).

The new guarded host-flow integration compares full bytes across direct/staged
POSIX, binary and Windows routes for two authored neutral inputs, with thirteen
rejections each. The existing bridge integration remains required, including
normal public read and intentional save rejection. Scoped static checks passed.
The independent 4,643-source snapshot passed both permanent integrations and all
four separately captured workers, with sixty-eight rejected requests and zero
runtime input reads/research imports. Both old Windows containers and all their
streams stayed identical. The new host containers are 8,177 and 8,259 bytes. The
[process receipt](../../../../re/solidworks/measurements/2026/SdkStandaloneHostPreparation01.json)
binds exact sources, comparisons and acceptance limits. The
[construction record](../../../../re/solidworks/records/SdkStandaloneHostPath2026.md)
binds evidence, exact source scope and remaining admission limits.
