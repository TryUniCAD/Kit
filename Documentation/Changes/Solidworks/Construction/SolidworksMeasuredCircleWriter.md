# Measured SOLIDWORKS circle boss publication

Kit builds a version-19000 ordinary part with a closed analytic circle, fixed
centre, live radial driver and live blind-boss depth. The shared part recipe
allocates the sketch, support, two distinct native `D1` owners, feature and
single body from the neutral document. It generates all ten streams from typed
fields and requires no SOLIDWORKS runtime or input files.

The neutral planner covers a forward, diameter-driven Front-plane boss and
a reversed, radius-driven Top-plane boss. Each model requires one unmodified
active configuration and one solid, in millimetres. Public writing also needs
trusted native evidence matching the complete regenerated file. Supply
`values["solidworks_native_measurement"]` with the measured `written_at`
epoch and the parsed circle `receipt`. Preserve the exact measured
basename and encoded destination. Use an empty, seekable binary stream at
position zero for stream output. The receipt records the oracle identity and
observations. The caller authenticates its origin and custody.

The main-target extraction reproduced the disclosed forward diameter candidate
through direct stream, registry stream and registry path publication. All ten
logical streams and the complete 8,421-byte archive matched the previously
measured artifact. Two existing polygon cases retained exact publication.
The cold reader recovered both driving dimensions and a three-face cylinder
with analytic mass properties through the normal SDK.

The separately qualified reversed Top-plane radius has no matching
publishable receipt on this path. Other ends, unmapped
source state, altered receipts and different archive bytes refuse. This
change does not qualify saved-circle semantic rereads or FreeCAD corpus inputs.
