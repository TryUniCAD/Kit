# Authenticated rigid nested assembly publication

The normal registry and direct SOLIDWORKS adapter rebuild each nested
definition from the complete neutral hierarchy. They verify an authenticated
whole-bundle measurement before writing any staged member. Each file's
size, digest and actual encoded locator contribute to the check.

The native usability flags require both an exact bundle and the measured
physical destination. Set `defer_native_delivery=True` with the explicit
measured native destination to deliver the same complete bundle elsewhere
with both flags false. The result reports where the files must be installed.

Four disclosed bundles reproduce every measured file through both APIs.
The two previously native-tested Windows hierarchies retain their own
authenticated manifest commitments and exact generation policy. The
current gate still requires a guest replay to reconfirm those two bundles.
