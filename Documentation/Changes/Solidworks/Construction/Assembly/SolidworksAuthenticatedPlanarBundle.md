# Authenticated planar assembly publication

The ordinary SOLIDWORKS assembly writer regenerates the measured
two-occurrence coincident and driving-distance bundle from the neutral
document. It requires the authenticated offline receipt at
`solidworks_native_measurement`. The writer checks its exact build,
bracket controls, native process lifetimes, epoch, native locator and
both complete file digests before opening either staged output.

The measured locator qualifies the native usability flags. For delivery
to a separate directory, explicitly set `defer_native_delivery=True`,
supply the measured `native_destination`, and allow the non-qualified
result. The result retains the destination obligation and both native
flags are false. Other planar and perpendicular models retain their
internal generation path pending exact publication evidence.

Strict Kit readback of the measured cold pair retains the actual
distance-mate parameter in addition to the child dimensions.
