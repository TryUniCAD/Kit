# Generate the default concentric display state

The internal SOLIDWORKS concentric composer accepts one explicit
`AsmDisplayIn` named `Display State-1` when both actual direct occurrences
are visible. The generated binary VisualStates store uses the actual
parent file, active configuration, occurrence references and three
principal datums. Mixed radial visibility retains its existing three
state profile.

Four guarded workers independently decoded the disclosed original and
edited D01 states and reproduced the scoped parent binary state from
neutral input. The existing parent streams, child bytes and measured
three-state comparison remained exact. Historical presentation and
public publication remain outside this internal construction.
