# Shared creation clocks for planar mates

The internal planar assembly constructor can use a separate whole-second creation epoch for each ordinary mate. A supplied epoch drives the mate's feature clock and the same owned revision entry in both native headers. Omitting that value uses the document creation epoch as before.

Two guarded workers reproduced the previously measured A22 assembly and child byte for byte through the historical container ordering. A separate neutral comparison changed one event and isolated the difference to the two headers and the MatesList stream. The constructor leaves public A22 publication outside its acceptance boundary.
