# Shared SOLIDWORKS concentric cylinder child construction

The internal assembly preparer now builds a feature-only circular
blind-boss child from its neutral model, explicit self identity and
authored scene. It attaches the live body output, active cylinder
partition, both cap and rim references and retained rollback marks.
The parent can consume the actual generated face tag. The scoped
inputs cover a radius or diameter driver on the standard Front
support, with one ambient light or an ordered four-light scene.

The guarded standalone proof matched both complete previously
native-tested pairs byte for byte. Strict readback recovered both D1
owners and the physical cylinder topology. An independent geometry
edit changed the partition, and a longer authored scene changed
the Config-0 length. The aligned signed alternate-epoch comparison
matched the previous constructors. A separate B-rep-bearing
input refused without stripping the supplied geometry.
