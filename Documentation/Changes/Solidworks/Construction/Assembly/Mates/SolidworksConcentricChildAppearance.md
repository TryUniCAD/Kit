# Named appearance for an internal concentric child

The internal forward Front radial child now accepts an explicit
named renderer with separate classic and DSPBR properties. It
generates the child model, selected configuration, independent
display holder and appearance allocator from their actual owners.
The aligned unlocked parent can combine this child with its single
all-visible display state and the 3D radial text.

Both disclosed D01 states reproduce their scoped typed appearance
and all physical face and driving-dimension roles. Guarded generation
changes just four child streams and preserves the complete parent
bytes. Full source and native qualification remain open.
