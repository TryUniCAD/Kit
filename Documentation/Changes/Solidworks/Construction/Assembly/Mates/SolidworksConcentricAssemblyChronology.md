# Concentric assembly revision history and feature instants

The D01 research composer builds assembly Header revision tables
and preserves subsecond feature creation instants from actual owned
model roles. It feeds the resulting pair of Headers and signed mate
graph through the shared assembly emitter. Visual plane references
derive their times from the corresponding creation logs.

Two isolated guarded processes reproduce the same 11,908-byte
parent and the previous exact generated child. A separate one-event
contrast changes only the parent Headers and VisualStates and
retains the feature FILETIME. The original source and edited
disclosures replay all four Headers exactly with independently
reconstructed revisions. Six malformed-owner or incomplete-clock
contrasts refuse.

The existing public admission rules still apply. The
[chronology record](../../../../../../re/solidworks/records/ConcentricD01AssemblyChronology2026.md)
provides the reproducible research command, underlying evidence and
remaining source implementation and native qualification boundaries.
