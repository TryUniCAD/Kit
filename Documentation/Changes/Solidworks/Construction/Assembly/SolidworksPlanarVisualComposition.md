# Planar assembly default display composition

The internal planar constructor can generate the single all-visible parent display state for the bounded two- and three-occurrence rectangle groups. It emits the XML and the independently allocated binary store from the actual neutral occurrences. An explicit constructor-only child request builds the separate selected configuration and detached self appearance owners.

The guarded host run replays both emitted stores, retains ordered mates, placements and existing dimension presentation, and fails closed on ten malformed inputs. The earlier no-intent and radial outputs retain their exact bytes. Populated native renderer data remains outside the current writer scope. Public writer support and native acceptance requirements are unchanged.
