# Native relocation of standalone SDK parts

Two independently generated forward blind-boss files opened from a UNC
location on a different drive from the absolute self path in their headers.
The second case uses a Unicode filename and an archived path that stayed
absent throughout the trial. Both files kept their authored basenames.

Both cases preserved 25 native feature rows and one solid through a driving
depth edit, new save and fresh reopen. All eight native processes and
220 numerical comparisons passed with healthy controls. Read the
[relocation record](../../../../re/solidworks/records/SdkPartRelocation2026.md)
and [measurement](../../../../re/solidworks/measurements/2026/SdkPartRelocation01.json).
The trial covers standalone parts. Linked files and public writer admission
follow their own verification.
