# SOLIDWORKS writer evidence guards

SOLIDWORKS direct and registry writes apply the shared research, inch
dimension, equation, sketch support and native feature checks before
opening a destination. These checks include embedded component documents.
Research results retain their qualification marker through ordinary
inspection and interchange serialization.

The shared markers live with their adapter contracts so direct writers
can load the policy without a circular import. Guarded write checks
cover existing paths, absent paths and binary and text destinations.
