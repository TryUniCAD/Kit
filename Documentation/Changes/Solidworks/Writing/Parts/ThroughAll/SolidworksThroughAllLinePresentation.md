The internal component builds the actual ordered line patterns and category-font map from explicit typed settings. Each category gets a fresh configuration. Native map order, counts, tags and preset-width state derive from constructor and serializer rules.

Use the internal `ReadThruLines`/`MakeThruLines` pair in the [guide](../../../../../Reference/Research/Solidworks/Construction/ThroughAll/LinePresentation.md). Starred keys, unknown/aliased owners, custom widths and other modes are refused. Font selectors stay authored strings; no missing local style is fabricated. Catalog physical-unit conversion and wider renderer resolution remain unqualified.
