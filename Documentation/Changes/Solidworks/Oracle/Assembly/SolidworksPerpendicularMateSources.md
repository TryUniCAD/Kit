# Ordinary perpendicular-mate source protocol

PR #121 adds a source-only native authoring and observation method for one ordinary principal-plane perpendicular mate between two resolved occurrences of a rectangular part. It freezes three disclosed designs, creates two guest-private specimens before writer development, and measures baseline and separately edited source pairs with healthy native controls.

The native-image collector binds the exact 2026 runtime class, common two-geometry factory/serializer and perpendicular command slots. It also proves that the perpendicular command ignores the alignment selection used by coincident and parallel. No perpendicular writer or public format coverage is enabled.

Use `PreparePerpendicularMateSources.py` with an unused external packet directory, the pinned native control, and the collector's numeric receipt. Run the resulting recipe's `verify` and no-CAD `metadata` commands first. Root then runs one explicit source phase at a time. Every case requires five fresh process identities, healthy brackets, exact ordered owner/datum identities, two bodies, independent geometry, live valid reorientation and child-depth edit, synchronized saves, and fresh baseline/edited reopen. Keep the sealed designs and raw observations guest-private until the writer method and predictions are frozen.

The host preflight passed without COM imports, native execution or sealed design creation. The three independent pose predictions remain orthogonal before and after their requested edits. Vendor authoring, native source locks, active correction from an invalid angular start, generated files and held-out acceptance remain pending. This method does not qualify arbitrary perpendicular geometry or the remaining free solver degrees of freedom.
