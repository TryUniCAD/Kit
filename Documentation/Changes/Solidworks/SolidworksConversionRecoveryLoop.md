# FreeCAD to SOLIDWORKS conversion recovery loop

The active goal now records the user-authorized limit of 1,000 repair/retry
iterations. The [loop record](../../../re/solidworks/records/ConversionLoop2026.md)
defines input/output identities, first-error evidence, shared-rule repair,
remote process verification and repeated native inspection with healthy
controls. Supporting traces and CI polls are not counted as conversions.

The target remains the unchanged public FreeCAD assembly and all of its required
parts, with actual screenshots in the PR and the original CAD source link.
Research prototype candidates are explicitly distinct from that full source
conversion. No production writer, complete public-project conversion or native
acceptance is claimed by this workflow entry. Actual results continue in the
linked native measurement and Tupni ledgers; no local tests were run.
