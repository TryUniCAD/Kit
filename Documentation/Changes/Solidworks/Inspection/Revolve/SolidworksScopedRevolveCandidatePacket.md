# Compare selected revolve cuts on signed principal planes

The research packet constructs two complete neutral selected-stock revolve parts. The Top-plane case cuts the inner stock and the Right-plane case cuts the outer stock. A fresh-process constructor repeats each complete output with file reads disabled and checks the linked Config and Resolved graphs. The oracle records the actual editable cut and stock drivers, both solid owners, mass properties and the complete feature tree before an edit and after a fresh reopen.
