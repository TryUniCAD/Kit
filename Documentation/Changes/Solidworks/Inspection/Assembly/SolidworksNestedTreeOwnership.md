# Inspect rigid nested assembly tree owners

The research audit links the public SOLIDWORKS feature timeline to typed
assembly roots, component occurrences, environment and cabinet members,
and the empty exploded-view manager. It checks the resulting hierarchy
against recorded native observations for two original and two generated roots.

Four guarded processes checked 86 indexed rows, 96 visible rows and 18
expanded occurrence paths. The scope is disclosed rigid assemblies with
empty mate groups. Runtime defaults, saved presentation state and authored
occurrences retain their separate ownership in the evidence. [Method and receipt](../../../../../re/solidworks/records/NestedAssemblyTreeOwners2026.md)
