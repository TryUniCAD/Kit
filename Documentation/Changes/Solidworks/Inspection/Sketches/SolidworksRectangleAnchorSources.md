# SOLIDWORKS rectangle anchor sources

`re/tooling/sw2026/AuthorRectangleAnchors.py` measures native corner and center rectangles locked to the Front Plane origin. The source observer records native relation kinds and entity IDs, actual solver status, dimensions, tree and solid geometry. It makes independent driving width and height edits, then reopens the original and edited siblings in a separate native process. Both edits must preserve the intended corner or center and the single blind boss.

Use a private job directory with `Control.SLDPRT` and the five hash-pinned tools under `Tools/`. The `kit.sw2026.rectangle-anchor-source.v1` job includes `oracle_sha256`, `control_sha256`, `tools_sha256`, `writer_output_count` set to zero and two cases ordered `corner`, `center`. Each case declares `width_m`, `height_m`, `depth_m`, `edit_width_m` and `edit_height_m`. Run the frozen tool with the job path and `--job-sha256`. Use `--verify-only` for a local custody check without starting SOLIDWORKS. The completed batch requires two healthy pristine controls and six distinct exact-build native processes.

The first disclosed trial uses a 31.73 × 18.27 × 7.41 mm corner rectangle and a 43.19 × 25.63 × 6.83 mm center rectangle. The native trial is pending.
