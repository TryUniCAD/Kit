# Controlled inspection of generated circle sketches

`re/tooling/sw2026/InspectCircleSketch.py` inspects the single-entity sketch synthesis rung in the pinned SOLIDWORKS 2026 SP05.2 oracle. It accepts one JSON job path and runs through `prlctl exec "Windows 11" --current-user` using the existing host deadline supervisor. Freeze the tool and its imports from a committed revision before launching it.

The job supplies `checkout_root`, an unused external `output` directory, the native `control` and its SHA-256, the expected `oracle_sha256`, a `generator` receipt and nonempty `cases`. Each case contains `name`, the generated native `path` and `sha256`, and the exact neutral `request` published by remote CI. Pin the tested commit, its parents, the CI artifact and each request/file receipt before constructing the job. Do not generate or run repository checks locally.

Every case opens a hash-verified generated file in an owned fresh application process, rebuilds, checks zero load warnings/errors and rebuild problems, inspects exactly one ordinary native circle and checks its local center/radius against the neutral input. It also checks the authored principal-plane origin/basis through native math transforms, requires zero solid bodies, and checks the native feature tree for errors and warnings. It saves an external copy, closes its owned process, and repeats the checks after reopening the saved copy in another process with a different PID and creation time.

A vendor-authored control runs before and after the cases. Failed case execution still attempts the after-control and records cleanup failures. Per-phase records preserve API calls, numeric checks, executable identity, source immutability, save results and cleanup; the batch writes `Inspection.json`. A passing batch requires both controls, all requested phases, fresh process identities and unchanged control/candidate inputs. The tool never closes unowned sessions or changes licensing.

The [first remote generation receipt](../../../../../re/solidworks/measurements/2026/CircleSketchProcesses814f5f8.json) records two independently authored circle requests, sixteen complete archive comparisons, 183 passing native-format process checks and 171 passing CI policy process checks. These are generation/process observations, not native acceptance. The new inspection tool has passed static AST review only; its first native run is pending.

This workflow measures an unconstrained, sketch-only rung. It does not establish a radial driving dimension, extrusion, held-out generalization, material-folder naming, camera parity or a production writer. Those acceptance flags stay false even when all rung checks pass. Six held-out native payloads remain sealed.
