# Generated radial sketch driving-edit inspection

`InspectCircleSketch.py` now handles an explicit `circle_dimension` request in the generated sketch input. The JSON job retains exact candidate/control hashes, generator revision, artifact identity and pinned executable hash. Each radial case additionally requires an explicitly authored positive finite `edit_factor` different from one.

The inspector checks `D1@<sketch_name>` exists, is editable and driving, and has the radius/diameter value derived from the neutral radius. It requires one native display dimension that targets the same parameter. Local geometry, authored plane, zero bodies, feature errors/warnings and rebuild problems retain their original checks. It also records `ISketch.GetConstrainedStatus` and rejects overconstrained, no-solution, invalid and autosolve-off states. The method and enum were independently read from the installed version-34 type libraries, with hashes and signatures retained in [method metadata](../../../../../re/solidworks/records/SketchSketchStatusTypes2026.json) and [enum metadata](../../../../../re/solidworks/records/SketchConstraintStatesTypes2026.json). The [2026 vendor enum reference](https://help.solidworks.com/2026/english/api/swconst/SOLIDWORKS.Interop.swconst~SOLIDWORKS.Interop.swconst.swConstrainedStatus_e.html) supplies the matching public meanings; this enum is not substituted for internal entity/sketch wire states.

Radial cases run three owned fresh processes: initial load/rebuild/save; saved-file reopen, driving edit/rebuild and edited save; then fresh reopen of the edited file. Center and plane must remain unchanged while radius and native parameter scale by the explicit factor. Every process has a distinct PID and creation time. Before/after controls, immutable original sources, cleanup and dialog gates remain mandatory. Plain free-circle cases keep their two-phase route. Results now use `kit.sw2026.circle-sketch-inspection.v2` and preserve original and edited snapshots separately.

The [first radial native receipt](../../../../../re/solidworks/measurements/2026/RadialSketchInspection01.json), source `263a75d4133482d4789626b7ccee15d8f7eb49d7`, passed both generated free-center radius/diameter sketches through six native phases and 104 numeric/frame checks to six significant figures. Both controls, source hashes, cleanup and independent post-inventory passed. Radius scaled by explicit factor `1.31`, diameter by `0.77`; centers and planes remained unchanged, and the edited values survived fresh reopen. The later explicit fixed-center route additionally requires fully constrained public status three and one nonsuppressed fixed relation whose exact binding is the circle center. Those changed checks remain pending. The [earlier free-circle receipt](../../../../../re/solidworks/measurements/2026/CircleSketchInspection01.json) stays bound to its original v1 sources. Whole-family, extrusion, appearance and held-out acceptance flags remain false.

See [radial synthesis](../../Model/Curves/SolidworksRadialSketchSynthesis.md), [controlled sketch inspection](SolidworksCircleSketchInspection.md) and the [constructor ledger](../../../../../re/solidworks/records/RadialStyleAndEngine2026.md). Execution stays in the reserved VM through `prlctl exec "Windows 11" --current-user`; the host supervisor and independently checked process inventory remain separate evidence from the native records. The tool does not change licensing or close unowned sessions.
