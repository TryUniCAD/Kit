# SOLIDWORKS pocket centre fixation

The SDK now reads the fixed-centre relation in an ordinary 2026 radius-driven single-circle pocket sketch. The relation targets the circle's `center` subelement. The radius remains driving and the circle entity's `fixed` flag stays clear. The reader owns the logical relation separately from the radial dimension and reports its exact native byte span.

The reader requires the typed current sketch arrays, an independently bound radius and the concrete local point-handle class. An unsupported or incomplete relation layout leaves the previous sketch projection intact. The change covers the admitted local one-circle frame with its first arc and radial class declarations and one logical point constraint. The generated pocket regression passed through the public `open_document(..., include_brep=False, include_tessellation=False)` API using Python 3.11.16 and pytest 9.1.1. It checks the centre subelement, the driving radius, the circle's independent fixed flag, the native relation span and the existing profile and cut semantics. A separate read of the earlier native-verified generated specimen returned the same two sketch relations, with a 55-byte native span for the fixed relation.
