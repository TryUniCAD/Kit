Two-direction requests also supply a positive `reverse_depth_m` and a separate nonidentity `reverse_depth_edit_factor`. Existing `blind_extrusion` requests retain forward, single-ended blind semantics. This adds an oracle observer; it does not enable a writer or production adapter.

Run the existing frozen, owner-controlled inspector job procedure. Both end depths remain independent. The two-direction interval is `[-d2,d1]`, mid-plane is centered with total length `d1`, and reversal flips the interval. Unequal depths make a reversal error visible in center of mass.
