# Trace initial view restoration separately from hidden previews

The temporary [Hopper REA MCP session](SolidworksHopperMcpSession.md) resolved three direct callers of `uiSplitterInfo_c::setDocViewingXforms` in the pinned 2026 UI module. The [caller receipt](../../../../../re/solidworks/measurements/2026/ViewLoaderCallers01.json) binds that REA evidence to original image hashes, complete declared unwind ownership, two compact getters and relevant imports. Original instructions were inspected independently because the composed function dossier stalled and returned no decompilation result. No vendor instructions or pseudocode are published.

The callers have different roles: `uiModelView_c::OnInitialUpdate`, `uiModelDoc_c::iGetViewArray` and `uiModelDoc_c::iSaveHiddenDocPreview`. The view-array method returns without splitter restoration when its user-environment argument is null; it is not the no-user-environment fallback. Its body spans three reverse-linked unwind records, not only the 38-byte entry record.

For the normal editable-view path without a matching user environment, `OnInitialUpdate` resets the active transform, reads the document pointer at runtime `+0xae8` and assigns it through model-view virtual slot `+0x630`. It then reads the separate pointer at document `+0xaf0` and calls `setPanZoomXform`. View-only and drawing paths have additional branches; optional tree-shift work can follow the initial assignments. The import used to select view-only behavior is explicitly resolved as `baseDocState_c::isOpenedViewOnly`, not inferred from its neighboring symbols.

This static path supports the [two unseen camera measurements](SolidworksCameraHeldoutMeasurements.md): both generated definitions have no user-environment rows, and their initial native poses match the independent source observations exactly. A runtime call-site trace was not collected. The separate hidden-preview caller further distinguishes preview creation from the normal active-view path; it does not establish pixel-level viewport parity or explain every preview-cache decision.

Source/metadata analysis and original instruction inspection ran on the host. No local test, CAD writer verification, licensed target-code execution or licensing-process change occurred. The public adapter remains read-only. Perspective, multiple-window behavior, full presentation parity and the material-title regeneration caller remain unfinished.
