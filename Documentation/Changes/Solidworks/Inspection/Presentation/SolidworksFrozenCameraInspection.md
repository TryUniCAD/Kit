# Inspect frozen camera predictions before setting any view

`re/tooling/sw2026/InspectCamera.py` compares two independently generated camera files with the locked native source API observations. It records `ActiveView.Orientation3`, `Translation3` and `Scale2` immediately after opening each generated file, before an explicit rebuild or any view-setting command. It then checks the body, driving dimensions, requested plane, rebuild state and camera again.

Each candidate has three fresh owned SOLIDWORKS processes: open and save, reopen and edit the radial/depth dimensions before saving, then reopen the edited file. The observer compares each initial, rebuilt and saved pose with the independent source pose; the edit phase also checks pose after dimension changes. It does not import or call the pose setter. Healthy controls bracket the batch. Input, reference and control hashes must remain unchanged, and all eight candidate/control process creation identities must differ. The host must separately verify that no SOLIDWORKS process remains and that licensing processes were preserved.

Run the committed observer only through the documented macOS `prlctl exec --current-user "Windows 11"` transport and the existing oracle supervisor. Its JSON job supplies `output`, `checkout_root`, `control`, `control_sha256`, `oracle_sha256`, `reference_inspection`, `reference_inspection_sha256`, `writer_freeze_sha256`, `generator`, `inspection_source_revision` and two `cases`. Each case contains `name`, generated `path` and `sha256`, the neutral `request`, explicit `edit_factor` and `depth_edit_factor`, and `expected_pose`. The expected pose must equal the original source-author observation in the locked reference receipt. Use fresh output directories outside repository checkouts.

The [prediction protocol](SolidworksCameraHeldoutPrediction.md) still gates access to those private observations: all writer dependencies stay frozen, and complete generated prediction processes must pass before reference access. Saved source CAD payloads remain sealed. This observer supplies no production writer and does not establish pixel-level viewport equality, perspective support, complete feature-tree parity or full native acceptance.

Introduction verification is source and AST inspection only. Native measurements are pending. No local test or writer execution was run, and `native_acceptance` and `heldout_acceptance` remain false in the raw observer receipt.
