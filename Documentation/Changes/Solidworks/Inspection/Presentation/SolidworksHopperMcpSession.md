# Keep a temporary native REA MCP session for large Hopper targets

`re/tooling/sw2026/McpNative.py` launches an existing public REA executable as a temporary stdio MCP server. It sets `REA_HOPPER_STARTUP_TIMEOUT_MS` only in that child process, with a default fifteen-minute startup deadline. It neither installs software nor changes client registration or configuration. This addresses the observed two-minute bridge-startup timeout while Hopper is still analyzing the 2026 UI DLL.

Use an absolute existing `--launcher`, a new absolute `--state` directory outside the repository, and the committed `--source-revision`. Optional `--startup-ms` accepts two to thirty minutes. The client negotiates MCP `2025-06-18`, discovers the complete advertised tool inventory, then reads one JSON request per stdin line: `{"name":"open_binary","arguments":{"path":"/licensed/path/slduiu.dll","provider_id":"hopper"}}`. Follow with advertised permitted native-analysis tool requests. Send `{"stop":true}` to export the final evidence, request binary cleanup and close the owned server transport.

The client retains complete server messages, individual replies, hashes, server identity, source identity, progress and cleanup status in its private external state directory. Replies can contain proprietary assembly or pseudocode and must stay outside repository checkouts. It supports a narrow native-analysis tool allowlist, declines unnegotiated server-requested capabilities, enforces absolute request deadlines and sends cancellation on expiry. Add `timeout_seconds` to an individual request to use a shorter deadline within the session limit. An independent stdin reader accepts `{"cancel":true,"reason":"operator reason"}` while a query is pending and sends the MCP cancellation notification. Local cancellations are explicitly recorded without inventing a native result; late server messages remain in the raw log. Shutdown affects only its owned MCP subprocess; Hopper document cleanup must be established by the retained `close_binary` result, not by transport exit.

The transport and lifecycle follow the official [stdio specification](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports) and [lifecycle specification](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle). The [first live session](../../../../../re/solidworks/measurements/2026/HopperMcpSession01.json) negotiates REA 6.7.0 with 207 advertised tools, binds the expected 2026 UI image and resolves three direct callers of its saved-view restoration routine. The first composed function dossier stalls; its missing result is not counted as decompilation evidence. The later cancellation extension has source/AST inspection only until a live query uses it. No local tests or CAD writer verification ran, and this transport adds no generated-file acceptance or production adapter coverage.
