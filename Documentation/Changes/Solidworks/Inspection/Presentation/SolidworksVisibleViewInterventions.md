# Measure independent visible view property interventions

The saved derivative fixtures report identity document/user transforms and do not vary an explicit view property. The new research-only `re/tooling/sw2026/ProbeViewState.py` opens an unchanged generated circle part in an owned visible 2026 process, records its active orientation/translation/scale, applies an explicit named orientation, translation or scale request, then saves and checks a separate fresh-process reopen. Baseline and combined requests can bracket the independent interventions.

Use the existing frozen-source external job and host supervisor with unused output paths, a hash-bound generated input/neutral request, the pinned oracle hash and before/after controls. Each case adds a `view_request` mapping with optional `named_view` (1–9), `translation` (three finite native API coordinates) and positive finite `scale2`. No translation-unit conversion or active-to-wire field mapping is assumed. The observer verifies setter readback, live pose after saving and initial/rebuilt pose after fresh reopening, while retaining initial body and analytic geometry/dimension checks. It records process identities, sources/saved hashes, dialogs and cleanup.

These are training observations on existing generated input, with zero new writer outputs and no held-out camera acceptance. Newly saved files require separate complete remote archive decoding before a persisted field is assigned an active-camera role. No constructor, schema, frozen writer helper or production adapter changes. Native intervention outcomes remain pending; introduction verification is source/AST inspection only, with no local test, archive parser or writer verification run.

The API requests use [ShowNamedView2](https://help.solidworks.com/2026/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelDoc2~ShowNamedView2.html), [GetStandardViewRotation](https://help.solidworks.com/2026/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelDoc2~GetStandardViewRotation.html), [Scale2](https://help.solidworks.com/2026/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelView~Scale2.html) and [Translation3](https://help.solidworks.com/2026/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelView~Translation3.html). Setter readback checks only the explicitly requested properties; the complete observed pose is the fresh-reopen expectation. Incidental changes to other properties are recorded rather than assumed absent.
