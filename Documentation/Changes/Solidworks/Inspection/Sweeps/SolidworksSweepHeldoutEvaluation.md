The [sweep evaluation protocol](../../../../../re/solidworks/records/OrdinarySweepHeldoutEvaluation2026.md) freezes the density-corrected research writer after a verified disclosed native pass. It generates both independent candidates from neutral initial geometry and density before inspecting any locked guest-only native source or matching lifecycle records. The existing native phases compare cold geometry, feature order, both driving dimensions and their separate edit/save/reopen chains between two healthy controls.

Offline verification reproduced both exact disclosed files with eleven streams and zero audited writer reads. The evaluator publishes only digests, counts and verdicts after a complete native pass. Public SDK sweep writing and arbitrary sweep families remain outside this scope.
