# Predict ordinary revolves before disclosing their native measurements

The research prediction tool generates an ordinary revolved boss from the
authored rectangle, centreline, plane, direction and angle. It uses the pinned
generative writer and standard English tree presentation. It records file,
request, analytic target and archive receipt hashes for each part. The
comparison tool validates the saved bytes and compares measured geometry, tree,
profile frame and driving edit with the independently locked native results.

Run `PrepareRevolvePredictions.py --help` and
`CompareRevolvePredictions.py --help` from the research environment. The
[validation procedure](../../../../../../re/solidworks/records/OrdinaryRevolveHeldoutProtocol2026.md)
specifies the source and writer pins, disclosure order, math and native gates.
The inspector options `inspect_before_rebuild` and `inspect_profile` capture
the body and tree at open, the five resolved sketch segments and the active
configuration and sketch frame.

All three disclosed candidates generated through isolated processes. Each
passed nine complete archive round trips, reference-ownership and frame
checks, with no reads denied during construction. This proof covers a single
ordinary boss, a rectangular profile on one principal plane and a selected
upright centreline. The three disclosed native comparisons passed across
eight fresh processes. Each candidate exposed one solid and matched its
independent 19-node tree on open, with matching profile frames, driving
dimensions and clean edited reopens. The test method was then frozen before
revealing the two held-outs. Production writing remains unavailable.
