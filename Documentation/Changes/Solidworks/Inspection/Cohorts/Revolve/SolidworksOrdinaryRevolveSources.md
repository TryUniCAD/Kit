# Author native ordinary revolved-boss sources for independent verification

The SOLIDWORKS 2026 oracle authoring tool creates an ordinary solid revolve
from a closed rectangular sketch and an explicitly selected construction
line. It accepts a hashed private specification, immutable control and a
new output directory. The source batch includes a full-turn control, two
disclosed partial directions and two sealed partial held-outs.

The probe verifies the selected sketch and line, measures one-body volume,
area, centre of mass and rebuild state, and checks a driving angle edit in
fresh reopen processes. It publishes a source lock containing file and
measurement hashes. Source authoring and lock verification are pending.
The [2026 constructor evidence](../../../../../../re/solidworks/records/OrdinaryRevolvedBoss2026.md)
documents the field rules, inputs and acceptance procedure.
