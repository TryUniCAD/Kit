# Default SDK readback of nested SOLIDWORKS bundles

A pinned research command compares the default SDK reader with the authored
neutral assembly requests and their seven frozen generated files. It checks
physical child links, occurrence order and poses, active configurations,
editable leaf dimensions, and neutral body metrics. It records the current
caption, order, configuration and native history gaps that prevent cold
same-format re-export.
