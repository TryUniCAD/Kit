# SOLIDWORKS external reference wire evidence

The assembly research record identifies the native serializers for the external reference interface and feature in SOLIDWORKS 2026 SP05.2. It records the mode byte that selects the pooled name path, the nullable reference tag and the trailing pattern owner identifier. The pinned native trace and disclosed assemblies support the ordinary version-19000 path. The historical pattern-data path and nonzero name mode retain separate evidence boundaries.
