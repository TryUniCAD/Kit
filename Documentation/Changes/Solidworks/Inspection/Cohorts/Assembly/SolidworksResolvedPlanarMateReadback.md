# Project resolved planar mate references

The version-19000 research reader follows the native mate wrapper chain to
its assembly occurrence and the real plane in the synchronized child.
It reports the ordered instance and support-plane IDs, stored frame,
alignment and ordinary driving distance.

Run the probe with the native parent and child. Six disclosed assembly reads
reproduce their mate-list bytes and match all twelve support-plane IDs from
the public part reader. The probe rejects stale and mismatched child inputs.
Its current scope is direct part occurrences in one configuration. Public
assembly adapter integration remains open.
