# SOLIDWORKS generated occurrence bundle

The SOLIDWORKS 2026 research process accepts an authored assembly and child-part request together with one resolved external part occurrence. It generates both file containers in memory. The assembly links to the generated child's file identity and configuration. Its occurrence owns a rigid placement, child-local bounds and a named entry in the configuration's contextual reference chain.

Pass `assembly`, `child` and `occurrences` in one JSON object to `re/tooling/sw2026/AssemblyRootProcess.py`. The assembly and child each take an explicit native output path and save event. The child uses the existing research part builder with a forward blind polygon extrusion. The occurrence takes its name and a `placement` with `origin`, `u` and `v` in parent coordinates. The process returns the assembly and child containers with a decoded graph report. [Occurrence field and ownership rules](../../../../../../re/solidworks/records/OrdinaryOccurrenceConstruction2026.md)

An isolated process integration test generated the bundle with identity placement and with a rotated, translated placement. It checked the external directory's direct slot, occurrence ownership, configuration identity, map continuity, stream round trips, bounds and runtime file-access audit. The two existing empty-assembly container hashes matched before and after the change. [Integration test](../../../../../../tests/Convert/Solidworks/Research/Assembly/OccurrenceBundleTests.py)

The pinned SOLIDWORKS 2026 SP05.2 build opened the generated identity-placement assembly with zero errors and warnings. It resolved the generated child and selected the authored configuration. The assembly rebuilt and saved with zero errors and warnings. The saved derivative returned warning 32 on fresh reopen, then rebuilt to the same 23-node tree and one-body geometry. All 42 numeric checks and both bracketing controls passed across four distinct processes. [Native measurement](../../../../../../re/solidworks/measurements/2026/GeneratedSingleOccurrenceNative01.json)

The three original occurrence stamps agree with the generated child on disk. The vendor-saved parent contains three newer stamps while the child file is unchanged. The inspection tool records parent and child update state before and after rebuild. Supplying `owned_input_directory` enables a controlled save of the staged generated child before the parent. [Persisted stamp comparison](../../../../../../re/solidworks/measurements/2026/GeneratedOccurrenceDerivativeStamps01.json)

A paired run used the same generated files in both lanes. The parent-only derivative reopened at child update stamp 117 with warning 32. Saving the rebuilt child before the parent preserved the loaded child update stamp 132 and both documents reopened without rebuild requirements or warnings. The four candidate phases had equal rebuilt geometry and feature trees, with all 84 numeric checks and four controls passing across eight processes. [Paired save measurement](../../../../../../re/solidworks/measurements/2026/GeneratedOccurrenceSaveComparison02.json)

This witness covers one generated external part occurrence. Repeated occurrences, assemblies as children, configurations beyond the single active configuration, mates and other component states are outside this bundle's contract. The user-facing adapter remains read-only.
