# Classify planar mate construction state

The ordinary version-19000 coincident, parallel and distance factories
bind resolved datum references to their child occurrences and detached
plane references to the containing assembly. The field rules cover
native wrapper construction, explicit alignment, and the default pair
of distance options for planes with absent arc overrides.

The native functions were traced on SOLIDWORKS build 34.5.2.0604. Three
disclosed assemblies corroborate reference ownership and alignment.
The disclosed distance mate also corroborates both distance option
values. Native load, solve, edit and reopen of generated mates remain
to be measured.
