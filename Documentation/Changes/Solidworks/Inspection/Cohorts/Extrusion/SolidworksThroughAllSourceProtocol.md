# Through-all extrusion source protocol

PR #121 adds source-only research tools for ordinary forward, reverse and two-direction through-all cuts and bosses. The tools freeze independently authored disclosed cases, create new hidden designs only inside the Windows guest, and run native author/edit/save/fresh-read phases with independent controls.

The [construction record](../../../../../../re/solidworks/records/ThroughAllConstruction2026.md) binds the exact 2026 modules, native distance-owner deletion and reconstruction, and the managed factory's unsupported through-all boundary. The [source protocol](../../../../../../re/solidworks/records/ThroughAllSourceProtocol2026.md) documents custody and numeric acceptance. The [factory gotcha](../../../../../Gotchas/Conversion/Solidworks/Model/Extrusion/ManagedExtrusionPacketsExcludeThroughAll.md) records why changing a blind enum does not provide the required graph.

Use `PrepareThroughAllSources.py` with an unused packet destination, the checksum-bound control, native evidence and custody record. Run its frozen recipe serially through the existing oracle owner. Host checks require Python 3.11 or later. Metadata validation starts no CAD process. Each native source lock requires five distinct healthy processes, two immutable native states, exact profile and owner observations, and successful fresh reopens.

Verification is currently limited to original-image static evidence and source-only host preflight. The [five-process packet check](../../../../../../re/solidworks/measurements/2026/ThroughAllSourcePacketProcess01.json) passes the genuine frozen packet and rejects four malformed variants at the actual verifier boundary. Six disclosed source-plan cases and six invalid or guest-only input boundaries also pass the host smoke check. The hidden designs have not been opened or created on the host; no VM or native application was launched by this tranche. No through-all writer or public format registration is added. Boss finite-extent geometry is explicitly unqualified and cannot pass a writer gate from these discovery observations.

The [separate observer retry](SolidworksThroughAllSourceObserverRetry.md) preserves a later root-owned D01 failure with healthy controls and reuses the existing opaque guest seal. It adds no source or writer qualification.

The earlier exposed neutral end-condition cases are excluded from blind qualification in this lane. Their identifiers and original specification hash are retained in the custody note without design values. The fresh guest cohort is independent.
