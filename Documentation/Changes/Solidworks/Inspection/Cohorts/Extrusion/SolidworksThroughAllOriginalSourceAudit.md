# Original through-all source audit

Added a reproducible research auditor for the three disclosed native through-all source controls. It reads the complete ordinary SDK document, retains source owner identities, derives signed geometry independently and reports the owners still absent from strict source construction.

The auditor requires pinned source/method manifests and declared control hashes. It produces an explicit incomplete-projection diagnostic rather than certifying a stripped shape. A separate proposal tool freezes a real stock `D1` edit and its analytic expectations while keeping native execution with the oracle owner.

Verification uses 33 fresh source/SDK processes and five lifecycle-planning processes. All three B-rep bounds and signed rim checks match, 21 invalid shape/scope inputs are rejected, and removing a history owner is detected even when predicted geometry is unchanged. The original-conversion gate remains closed. No writer output, hidden source access, new native acceptance or public coverage is claimed.
