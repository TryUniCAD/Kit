# Through-all source observer retry

The through-all source observer now uses `owned_dimensions()` so the inherited `CurveAuthor.dimensions` list cannot shadow its traversal. The source verifier checks the pinned inherited instance namespace before COM import. A recorder's last successful native stage is no longer treated as the failing API when a later Python expression raises.

The source preparer can bind an existing guest-private sealed neutral container through `--previous-packet` and `--previous-packet-sha256`. It validates the old public packet and successful seal record on the host. The guest imports only the exact hash-bound bytes instead of creating new designs. Neither hidden values nor their observations are exposed to the host.

The [retry record](../../../../../../re/solidworks/records/ThroughAllSourceObserverRetry2026.md) preserves the failed D01 author run and both successful controls. Its [failure receipt](../../../../../../re/solidworks/measurements/2026/ThroughAllSourceObserverFailure02.json) distinguishes the two successful native draft queries from the Python collision. The [seven-process verifier receipt](../../../../../../re/solidworks/measurements/2026/ThroughAllSourceRetryProcess03.json) includes checksum-rebound collision and custody negatives. The [focused gotcha](../../../../../Gotchas/Conversion/Solidworks/Oracle/Extrusion/CurveAuthorStateCanShadowSubclassMethods.md) records the cause and workaround.

This is an observer and source-custody correction only. It changes no neutral design, geometry, tolerance or writer behavior. The four existing sealed designs and all Packet02 files remain unchanged. Native Packet03 qualification is pending; no through-all writer or public coverage is added.
