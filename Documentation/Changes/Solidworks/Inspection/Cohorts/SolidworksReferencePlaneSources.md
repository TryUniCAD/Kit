# Author controlled native offset-plane sources

The new research source plan and split-phase runner prepare the first independent SOLIDWORKS 2026 offset-plane cohort. Four disclosed cases include a repeated source, Front and Right offsets and a reversed Top offset. Each source has an origin-fixed circle sketch on the authored plane and a blind boss with driving radius, plane distance and depth. The plane-distance edit must move the solid's center of mass by the independently predicted amount while preserving volume and area.

The runner inspects the registered major-34 API without launching CAD, then uses fresh native author and reopen phases between healthy controls. It retains original and edited native files plus STEP and Parasolid geometry siblings. Only after the disclosed cohort qualifies does the guest create two independent private source specifications. Their values and detailed native observations remain guest-private. Each held-out source requires its own healthy brackets and immutable artifact lock before writer work.
