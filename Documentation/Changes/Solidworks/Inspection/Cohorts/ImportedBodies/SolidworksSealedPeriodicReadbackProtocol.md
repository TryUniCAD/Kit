# Private periodic import evaluation

The periodic evaluation tools package an immutable writer and observer
closure, including the hashes of any tracked empty package initializers.
The Windows guest verifies the pre-writer source lock and
generates each candidate twice from the private authored geometry.
Generation receives a typed neutral boundary through an isolated
process with zero runtime input-file reads. The build phase locks both
candidate hashes before measurement can open the native originals.

The controlled native phase compares the actual periodic geometry,
native import ownership and solid measures. Each candidate must
open cleanly, rebuild, save and reopen in a fresh process. Both
pristine controls must pass. The shared receipt contains hashes and
outcomes. All original and generated CAD files stay in the guest.

The declared seam gauge applies to a geometry-only projection.
Original seam parameterization, provenance, scene and annotation
transfer require their own qualification.
