# Measure public native admission on available FreeCAD sources

Adds an independently replayable research census for strict path-based FreeCAD reads and normal SOLIDWORKS part or assembly writing. It preserves the entire neutral document, checks original byte identity, disables carrier output and separately reads back any generated native result.

Both runs examined all 171 available paths representing 162 distinct sources. All strict reads returned valid models. Every public write refused before creating a file. The retained source metadata, payloads and model features explain the current admission boundary. The historical benchmark roster and native acceptance remain open.
