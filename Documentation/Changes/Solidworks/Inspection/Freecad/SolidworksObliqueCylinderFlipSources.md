# Oblique-cylinder directed-hinge source probes

PR #121 adds an exact-build numeric pin and disclosed source-only authoring profile for an ordinary oblique circular boss with two editable angular planes. The pin follows the real ordered plane intersection, signed angle and rotation owners. The independent replay retains the earlier wrong angle-normal prediction and the native partial observations that refute it.

Use `PinObliqueCylinderSign.py` with the licensed 2026 original images outside the checkout, or `ReplayObliqueCylinderSign.py` with the exact declared failed D01 observation. Both require Python 3.11 or newer and create a new numeric receipt without CAD execution. `ObliqueFlipSources.py prepare` freezes a separate two-case recipe with one positive-tilt/reverse-true design and one negative-tilt/reverse-false design, ten analytic states, the existing exact controls and independently checked driver edits/save/reopens. Root alone executes native phases.

The original observer's argument delegates preserve its default behavior. The separate profile checks the actual directed hinges before angular construction and checks signed plane normals afterward. Unsupported axis ordering, degenerate/skew geometry, zero-crossing edits and hidden execution remain closed. These tools do not add a production writer or qualify source/held-out/native output.

At freeze, two static-pin runs and two numeric replays matched exactly; two frozen-packet verifies passed and four tampered packets were refused. Six source files passed AST/compile and comment/docstring checks. Both predecessor packets remained unchanged. No new native process ran.

The subsequent six-process native run reproduced both directed hinge and signed plane cases with four healthy controls. Both measured volumes fell outside the six-significant-figure threshold before edits or persistence. The original expectations are preserved.
