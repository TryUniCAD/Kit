# SOLIDWORKS empty drawing manager construction

The research builder generates the empty drawing's layer mask, sketch-block manager, component-property owner and tail state. The block manager receives its own GUID. The option word comes from the native release mode and authored automatic dimension-text linking.

The [tail process](../../../../../re/solidworks/measurements/2026/DrawingTailFields01.json) verifies source class ownership on three disclosed drawings and reads both generated option variants through the shared archive graph. Full drawing construction and native trials remain separate. [Field rules](../../../../../re/solidworks/records/DrawingEmptyManagers2026.md)
