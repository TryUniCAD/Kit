# SOLIDWORKS drawing index configuration text

`ReadViewIndex` accepts the plain-text configuration selector from the typed drawing Definition and the wrapped `CStringValue` from construction. Both representations yield the actual view, external path, configuration name and selected local ID.

The index requires the supported file kind, an absolute path, a matching basename and title, valid index text and an allocated configuration ID. Strict public drawing reading and broader owner projection remain open.

The 56-process comparison covers six disclosed archive states and 11 malformed variants on two distinct archives. The valid inputs retain exact Definition bytes, map counters and public partial-read output, with no additional model file access. Black, Ruff and strict Mypy passed on the integrated code.
