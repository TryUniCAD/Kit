The ordinary version-19000 linked/named Definition reader now validates and retains the native detailing-edge index instead of requiring it to be empty. Exact model/component text, unsigned downstream IDs, actual reference nodes, row order and aliases remain available through `NamedRead.DetailingMap` and `FrontRead.DetailingMap`.

Nonempty native associations report `drawing.detailing_edges` through the result's `Unprojected` property. Portable child-edge resolution is not claimed. Invalid counts, duplicate keys, null or unproved references, unknown-prefix placeholders and unsupported schemas fail explicitly. Every other drawing guard remains unchanged, as do the public writer registry and fresh drawing constructors.
