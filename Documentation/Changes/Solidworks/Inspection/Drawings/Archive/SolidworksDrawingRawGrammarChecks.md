# Drawing raw-grammar inspection

The research-only `InspectDrawingRawDefinition.py` command measures exact Definition read/store and graph-map preservation separately from normal drawing UI/semantic admission. It requires a frozen SDK closure, the hash-bound custody manifest, the two exact already-disclosed originals, and an unused metadata output path.

The inspector uses existing typed field and header codecs, records complete usage and native byte-field ownership, compares every output byte and map slot, and checks mapped object identity. It separately requires the existing normal named-reader UI rejection. No SDK guard is patched, public mode added, source field changed, original writer modified, or CAD file saved.

Root independently measured both original Definition streams byte identically, 37,612 and 37,608 bytes, zero tails, 215 used schemas per direction and matching maps. Both normal reads remain rejected. Native usability, source-semantic completeness, and held-out writer acceptance remain false.
