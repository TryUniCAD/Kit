# Frozen blind drawing evaluation

The research tools `PrepareBlindDrawing.py`, `InspectBlindDrawing.py` and `BlindDrawingSemantics.py` separate neutral generation from native comparison. They preserve the original H01/H02 source-lock and specification digests, and admit the four independently derived standard orientations with finite positive explicit scale. Hidden recipes are not read until the original registration, complete neutral binding, qualified discovery result and immutable writer closure all verify.

`PrepareBlindDrawing.py generate` consumes only the original authored view recipe and a previously complete neutral bundle. It runs the guarded writer twice per case in a separate immutable source tree, requires identical complete outputs and zero runtime reads, and compares the output to independent trigonometric rotation and eight-corner projection math. A footprint extending beyond the sheet does not itself restrict view scale. Generation records its own source/method hashes and does not open a native comparison file or author observation.

After the host preparation digest is frozen, `attach-comparison` adds exact hash-locked native source pairs and their comparison-only observations. These values never enter generated requests. The standalone observer uses pristine native brackets and, for each case, native source and generated edit/save/fresh-reopen lanes. One disclosed rehearsal case requires eight fresh processes; both registered held-out cases require twelve.

The observer compares all measured sheet/view values, complete source/generated drawing and child feature trees, linked configuration and real child identity, body geometry and all initial/rebuilt/edited/reopened states. It passively enumerates annotations through the sheet and model views. A source annotation prevents this empty-annotation profile from qualifying; the annotation writer/comparison work remains an explicit unfinished requirement. Source/generated path roles and the derived child update stamp are the only declared comparison exclusions, with actual paths and child file hashes verified separately. Healthy controls or an interpretable failure cannot report a paired semantic pass.

The writer closure is identified by all 3,685 digests from the qualified scaled-drawing source manifest, not by a mutable checkout or a presumed commit alone. The private closure recovered original builder objects and the independently verified SDK parent sources, then reproduced all four native-qualified drawing/part pairs twice with identical complete reports and zero runtime reads. Both original frozen mapper and predecessor packets remain unchanged. The shared source hook and SDK work are preserved.

The original child intent is independently available in the authored `MakePartInput`/`PartFileTests` recipe: a 20×10×7 mm rectangular boss and its explicit names, configuration and provenance. The binding records that authority rather than taking fields from a sealed child. Shared sheet/name intent is explicit and must pass the paired comparison. This is a bounded drawing-layout/history evaluation; complete CAD acceptance and metadata, annotation or feature coverage beyond the declared comparison remain unfinished.

Local verification so far consists of immutable source recovery, eight exact qualified-input writer replays, a disclosed original-source generation with deterministic guarded replay, complete layout preflight against the disclosed native author record, and host-only oracle packet custody verification. The new native annotation/history observations and the original held-out layouts have not yet executed when this entry is prepared. Root owns those controlled runs; no VM, license process or sealed source was touched during preparation.
