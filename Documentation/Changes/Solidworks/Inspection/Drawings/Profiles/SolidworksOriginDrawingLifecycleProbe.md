# SOLIDWORKS origin drawing lifecycle probe

The new frozen probe measures four disclosed, fully SDK-generated linked drawing/part pairs. It uses ordinary SOLIDWORKS COM APIs only and never constructs a model through the vendor API. The preexisting SDK constructor closure remains unchanged. Hidden drawing sources stay closed.

`InspectSdkOriginLifecycle.py verify PACKET --packet-sha256 SHA` verifies packet metadata without starting an application. Guest `preflight` refuses every existing encoded target. `run` creates only new task-owned working copies, brackets the cohort with two pristine controls and uses 18 distinct owned application processes. Each pair passes open/rebuild/save, independent reopen, one child driving edit plus view movement/save, and another independent reopen. Corner models exercise width; centered models exercise height. Only the declared owned child copy is saved in place. Packet inputs and original drawing working copies remain immutable.

The observer checks the executable identity, exact locator/configuration, complete predicted trees, analytic child solid measures, driving parameter ownership, full constraint, contour/diagonal geometry, actual relation/entity roles, measured anchor coordinates, native origin/profile IDs, sheet/view properties and persistence. It records partial checkpoints and preserves every failure. It never closes an application outside its owned lifetime or stops licensing processes.

`QualifySdkOriginLifecycle.py CANDIDATE PACKET NEW_OUTPUT --manifest-sha256 SOURCE_SHA --packet-sha256 SHA --native-result-sha256 RESULT_SHA` performs the separate host join. The exact full Definition/linked-child decoder must retain bytes and owners. Initial and edited saved displays must resolve to each native-reported actual child origin, with its actual creation time, configuration and external component path. A guest pass alone is insufficient.

At preparation, only AST, mathematical packet preparation and file hashes were checked by this worker. Native probe execution and its typed saved-state join were pending. The underlying frozen constructor had independently passed 28 root-owned process checks, with 40 exact mathematical child-stream comparisons and unchanged prior corner outputs. No hidden source was opened and no public drawing writer or original-source parity was qualified. Screen-level rendering of the origin glyph is outside this COM/archive probe.
