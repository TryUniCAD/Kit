# SOLIDWORKS drawing epoch experiment

A private research factory now composes independently authored header, root-event and history clocks before child serialization. It uses the existing SDK model/header/history and complete linked origin drawing constructors. The normal constructor guards and original-source refusals stay unchanged.

Four cases separate earlier archive time, earlier root event and later history event. The real self-file creation identity and actual origin event lookup remain intact. A separate reader verifies both headers, history, linked graphs and exact stream emission.

The [source record](../../../../../../re/solidworks/records/DrawingSourceEpochExperiment2026.md) and [process receipt](../../../../../../re/solidworks/measurements/2026/DrawingSourceEpochConstruction01.json) bind root's passing 26 fresh processes: eight guarded builds, four unchanged counterparts, four preparations, two published refusals and eight atomic negatives. All guarded builds attempted zero runtime input reads. The earlier text-owner failure is retained.

The [root-run deck preparer](../../../../../../re/tooling/sw2026/epoch/PrepareEpochNativeDeck.py) accepts only the exact frozen proof, hashes every source and input, and prepares ordinary native tools for a new controlled batch. The [host clock observer](../../../../../../re/tooling/sw2026/epoch/InspectEpochClocks.py) records actual saved owners after that batch. Neither host tool invokes CAD or the VM.

No native epoch acceptance, hidden-input acceptance or public constructor expansion is claimed. The [text representation](../../../../../Gotchas/Conversion/Solidworks/Archive/ExternalReferences/HeaderLogTextHasItsOwnRepresentation.md) and [drawing clock owner](../../../../../Gotchas/Conversion/Solidworks/Archive/Drawings/DrawingClockInputsNeedActualStreamOwners.md) notes describe the two corrections made while preparing this experiment.
