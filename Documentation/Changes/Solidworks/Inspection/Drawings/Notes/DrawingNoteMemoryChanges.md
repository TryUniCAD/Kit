# Measure drawing note edits and inserts across rebuild

Adds a research observer for the exact disclosed ANSI A drawing inputs from the prior display-flag matrix. Verify a hash-locked job with `ObserveNoteMemoryChanges01.py verify --job PATH --sha256 HASH` and use `run` in the reserved native oracle. The observer replaces the existing note text and inserts a separate native note into a read-only drawing, with viewport captures before and after each rebuild. It checks actual annotation inventory, immutable inputs and unchanged preferences.

All four independent processes opened without errors or warnings. The native source and both pristine brackets retain the viewport changes through rebuild. In the generated drawing both changes appear on redraw, then the pixels return to the exact pristine baseline during rebuild. Both live note objects remain available through the API. Drawing rendering and held-out qualification remain open.
