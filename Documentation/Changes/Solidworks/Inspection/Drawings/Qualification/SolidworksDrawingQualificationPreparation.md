# Preparing original drawing qualification

This method prepares the existing complete SDK linked-drawing constructor and
its actual generated part for the two original drawing hold-outs. Preparation
reads only the published source-lock metadata, current source, disclosed neutral
fixtures and disclosed SDK measurements. It does not read sealed specifications,
native files, associated child dimensions or private observations.

The source candidate binds the complete SDK Python source, executed research
helpers, independent mathematical comparator, native observer tools and the
disclosed process fixture. The metadata-only preparer rejects source changes
during copying. A separate root-owned replay must pass the existing six-design,
25-rejection, 43-worker cohort. Root confirmation of the immutable writer is
required before unsealing anything.

Two earlier preparation attempts stopped before generation: one lacked the
disclosed `DrawingBlankSpec01.json` dependency; the next exposed a research
`dis.py` shadowing Python's standard library. The private repair moves research
directories behind the standard library in both worker processes, retaining the
explicit checkout SDK. It changes no writer fields or feature semantics. See
[the import-path gotcha](../../../../../Gotchas/Ci/Commands/ResearchPathsCanShadowStandardModules.md).

The public lock identifies `H01SheetA` and `H02SheetB`, their original hashes,
one shared part hash, a paper-size code, the exact oracle and authoring custody.
It does not expose enough per-case semantics to establish either compatibility
or an unsupported feature. The current SDK profile is one unformatted ANSI A
landscape sheet, one explicit named absolute view and an actual generated XY
rectangular blind part. Other child history, sketch constraints, annotation or
view families must be admitted explicitly after the freeze, never discarded.

The qualification plan separates frozen writer generation from original-source
measurement. It requires independently computed geometry, exact child resolution,
healthy source controls, edits, nonempty saves and fresh reopen. Existing disclosed
view-movement evidence does not substitute for a linked child driving edit.
Nothing in this preparation enables public drawing writing or claims native or
held-out acceptance.
