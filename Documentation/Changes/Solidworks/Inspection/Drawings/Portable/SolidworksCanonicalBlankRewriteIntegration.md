# Rewrite canonical generated blank drawings

The SDK and CLI regenerate one unchanged canonical Kit-generated blank SOLIDWORKS drawing from its strict decoded document. Pass the document to `write_document(document, destination)`, or run `kit convert source.SLDDRW destination.SLDDRW`. Strictly decoded Kit JSON supports the same route. The output keeps sheet layout, native presentation, creation and revision history, and the model title. The destination locator and save event are recomputed.

The rewrite verifies the typed source witness against the original SHA-256 and native sheet identity. Its scope is an unlinked ANSI A landscape sheet. Ordinary vendor-authored and vendor-saved files, views, annotations and changed layouts remain outside this rewrite profile. Older source-intent JSON with an omitted optional note field stays admissible.

Two sealed, pre-writer SDK sources passed twelve fresh SOLIDWORKS 2026 SP05.2 processes, with both pristine controls, thirty sheet states and 120 ordered tree rows. Eight additional processes on two disclosed inputs exercised direct SDK, SDK via JSON, inferred CLI and explicit CLI. Within each source, all four outputs were identical at a fixed save event and locator. Guarded construction made zero runtime input reads. The CLI test covers source metadata before and after introduction of the optional note field.
