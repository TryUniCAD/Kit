# Drawing centreline load rule

The SOLIDWORKS 2026 drawing loader sets the `CLUseCenterline` mask `0x100000` on its effective detail object for drawing versions through 19000. The raw detail serializer stores that runtime word.

The ANSI constructor clears the mask first. The shared load rule applies across drafting standards and explains the additional centreline difference in the disclosed ANSI saves. `getDetailDefs` can select a runtime detail override.

Original-image verification covers five pinned modules, sixteen complete functions, ten instruction windows and two concrete RTTI and vtable owners.
