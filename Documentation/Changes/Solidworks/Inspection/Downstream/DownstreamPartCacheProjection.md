# SOLIDWORKS generated part cache projection

The [research projection](../../../../../re/solidworks/records/DownstreamPartCacheProjection2026.md) derives standalone downstream stream names from configuration IDs, models the skip, removal and write branches, and inserts a typed cache into a generated part archive. It populates the finalized cache prefix from the exact build and actual generated header. It also projects the ordinary boundary face roles and the actual three surface identities of the exercised cylinder bodies. Local downstream component clones have individual object slots and a context-bound part owner.

Use the record's four process entry points for replay. Repeated runs preserve ten or eleven generated input streams, according to the part builder used. They reproduce the typed cache bytes, preserve role and reference identities, and record zero runtime file reads inside the guarded construction. The [measurement receipt](../../../../../re/solidworks/measurements/2026/DownstreamPartCacheProjection01.json) records the exact cases and hashes.

Actual populated cache root membership, file-reference list state, native rehydration, held-out inputs and the production adapter writer remain open.
