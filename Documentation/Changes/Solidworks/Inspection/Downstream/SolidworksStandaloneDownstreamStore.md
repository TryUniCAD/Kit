# SOLIDWORKS standalone downstream store

The [exact-build store record](../../../../../re/solidworks/records/DownstreamStandaloneStore2026.md) now binds the ordinary part sidecar writer separately from its already known reader and embedded configuration branch. It records the concrete storage dispatch, actual configuration enumeration/cache guards, `getStorageName()`-derived name, fresh archive/UI helper setup and direct body call without an outer object tag or map-count word.

Use this source rule with the existing raw body and generic archive primitives. Preserve skipped unopened/rebuild-pending configurations and the explicit missing/stale-cache deletion branch. Template, autosave, assembly attachment and unknown contexts remain outside this ordinary profile. No captured fields, populated cache defaults or production writer are introduced.

The numeric record pins all original native bounds and hashes. A mixed-mode name helper is independently bound through its exact CLI identity; see the [native-entry-cell gotcha](../../../../Gotchas/Conversion/Solidworks/Archive/Downstream/NativeEntryCellsMayContainManagedTokens.md).

The selected live document-manager installation, saved-stream recursive replay and native/held-out acceptance remain open. Earlier research packets are unchanged.
