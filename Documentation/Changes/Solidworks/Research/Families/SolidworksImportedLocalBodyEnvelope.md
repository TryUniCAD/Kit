# Inspect the native import storage envelope

The [envelope probe](../../../../../re/tooling/sw2026/imported_body_source/LocalBodyEnvelope.py)
decodes a hash-locked native import's separately named local body and
configuration partition. It evaluates the actual resolved atom and selected
mark and uses the measured archive count, name, validity and length rules to
reconstruct the outer archive framing.

Two independent host processes reproduce both complete streams. The
[measurement](../../../../../re/solidworks/measurements/2026/ImportedLocalBodyEnvelope01.json)
records the matching hashes. A disclosed contrast mode in the
[native source protocol](../../../../../re/tooling/sw2026/imported_body_source/README.md#use-the-results)
prepares a translated box and independent feature and body labels. Fresh
import generation and public conversion remain open.
