# Sealed imported geometry probe

The staging tool freezes a committed interpreter closure after verifying the
previous native source lock. It stages a control and opaque hashes. The guest
evaluator reads the original native parts inside the oracle, projects each
strict SDK boundary to an equivalent neutral rectangular solid and writes a
new local-body archive under a guarded construction process.

The native evaluation checks the untouched original, the generated part and
its fresh reopen in separate processes bracketed by controls. It compares
geometry against the independent authoring specifications and checks the
real import feature and its persistent reference. It shares result digests
and explicit source omissions. The private inputs and geometry measurements
stay in the guest. This procedure covers geometry-only transfer for the
sealed rectangular import profile. Complete original-source conversion and
the public writer require their own transfer evidence.
