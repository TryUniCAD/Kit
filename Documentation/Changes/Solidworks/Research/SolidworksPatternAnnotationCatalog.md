# Model-owned pattern annotation views

The SOLIDWORKS research tools generate an ordered Config-0 annotation catalog from neutral names, frames and display state. Display membership follows the allocated view, independent of the camera list. Two models replay exactly in four guarded processes with zero runtime input reads. This work measures the Config-0 slice. Native acceptance and the complete angular feature remain pending.
