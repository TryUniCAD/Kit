# SOLIDWORKS radial display store isolation

The radial visibility preparer accepts `--display-component xml-only`
or `--display-component store-only`. Each fresh experiment generates
the baseline and one selected parent store from the same neutral
assembly. The child archive, occurrence identities, mate, locators
and configuration-manager policy match within the pair.

Each single-store build must match the selected stream in the jointly
generated control. The binary VisualStates trial preserved both named
visibility states through a driving edit, save and fresh SOLIDWORKS
2026 SP05.2 reopen. It passed 84 candidate measurements with both
controls healthy. Native save also populated the initially empty
XML display-state list.

The XML-only trial opened without warnings and exposed only the
default display state. Both controls passed and the candidate
stopped at the display-state inventory check.
