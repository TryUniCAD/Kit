# SOLIDWORKS radial display store isolation

The radial visibility preparer accepts `--display-component xml-only`
or `--display-component store-only`. Each fresh experiment generates
the baseline and one selected parent store from the same neutral
assembly. The child archive, occurrence identities, mate, locators
and configuration-manager policy match within the pair.

Each single-store build must match the selected stream in the jointly
generated control. The frozen native procedure checks whether that
stream alone exposes and preserves the same named visibility states
through the existing native lifecycle.
