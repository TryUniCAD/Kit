# Generated cylinder body attachment

The host-only attachment experiment constructs a single output atom and writes the model, feature, mark, and kernel body references from the same neutral Front diameter cylinder. The live-body visibility row, output list, and atom manager all reference the same archive object. The modeled allocation session supplies the independent kernel tag and update events.

Run `python -B -m para.cylinder.CheckAttachment 1` or `2` with `src`, `re/tooling/sw2026`, `re/tooling/sw2026/serial`, and the repository root on `PYTHONPATH`. Two distinct generated parts pass in two fresh processes each with zero runtime reads. SDK readback resolves the producing extrusion, lateral face, and body, and checks that both mark references and update stamps agree across streams. A second attempt to attach the same output is refused.

The experiment stays in research. Native open, rebuild and edit, full tracking and display data, assembly mate writing, and held-out acceptance remain pending.
