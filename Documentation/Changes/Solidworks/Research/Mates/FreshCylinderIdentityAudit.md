# Fresh cylinder identity audit

A reusable host-only process audit distinguishes the identities genuinely supplied by the normal circle part writer from the kernel and body identities still required for a concentric endpoint. Two independently authored Front/Top circles use the real SDK preparation and public registry paths. Their actual feature, arc and header owners are preserved. Both generated parts lack a saved partition and body output atom; strict public reads reconstruct exact analytic geometry without inventing native persistent IDs.

Run `python re/tooling/sw2026/RunFreshCylinderIds.py --root /path/to/frozen-sdk --source-manifest /path/to/SourceBefore.json --inputs /path/to/AuthoredInputs01.json --output /unused/output`. The private checksum-bound handoff supplies those exact inputs and source closure. Every generated request has explicit radius, centre, depth, support, radial mode, direction, event epoch and final native identity. The in-memory generation boundary forbids file opens, runtime launches and network connections.

Twelve fresh SDK processes pass, including deterministic preparation repeats, eight normal default/metadata reads and four separate analytic encode/decode probes. All full nineteen-row public histories survive. The probe never attaches the analytic stream to a part, enables a new writer, accesses vendor-saved/hidden sources or runs the native application. Five earlier observer plumbing failures are retained by hash. Current SDK source is unchanged.

Fresh kernel face/atom publication, optional cylinder vector construction, circle child assembly bounds, native acceptance and held-out qualification remain open. This research addition does not qualify a concentric writer.
