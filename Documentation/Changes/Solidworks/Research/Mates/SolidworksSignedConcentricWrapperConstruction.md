# Construct signed concentric wrappers

The research-only concentric writer can take two ordered child-local endpoint axes through `make_concentric(..., endpoint_axes=...)`. It checks their ownership against the actual generated cylinder and computes the signed world directions and rim extents from each actual placement. The ordinary default path produces the same bytes.

The offline replay covers the disclosed D01 original and edited cases and an independently authored tilted anti-aligned locked case. Each reproduces its signed parent and child twice without runtime I/O. Legacy full files and verification receipts match in four fresh workers. Fifteen invalid selections or generated-wrapper changes refuse. This work leaves the pre-solve, whole-source and public writer gates in place.
