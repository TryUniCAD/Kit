# Construct the empty assembly exploded-view manager

The shared assembly composer accepts an explicit option for the ordinary empty exploded-view manager. The actual Config-0 model owns its generated node. The separate keyword index carries one `Feature` row by its allocated ID and an empty native name. The normal reader recovers the manager and the existing light and annotation rows.

Guarded host construction verifies the selected empty state and preserves existing outputs byte for byte when the option is absent. Populated exploded views, vendor acceptance and whole-source admission remain outside this slice.
