# Lock independent SOLIDWORKS edge-fillet sources

The [edge-fillet acquisition method](../../../../re/solidworks/records/EdgeFilletSourceAuthoring2026.md) now supports an independent pair in a protected Windows directory. It reuses the native phase tools verified against the two disclosed constant-radius fillets on SOLIDWORKS 2026 SP05.2. A separate method packet contains only those public inputs and the acquisition tools.

The guest supervisor checks the exact prior method and healthy controls, binds the supplied private intent by SHA-256, and requires both new source and edit/reopen lifecycles between fresh controls. Only the four native source digests and method/build evidence are published. The private model intent, phase receipts, CAD binaries, geometry siblings, and persistent-reference data stay in the protected guest directory.

The host verification checks the method package before any native execution. The private run still requires the designated oracle owner and an independently chosen pair. A source lock establishes custody before writer implementation and grants zero writer acceptance.
