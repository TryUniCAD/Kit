# Generated local-body part diagnostics

The research composer builds a complete SOLIDWORKS 2026 part from one typed
neutral prism. It allocates the actual configuration, import feature and body
atom, generates the bare Parasolid transmit and writes its separate local
storage envelope. The two diagnostic modes vary only the model-derived body
tracking attributes and resulting file identity. The model's active partition
keeps an empty world and a generated rollback history.

The guarded process builds rectangular and concave cases in both modes,
verifies all twelve compound streams and rejoins the typed archive and kernel
owners. The exact-build oracle brackets the candidates with native controls and checks
cold geometry, rebuild, body identity and persistent feature ownership. Four
original probes pass 280 geometry comparisons across healthy control processes.
SOLIDWORKS reports load warning 32 on all four. A separate authored ambient
comparison reproduces the warning and all 280 geometry checks, with local
body and active partition bytes unchanged in each same-path comparison.
Publishing the completed origin and import update state makes all four
disclosed candidates open, rebuild, save and freshly reopen with zero
diagnostics. The 11 fresh processes pass all three controls and 560 geometry
comparisons, with identical kernel and active partition bytes against the
same-locator pending builds.
The public writer and original held-out source qualification remain open.
