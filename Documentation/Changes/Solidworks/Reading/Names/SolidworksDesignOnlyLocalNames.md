# Preserve imported body names in design-only reads

Strict design-only reads bind the existing design body to the same native
local storage group and producing feature as a full read. They retain the
verified name and ownership evidence while leaving the B-rep and its
payloads out of the returned document.

The reader checks the physical active and rollback frames, the selected
partition mark, the linked configuration and import feature, and the
actual storage and name owners. Four measured rectangular and concave
imported parts preserve the same body identity and name in both read
modes. The existing public round-trip process checks this behavior.
