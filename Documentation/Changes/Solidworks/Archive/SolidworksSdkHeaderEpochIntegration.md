# Direct SDK Header epochs in fresh mates

Fresh planar mate construction now reads actual standalone SDK Header
log and stamp nodes alongside the established object-body row view.
The lookup preserves node identities and event order, uses the selected
datum's first real creation event, and rejects malformed or ambiguous
data before changing parent allocation or fixed state.

Generated process checks compare both header views with the unchanged
reference publisher across principal axes, absent/empty logs and two-event
logs. Faults cover counts, classes, schemas and epoch domains. Historical
bundle replay also retains authored folder ordering and records exact
stdin bytes separately from canonical JSON.

This addition fixes the internal header boundary. Public native writing,
complete SDK assembly composition and new native/held-out qualification
remain outside its scope. Read the [integration record](../../../../re/solidworks/records/SdkHeaderEpochIntegration2026.md)
and [sanitized proof](../../../../re/solidworks/measurements/2026/SdkHeaderEpochIntegration01.json).
