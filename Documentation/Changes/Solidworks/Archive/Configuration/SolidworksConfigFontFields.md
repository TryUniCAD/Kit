# SOLIDWORKS configuration font fields

The shared body reader has four layouts for current part detail definitions.
The layouts read line fonts, their embedded width, character formats, and
print widths. They keep the source names and typed numeric fields.
The enclosing record supplies the layout name and archive context.

The layouts apply to archive version 19000. Each embedded call leaves the
archive object map unchanged. Complete configuration reads require the
remaining detail and model owners.

Three guarded host processes read four exact intervals in each of two
tracked parts and four independently authored records. All fields matched
an independent decoder. Eight malformed records and unsupported
layout or version cases returned the expected refusal. The queue runs the
same cases through the integration suite.
