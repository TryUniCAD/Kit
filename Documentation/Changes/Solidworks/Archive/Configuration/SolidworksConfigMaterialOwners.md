# SOLIDWORKS lightweight configuration material owners

Supply the version-19000 part owner, inherited map and bounded lightweight
suffix to `ReadPartMat`. It reads the hatch, optional material and density,
null-scene model data and empty body visual counts. The actual density
object and downstream class and object slots remain in the returned map.

The disclosed L1 and ConcaveOwned records cover populated and absent
material ownership. Independently authored process cases vary wire values
and check the alternate density, scene and count refusals.

Full appearance, physical material assignment, complete configuration
admission and native writing require separate qualification.
