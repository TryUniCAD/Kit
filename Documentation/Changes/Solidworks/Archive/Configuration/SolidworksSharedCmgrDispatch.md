# Shared SOLIDWORKS CMgr write dispatch

The internal version-19000 configuration-manager codec uses the common archive
context and concrete virtual actions. A virtual `Flag` slot now requires an
actual Boolean target before either direction selects its nested fields.

Ten guarded host processes reproduced three disclosed manager streams and
verified the computed map change for independently authored managers with and
without a name. Both selectors retained their actual shared directory object.
The guard observed zero runtime external accesses. The disclosed controls
include one SOLIDWORKS-authored part and two previously generated parts.

This verification covers one ordinary part configuration at local ID zero.
Populated 3D printing settings, alternate archive modes, general source
transfer and new native or held-out writer acceptance require separate
evidence. See the [CMgr record](../../../../../re/solidworks/records/PartCmgrResearch2026.md)
and the [virtual flag rule](../../../../Gotchas/Conversion/Solidworks/Archive/VirtualFlagsRequireBooleans.md).
