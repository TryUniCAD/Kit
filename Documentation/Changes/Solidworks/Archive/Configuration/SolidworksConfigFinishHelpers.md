# Configuration surface-finish helpers

`ReadCfgFinish` reads an ordinary version-19000 surface-finish helper
from a bounded Config-0 interval with its actual mapped part owner.
Its shared layout preserves signed and unsigned fields, text, the
finish font and the font inside the embedded annotation helper.

The two disclosed saves supply six exact finish bodies and eighteen
embedded annotation and font bodies. The queue decodes the preceding
allocation tags from those saves and verifies the complete slot
directory against the independent live Config-0 traversal. The codec
preserves all projected map entries, both inverse lookups and the
actual inherited part and ModelHeader identities. A separate guarded
case emits authored fields, including different ANSI and Unicode font
names, against independently assembled wire bytes. Queue processes
require only the candidate checkout and use zero guarded runtime
external accesses.

The operation covers the measured embedded wire records. The full
detail and weld parents, annotation editing and public configuration
admission have separate acceptance gates.
