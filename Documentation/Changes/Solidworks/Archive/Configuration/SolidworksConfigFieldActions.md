# SOLIDWORKS configuration field actions

The bounded version-19000 `ReadCfgMember` reader accepts absent or
empty sketch block and part exploded view manager records. Supply the
specific owner descriptor, the exact record interval and the caller's
archive map snapshot. The sketch manager retains its fixed 16-byte GUID
and resolves the embedded map backlink to its own new object.

The feature base uses shared branches and concrete virtual targets.
The codec checks both inherited feature state and the two concrete
suffixes before exposing the result. This internal decoder reports
unsupported populated managers at its bounded parsing entry. Full
`Config-0` admission for literal part properties is tracked in
[PR #183](https://github.com/TryUniCAD/Kit/pull/183).

The reference trace measures both real owner intervals in the disclosed
L1 part and both null intervals in the concave control. Fresh process
queue cases cover the physical records and invalid owner, virtual,
backlink and framing cases, including a complete single-row exploded
view map that reaches the semantic owner guard. Queue execution remains pending.
