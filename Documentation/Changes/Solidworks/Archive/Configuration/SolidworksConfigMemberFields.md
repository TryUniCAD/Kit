# SOLIDWORKS configuration member fields

The internal `ReadCfgMember` codec reads one bounded version-19000 member
from immutable bytes. Pass the concrete role descriptor and a snapshot
of the owning archive map. The result retains typed fields and the map
needed by subsequent owners.

The relation manager uses schema one. Its stored words and dimension
cache retain their native types. Its typed member list supports nullable
rows. The observed empty color table uses schema zero. An absent color
owner consumes one null tag. Populated color rows and linked
relation objects require further owner layouts.

Fresh host processes read four physical members from the disclosed
ladder and concave parts. A separate authoring control verifies the
named count traversal, raw unsigned count retention and class map
handoff. The queue process cases and full configuration qualification
remain pending.
