# SOLIDWORKS configuration thread and mark records

Pass a bounded version-19000 member record, its expected descriptor
and the current map snapshot to `ReadCfgMember`. The reader retains
the thread manager's signed Boolean wire word and its runtime value.
The partition mark reader retains its signed kernel ID and separately
allocates the archive object.

The bounded thread profile accepts empty maps or absent managers.
The bounded mark profile requires a concrete schema-one mark.
Populated holder maps, complete configuration parsing and native
writing remain separate work.

Reference reads identify four physical intervals in the disclosed
ladder and concave controls. New queue cases verify those inputs,
authored signed words and malformed records through the guarded reader.
Queue execution remains pending.
