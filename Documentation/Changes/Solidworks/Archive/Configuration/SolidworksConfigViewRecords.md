# SOLIDWORKS configuration view records

The internal configuration member reader accepts one concrete
version-19000 `moView_c` record with compact transforms, empty linked
rows and absent optional lists. Supply its actual archive map snapshot.
The reader retains the stored name, scalars, both transform forms and
the class and object slots.

The shared body executor supports native zero-byte context assignments,
bit sets and clears. A view uses this state across its two list windows.
The two disclosed standard view groups and an independent active-condition
contrast are covered by prepared merge-queue process cases.

Populated lists, extended transforms, complete Config-0 admission and
native writing require separate qualification.
