# SOLIDWORKS archive body values

Internal field callbacks read and write fixed-width scalars, canonical
CString frames and mapped object links. Counted rows can call these
handlers while retaining their parent field scope. A stored field
alias supplies a write value when the primary field is absent.

Text reads reject overlong length prefixes before advancing the
cursor. Source ANSI frames keep their byte representation. The graph
writer permits null and backreference tags at its maximum open body
depth. New objects at that depth and empty class names fail before
the writer assigns a slot for them.

The [fresh-process cases](../../../../tests/Convert/Solidworks/ArchiveValues/BodyValueTests.py)
check generated bytes, text values and shared object identity.
[Depth and descriptor cases](../../../../tests/Convert/Solidworks/ArchiveValues/ValueDepthTests.py)
check terminal tags and refused writes. The
[text refusals](../../../../tests/Convert/Solidworks/ArchiveValues/ValueRejectTests.py)
check cursor and field state. Current-revision process results await
remote CI. Stream layouts and native document acceptance have
separate verification requirements.
