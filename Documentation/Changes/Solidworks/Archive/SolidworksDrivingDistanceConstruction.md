# Fresh driving planar distance mate graphs

The SDK can construct one ordinary positive aligned planar distance mate
with its real length parameter, value dimension, retaining handle and
model-styled display. It allocates the dimension ID before the mate ID
and retains the actual ordered occurrence and child-plane references.

Use `MakeDistMateMut` with the actual parent graph, a distance
`PlanarMateIn`, and explicit `DistanceInput` values in metres. The first
profile requires two resolved direct part occurrences, principal planes
with positive signed separation, a fixed anchor and ordinary zero-tolerance
linear style. Other distance modes and public writing remain disabled.

Generated process checks compare complete parent and child artifacts with
the unchanged research composer and verify that a driving-length change
alters only MatesList. Malformed inputs must leave shared IDs, reference
counters and fixed flags unchanged. Native and held-out acceptance remain
separate gates; this addition does not activate an adapter writer.

Read the [construction record and reproduction command](../../../../re/solidworks/records/SdkDrivingDistanceConstruction2026.md),
the [sanitized receipt](../../../../re/solidworks/measurements/2026/SdkDrivingDistanceConstruction01.json)
and the [typed packed-double coverage gotcha](../../../Gotchas/Conversion/Solidworks/Archive/Dimensions/PackedDoubleCoverageDoesNotMeanOpaquePayload.md).
