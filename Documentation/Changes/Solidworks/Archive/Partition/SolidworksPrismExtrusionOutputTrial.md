# Bind the generated prism body to its producing extrusion

The research composer accepts `--link-extrusion-output` when generating its ordinary one-body prism. It verifies the actual attributed partition body, manager atom, producing extrusion, and body-match value. It then links the same atom object into the extrusion output array and derives the output ID from that node.

Use it with the existing neutral ambient specification and saved-bookkeeping options. Six guarded generations cover two shapes, including same-locator controls. Each same-locator pair changes only ResolvedFeatures. Readback preserves the actual Config-0 atom alias, and the generated partition stays byte-identical. Both linked prisms expose one correct solid on normal cold open. Both unlinked counterparts expose zero. The linked shapes preserve driving depth edits through rebuild, save and fresh reopen. The eight-process trial includes two healthy native controls and adds no public profile.
