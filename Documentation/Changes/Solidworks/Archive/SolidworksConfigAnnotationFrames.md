# Read SOLIDWORKS configuration annotation defaults and frames

The internal bounded reader preserves the inline annotation defaults, their ten base records and the geometric tolerance helper in ordinary SOLIDWORKS 2026 part configurations. It retains the signed layer selector, counted string arrays and canonical short null references. Populated layer, tolerance, datum and indicator owners require additional layouts.
