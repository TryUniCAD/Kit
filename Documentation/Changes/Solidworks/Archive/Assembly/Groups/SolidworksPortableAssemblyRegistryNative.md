# Measure a portable SOLIDWORKS assembly through a writer registry

The isolated Kit registry generated a three-occurrence assembly and its
shared dimensioned child from a neutral document. SOLIDWORKS 2026 SP05.2
verified the exact generated pair through a driving distance edit, child-first
save and fresh reopen. Four native processes passed 440 numerical checks with
healthy controls. Kit read back all six typed mate endpoints and reproduced
26 scoped archive streams byte for byte.

The measurement covers the disclosed assembly with ordered aligned distance,
coincident and parallel mates. It uses an explicitly supplied private writer
registry. Default registration and the original FCStd corpus have separate
qualification requirements.
