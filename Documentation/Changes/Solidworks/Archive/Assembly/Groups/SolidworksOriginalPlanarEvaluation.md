# Freeze the original planar mate SDK evaluation method

New research tools prepare the original pre-writer-locked assembly evaluation
without exposing its two sealed designs on the host. A strict semantic stage
preserves actual names and selected configurations while independently building
the known dimensioned rectangle child, placements and ordered mate graph from
the authored recipe. It validates complete principal-plane ownership and rejects
unsupported source state before generation.

Use `CheckOriginalPlanarMethod.py` to replay the two disclosed document/recipe
pairs in fresh processes. The frozen proof passes twelve successful processes,
seven fail-closed negatives and 88 typed stream round trips. Both whole-file
bundles match the independent mathematical composer and pass strict public
readback. No original held-out source or CAD application is accessed.

`FreezeOriginalPlanarEvaluation.py` pins the passed source, dependency lock,
tools, public locks and root-supplied locator strings. Run its frozen driver's
`verify` and `dependency-check` before source release. Guest-only `prepare` and
`measure` require `--release-source-evaluation`. Each slot freezes request and
prediction before construction, then compares the immutable original against
the generated editable pair in five fresh native processes with disclosed A22
brackets, synchronized save and fresh reopen. Progress exposes slot state,
process identity, verdicts, check counts and hashes; detailed source content
stays guest-local.

Host preflight verifies code/dependencies and rejects both unreleased commands
with zero attempted original-specification or native CAD file opens. The
separately recorded [original A20/A21 evaluations](SolidworksOriginalPlanarMateNative.md)
subsequently passed. Public assembly writing remains disabled.
