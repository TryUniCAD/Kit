# Frozen perpendicular blind evaluation

PR #121 adds a private neutral translator, independent paired comparator, complete source/runtime freezer, guest-only slot extraction and phased native evaluation for one ordinary perpendicular. The [guide](../../../../Reference/Research/Solidworks/PerpendicularMateEvaluation.md) gives the workflow and [method record](../../../../../re/solidworks/records/PerpendicularMateBlindMethod2026.md) documents exact scope, inputs, release gates and remaining qualification.

Twelve disclosed process checks pass translation, deterministic complete generation, typed ownership and independent predictions while rejecting unsupported reverse source-selection order and host sealed-slot inputs. Authentic independent native controls pass the comparator; an authentically different design is rejected. The full 5,844-file source closure and 39 tools are frozen before hidden access. Two additional processes confirm the guest-only entrypoints reject host execution.

The first runtime preflight exposed bounded arithmetic differences: two-ULP standard-view diagonals and a one-ULP frame projection. Independent typed and arithmetic probes explain every changed value, with all other fields and aliases exact. The writer math is preserved, both host/guest commitments are retained, and actual guest replay must match its complete file identities twice before extraction.

Hidden payloads, predictions and observations remain guest-private; public progress reports only opaque identifiers, hashes, statuses and process identities. The actual guest reproduced its disclosed identity twice before root released the two opaque neutral preparations. Both subsequent source-only builds and hidden native evaluations passed under the unchanged frozen method, as recorded in the [terminal proof](../../../../../re/solidworks/measurements/2026/SdkPerpendicularHeldoutNative01.json). Native execution remains root-owned, and normal public perpendicular writing remains unfinished and disabled.
