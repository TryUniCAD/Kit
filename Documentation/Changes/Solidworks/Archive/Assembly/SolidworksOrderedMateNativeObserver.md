# Ordered SDK mate native observer

The research observer now measures an independently generated SDK assembly
with ordered coincident, positive-distance and parallel mates on a rotated pair
of resolved occurrences. It reuses the existing native phase and synchronized
save implementation, with separate read-only A22 control brackets.

The packet freezer takes an exact generated fixture and disclosed control
recipe/parent/child paths, then writes an unused external packet containing
hashed tools and immutable generated inputs. The observer's `verify` command
recomputes the authored geometry, full expected trees, configuration identities,
ordered endpoints and distance-edit prediction without importing COM. Its `run`
command is reserved for the serial pinned Windows oracle and requires the
packet's SHA-256.

Native acceptance requires all four fresh phases, full trees, both configuration
names, the child's live D1, all six specific plane references, all three ordered
constraints, the live assembly distance edit, child-before-parent save and
fresh reopen with zero errors and warnings. The fixture's plain child and
proper Z rotations bound this observation method. Public writing and held-out
acceptance remain separate gates.
