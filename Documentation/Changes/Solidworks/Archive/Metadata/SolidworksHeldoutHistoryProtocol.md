# Verify held-out SOLIDWORKS metadata streams

The research tool freezes the bounded version-19000 History and Biography codec for a standalone comparison on two original SOLIDWORKS parts. Their exact source lock predates the first donor-free metadata constructor, and their prior native lifecycle records bind the original hashes.

The host verifies the packet and runs a synthetic trace through an isolated process. Root runs the actual replay on the Windows guest. Each stream must have complete archive ownership and reproduce its exact bytes. The result records counts, hashes and verdicts without exporting source payloads.

The protected replay is pending. This tool does not register a public writer or measure a newly generated part. [Chronology and guarded protocol](../../../../../re/solidworks/records/HistoryStreamSlice2026.md#prospective-held-out-stream-comparison)
