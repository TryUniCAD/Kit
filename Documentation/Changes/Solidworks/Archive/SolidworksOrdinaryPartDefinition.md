# SOLIDWORKS ordinary part Definition codec

The internal version-19000 codec reads and emits the ordinary part `Contents/Definition` stream. Its constructor derives the archive from explicit presentation and density settings. The public part writer requires separate qualification.

Two independently authored streams and two disclosed native saves re-emit byte for byte. Guarded workers also checked twelve refusals, including assembly roots and unsupported rendering objects. Fresh native lifecycle evidence remains pending for complete generated parts. [Field ownership and evidence](../../../../re/solidworks/records/SdkOrdinaryPartDefinition2026.md)

The ordinary reader requires canonical archive tag widths. Its merge-queue checks covered journal length growth, the tracked L1 save, guarded unsupported profiles and mapped object and class references.
