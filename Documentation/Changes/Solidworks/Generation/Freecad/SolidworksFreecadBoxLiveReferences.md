The disclosed F14a oracle protocol takes the two existing model-only parts generated from FreeCAD 1.0.2 and 1.1.4. It measures real SOLIDWORKS references before and after one Height edit, after the native save to a fresh derivative and on fresh reopen. The first native run verified the mechanics and stopped at the Python return-type guard before reference resolution. The corrected packet passed host verification and awaits the native retry. It identifies the actual AdditiveBox through face and body ownership and probes that feature's reference separately. It retains per-role status, resolved geometry and object equality. The two prior native controls bracket the measurement. Reference tokens stay in process memory.
