# Independent circular extrusion side geometry

Kit now has a bounded neutral BRep builder for independently drafted two-sided circular extrusions. It creates two exact frustum sides joined at the profile rim, with correctly oriented end caps, analytic volume, area, centroid and world bounds. Both positive and negative tapers retain their own side roles; an internal cap is never emitted. Untapered sides merge into a cylinder.

The implementation is `convert.Geometry.Extrude.Circular.DualSide.BuildDualSide.BuildDualSide`. Inputs are a design body identity, right-handed sketch `Transform`, local `CircleGeometry`, positive first and second distances in millimeters, and independent first and second taper angles in radians. It returns the complete neutral `BrepModel`, volume in mm³, area in mm², world centroid in mm and world bounding box. `MeasureDualMass` takes the same geometric controls without the body identity and returns two `SpaceVector` records: world-origin diagonal inertia `(xx, yy, zz)` and off-diagonal inertia `(xy, xz, yz)`, in mm⁵ before density. Nonfinite controls, collapsed or nonpositive end radii and right-angle tapers are rejected.

This is an offline geometry prerequisite. Strict Fusion reader admission, native writer guards and read-only markers are unchanged. Complete persistent feature naming, saved snapshots, graphics and native target acceptance remain unfinished; the helper does not establish conversion acceptance.

The [independent draft gotcha](../../../Gotchas/Conversion/Fusion/Geometry/Drafting/IndependentCircularDraftSides.md) explains why one cone or the general convex-meridian sweep cannot represent every measured side pair.

The [revision-bound proof](../../../../re/Fusion/DecodedPromotion20261127/DualDraft/Findings.md) compares all 101 independently recorded Fusion observations with 1,313 numerical checks and zero failures. It also compares all 68 committed native archives through the actual production document reader and typed journal, checking owned parameter roles, active-body ownership, cone/cap/rim geometry and closed topology. The full saved mass caches pass 748 comparisons across all 68 files using the existing cache-only tolerance, and eleven encoded single-component cache corruptions refuse explicitly. New cases use the existing shared archive integration suite, including the equal-volume swapped-side centroid counterexample and held-out parameter combinations. No CAD runtime, native API call, donor data or model execution participates in these checks. CI and merge-group acceptance remain separate.
