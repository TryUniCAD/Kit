# Preserve existing prism history and refusal contracts

The saved-edit reader had changed eight-byte, entity-tagged body histories from `JournalModel` to `PrismHistory`. The specialized view puts records in canonical order. Existing authored feature histories therefore changed representation, and a previously accepted prepared archive emitted different bytes.

Document reading now retains the complete typed journal for that existing eight-byte, entity-tagged profile. Four-byte saved-edit prism views retain their measured support. The standalone prism parser still reads typed identity values; document selection preserves the existing journal contract. Production decoding does not use captured templates or a CAD runtime.

Draft projection now requires a positive XY extrusion with its independent generic snapshot before admitting a nonzero taper or retired-sheet reset. A changed parameter attached to an ordinary prism cache, a reverse extrusion, or a YZ datum continues through its established checks. The untapered binding guard retains its existing diagnostic, including zero-depth rejection.

Empty prism tracking is omitted from semantic-state JSON so previously accepted neutral fingerprints remain unchanged. Nonempty source tracking is always retained. The decoder accepts both the older field inventory and an explicit empty tracking record. A declarative field-omission registry keeps this compatibility rule outside the shared encoding logic.
