# Native Student context and independently authored Boss witness

An independently generated ordinary rectangular Boss opened cleanly, retained live driving dimensions through three edits and restorations, saved through SOLIDWORKS and passed a separate fresh read-only reopen.
The observed display-state name and feature visibility survived.
The authored brown default appearance reset to gray; material fidelity remains a separate failed claim.
This evidence covers the measured generation-19000 single-profile blind Boss and caller-owned Student context, not universal or lossless SOLIDWORKS support.

## Actual save context

The registered legitimate installation was SOLIDWORKS `34.4.1.1011`.
A fresh native-authored ordinary scratch part was saved without copying or modifying any existing customer document.
Its untouched SHA-256 is `9621451488f922546b7cd0d2fd087d200450b4fc59031e40b45919fb6a92938b`.

Both stock controls and normal owned application exit passed.
The same file hash remained unchanged.
An exact task-owned descendant was recorded separately after the main application's normal exit, then cleaned through its held job.
No forced termination was presented as successful application exit.

## Public Boss cleanup integration

The public Boss collector now applies the verified hidden-document policy only to the final stock control.
Its opt-in no-save close requires that exact pinned scratch path, successful initial read-only verification, a sole document and an actual false visibility getter.
Failed initial verification retains the earlier cleanup fallback; read-only candidate reopen alone cannot select the no-save stock-control path.
The collector establishes and reads back owned background lifetime control after exact empty-process attachment.
The strict control/result schemas, arbitrary pinned control geometry contract, edit stages and historical receipt verifier are unchanged.
Actual interop compilation and process-bound source-pin refusal coverage verify the integration without repeating the already successful geometry witness.
