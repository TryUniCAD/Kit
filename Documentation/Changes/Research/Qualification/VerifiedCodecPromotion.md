# Verified codec promotion

A completed field or paired-gap assessment can now produce a Git patch for a scoped reader or writer change. The operator supplies a traced rule and independently measured holdouts. The public CLI must fail at least one baseline measurement and pass every measurement with the proposed code before publication. A refuted finding, stale receipt or changed input cannot qualify a patch.

[Command and request format](../../../Tasks/ResearchCommandLine.md#export-a-qualified-codec-change)

The hosted process gate seeds reader and writer failures in isolated copies of Kit, runs the inference controller, qualifies repairs against two interchange documents and replays the exported regression after applying each patch. These controls exercise the promotion workflow. Native CAD semantics require separate format-specific evidence.
