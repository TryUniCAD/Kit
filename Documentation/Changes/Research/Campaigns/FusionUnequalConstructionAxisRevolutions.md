# Unequal construction-axis revolution campaign

## Scope

Task `A08h-FusionUnequalAxis20261127` records bounded Fusion source evidence.
The campaign uses solid NewBody revolutions with unequal angular extents and explicit TwoPoints construction axes.
It varies each angle, axis origin, axis direction, radial offset and axial offset independently.
Angle swapping, axis reversal and two combined holdouts supply distinguishing cases.

The [research package](../../../../re/Fusion/UnequalAxis20261127/README.md) contains the authoring source, native files and recorded observations.
The [automation register](../../../Reference/Research/AutomationSteps.md#a08h-fusionunequalaxis20261127) owns status and remaining requirements.

## Use

The campaign uses the existing private CAD script worker, research controller, supervisor and deterministic CLI.
Select the licensed worker through its private host configuration.
Keep credentials outside the checkout.
The package records exact paths, hashes and invocations needed to reproduce its offline evidence.
Models remain disabled.

The catalogue P05 builder exposes one angle and cannot express this campaign's two angles and custom axis.
The separate campaign script uses the established native API sequence without changing shared builders or decoders.
The capture scripts require the native worker's `app` and `work` bindings.
They are research tooling, not standalone production commands.
