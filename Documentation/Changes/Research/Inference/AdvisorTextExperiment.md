# Executing advisor choices on stalled text decoding

For an unknown stream with an inferred text prefix and an opaque suffix, the file run offers narrow and wide counted-text probes. An accepted advisor selection executes first. The probes operate on the pinned input, search up to 64 bytes beyond the stall and require a second adjacent readable record. FileExperiments.json records each candidate pair or negative result. The advisor sees the generic question and experiment names. It cannot supply executable code. The run can also execute both probes offline.
