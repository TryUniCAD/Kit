# Deriving an extrusion edit reader

The FreeCAD research experiment varies each plausible millimetre length in the embedded extrusion definition together with the already identified driving parameter. It selects a field only when the emitter reproduces the saved change to the correct native end and preserves the other end. The resulting binding is written into a Python reader in Reader.patch. Its separate process must reproduce the entire recovered candidate graph before the CLI publishes the patch.

Apply the patch on its recorded repository revision, then run the generated Python file with one native part path and PYTHONPATH set to src and re/automation. The reader uses the repository's native evidence checks and handles only the native end bindings it learned. Its output is a research candidate for the verified edit. Reopening an exported model in FreeCAD requires separate evidence.

The forward-front control generated a LengthFwd reader. Applying its patch in an empty directory and running the installed script against two additional native controls recovered the reversed forward parameter at 14 mm and the symmetric total thickness at 20 mm. The original fitting part contained neither of these two variant files.
