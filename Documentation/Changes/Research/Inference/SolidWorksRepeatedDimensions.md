# Repeated SOLIDWORKS dimensions

The file-driven research command checks repeated extrusion depths against other saved parts. Controls must have a uniquely identifiable named scalar within the matching feature interval. The runner learns the distance from the next named feature and the locations of repeated depth magnitudes. A held-out prediction must identify exactly one framed scalar and agree with the public parameter span.

Sketches can store both display and driving copies of the same diameter or radius. The neutral reader can bind an unresolved dimension to a native circle when its measured geometry, operand index and displayed dimension type agree. The research report records the separate display and driving locations when both native operands also agree. Missing or conflicting evidence keeps the binding unresolved.
