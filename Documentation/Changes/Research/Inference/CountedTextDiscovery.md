# Recovering a counted text prefix

For a raw stream the decoder tries integer length fields and printable ASCII text stored in ASCII, UTF-16LE or UTF-16BE. A unique layout with two or more consecutive records produces byte offsets and field values. With at least two distinct controls, it freezes the codec sequence shared by the target and first control. Remaining controls must replay that same sequence and contain at least one different decoded value. The generated Python reader runs on each stream before the command publishes Reader.patch.

Use `kit run --root . auto --input stream.bin --control related.bin --control independent.bin --directory /tmp/raw-research`. Input-raw-structure.json reports the parsed prefix. For recognized Fusion active manifests, the run also compares the decoded asset and snapshot IDs to the repository's schema-aware manifest reader. Remaining bytes and non-ASCII text require additional evidence.
