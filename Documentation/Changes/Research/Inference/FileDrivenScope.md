# File-driven inference scope

`kit run` accepts a Fusion or SOLIDWORKS file in place of a feature catalogue. Reader output selects existing feature experiments by typed operation and end condition. The run preserves the source digest, available decode layers and remaining gaps. Gaps include unassigned uncompressed stream ranges and features without a research route.

The source file remains local. Supplying a licensed evidence worker or enabling the existing advisor uses the same settings as catalogue runs. A successful corpus assessment cannot certify a different input file.
