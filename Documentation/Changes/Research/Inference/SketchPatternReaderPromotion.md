# Promote a learned SOLIDWORKS sketch pattern count

Run the file-driven SOLIDWORKS command on a part with explicit linear or circular sketch pattern count records. The decoder learns the handle field from independent files. A candidate public reader must return the matching unitless integer and its eight-byte handle span. The decoder emits a Git patch for newly verified families after replay through the strict CLI. The engine block's two counts had previously been returned as lengths of six millimetres.

The integer parameter width remains unresolved. The public reader uses the independently located binary64 handle span for provenance. The native record pairing requires one explicit parameter and one explicit handle of the same family in a feature interval. Counts alone do not reconstruct placements or constraints.

At 39313546d the command emitted `SketchPatternCounts.patch` on the engine block. Applying that exact patch enabled both families in the public reader. Fresh strict CLI reads returned unitless integers of 6 and 6 for the block, 2 for the cylinder head, 5 for the bearing, and 8 for the crankshaft. The crankshaft was excluded from both training and patch generation. The integration case checks the public engine-block parameters and their handle spans.
