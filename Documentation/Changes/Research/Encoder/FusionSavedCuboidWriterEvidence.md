# Fusion saved-cuboid writer experiments

The research tools measure how a Fusion-saved fixed-corner cuboid stores its driving height and presentation. They preserve the SDK's read-only profile and generate no product conversion output.

## Usage

Use the repository's pinned Python and SDK. [DesignHeightEvidence.py](../../../../re/Fusion/SavedCuboidWriter/DesignHeightEvidence.py) checks the source custody manifest and follows the Design, ACT and Browser records. [DisplayHeightEvidence.py](../../../../re/Fusion/SavedCuboidWriter/DisplayHeightEvidence.py) takes repeated `--case` paths and an unused `--report` path. [PrepareDisplayContrast.py](../../../../re/Fusion/SavedCuboidWriter/PrepareDisplayContrast.py) takes a source archive, its SHA-256, and an unused output directory. It stages same-source research controls with separately normalized history, snapshot and material members.

The [native presentation protocol](../../../../re/Fusion/SavedCuboidWriter/PresentationOraclePlan.md) defines the independent controls, exact digest bindings, viewport observations and fresh-process checks. It is an isolated native measurement procedure. It uses no CAD application during ordinary SDK execution.

## Evidence and limits

The [Design report](../../../../re/Fusion/SavedCuboidWriter/DesignHeightEvidence.md) records four pinned graph checks, five negative probes, and identical reports from two fresh Python processes. The [display report](../../../../re/Fusion/SavedCuboidWriter/DisplayHeightEvidence.md) records eight prior saves and fourteen new research contrasts. A second baseline preparation reproduced all seven variant digests. A mismatched source digest refused before creating output.

The original and canonical history allocations differ even when the complete decoded model compares equal. The native presentation effect remains unmeasured. See the [physical display order gotcha](../../../Gotchas/Conversion/Fusion/Api/FusionGraphicsPhysicalOrder.md).

Fresh native checks did not dispatch while the host was occupied. The complete writer still needs generation from persisted authored semantics with the source unavailable, correct graphics and dependent state, and independent native open, rebuild, edit, save and reopen evidence.
