# SOLIDWORKS reader and writer delivery plan

The [delivery plan](../../Maintenance/SolidworksReaderWriterPlan.md) gives adapter developers a feature-by-feature route from the bounded part writer to full editable conversion.
Use the [conversion backlog](../../Maintenance/ConversionBacklog.md) to find the plan and the owning work registers.

The plan defines a held-out blind-boss round trip, a deliberate JSON edit, and independent native edit-and-rebuild checks.
It sets deterministic research as the default and describes when a researcher may seek advice on a parked finding.

The author checked the starting scope against the [measured part writer contract](../Solidworks/Construction/SolidworksMeasuredPartPublication.md).
The [CAD acceptance criteria](../../Reference/Operations/CadSuccessCriteria.md) supply the proposed native checks.
This documentation records future milestones. Existing measurement receipts retain their original scope.
