# Repository skill

[standard-pr-practice](skills/standard-pr-practice/SKILL.md) is the only
repository skill. Edit it directly; it is no longer generated from Kiro steering.
Claude Code discovers the same source through `.claude/skills/standard-pr-practice`.

Cubic is the only automated reviewer. Request it once per head with
`@cubic-dev-ai review this PR`. Only an explicit request from a verified repository
administrator authorizes agent queue enrollment, auto-merge, or merging.

See [merge queue operations](../MergeQueue.md) for CI phases and activation.
